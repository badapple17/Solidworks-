# 01 · 直齿圆柱齿轮（Z24 / m2.5）

> 模式 A（示意）+ 模型 → 图路线
> 生成模型：DeepSeek V4 系列（低成本档位）

## 1. 任务

用户用文字提出需求：直齿圆柱齿轮，按常规比例做个示意件，并顺带出三视图。没有图纸、没有功率/转速、没有变位系数，也没有逐项指定齿宽、轮毂、中心孔。

技能判定为 **A 示意模式**：不追问具体数值，但所有取值必须写清来源；出图属于路线 B，单独按工程图门禁验收。

## 3. 建模思路

齿形不是圆弧近似，而是**渐开线采样**：

- 基圆 `db = d·cos20°`；
- 每齿从齿根 → 基圆 → 渐开线上升 5 点 → 齿顶 → 渐开线下降 5 点 → 齿根，再沿齿根圆弧过渡到下一齿；
- 每齿 18 个点，24 齿共 432 段闭合折线；
- 同一草图里画出 φ20 中心孔，第一次拉伸即得到带孔的齿圈；
- 第二个草图是 φ36 / φ20 圆环，拉伸 20 mm 形成轮毂。

特征树只有两个实体特征：

```text
草图1 → 01_GEAR_BODY_Z24_M2.5_PA20（两侧对称 12 mm）
草图2 → 02_HUB_D36_BORE_D20（两侧对称 20 mm）
```

## 4. 参数表

| 参数 | 值 | 来源 | 说明 |
|---|---:|---|---|
| 模数 m | 2.5 | `standard` | 标准模数系列取值 |
| 齿数 z | 24 | `assumed` | 示意取值，保证传动比接近常见小齿轮 |
| 压力角 α | 20° | `standard` | 标准压力角 |
| 分度圆直径 d | 60.0 | `derived` | `m·z` |
| 齿顶圆直径 da | 65.0 | `derived` | `m(z+2)` |
| 齿根圆直径 df | 53.75 | `derived` | `m(z−2.5)` |
| 基圆直径 db | 56.382 | `derived` | `d·cos20°` |
| 齿宽 b | 12.0 | `assumed` | 常规比例 |
| 轮毂外径 × 宽 | φ36 × 20 | `assumed` | 轮毂宽于齿宽，形成台阶 |
| 中心孔 | φ20 | `assumed` | 与轮毂匹配 |

包围盒因此是 `65 × 65 × 20`：径向由齿顶圆决定，轴向由轮毂宽度决定，而不是齿宽 12。

## 6. 已知偏差与限制

1. **尺寸不构成完整尺寸链**：只保留了 4 个主参数（φ20、φ36、20、12）；齿形参数、齿宽和齿顶圆等未标注，不能直接按此图加工。
2. **没有齿轮参数表**：未生成模数/齿数/压力角表，也没有分度圆中心线。
3. **齿根是尖角**：未做齿根过渡圆角，不能直接用于强度分析或加工。
4. **未做变位、侧隙、公差、材料与强度校核**：这是示意图，不是可制造齿轮。
5. 齿形是**采样折线**（432 段），放大到极高倍率会看到分段；对示意和常规工程图足够，对滚齿仿真不够。

## 7. 复现

先复制整个目录到工作区，再执行：

```powershell
cd 01-spur-gear

# 1) 建模型（会新建 spur_gear_Z24_M2.5.SLDPRT，写入 evidence 和 previews）
py -3.12 build_spur_gear.py

# 2) 给轮毂草图补真实尺寸
py -3.12 add_gear_dims.py spur_gear_Z24_M2.5.SLDPRT spur_gear_Z24_M2.5_dim.SLDPRT

# 3) 出 A3 第一角三视图（<skill> 换成技能根目录）
py -3.12 "<skill>\scripts\sw_three_view.py" --part spur_gear_Z24_M2.5_dim.SLDPRT `
  --out-dir drawing --paper A3 --projection first --dims
```

脚本会自动发现技能目录（环境变量 `SOLIDWORKS_PLUS_PLUS_SKILL_DIR` → 发布包同级 → `~/.claude/skills` 等）。COM 写操作必须串行，运行期间不要手动操作同一文档。

## 8. 备注

- `build_spur_gear.py` 的输出文件名会自动避让：目录里已有 `spur_gear_Z24_M2.5.SLDPRT` 时会生成 `_2` 后缀，不会覆盖。
- `add_gear_dims.py` 的第二个参数是输出文件；如果同名文件已存在，SolidWorks 会覆盖保存。
- 原始任务目录为 `spur_gear_demo_20261024`，本包只保留了主建造脚本、带尺寸模型、四视图、证据和最终工程图。
