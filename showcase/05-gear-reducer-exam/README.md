# 05 · XXJSQ 减速器（考试题：零件 + 装配 + 上色 + 装配图）

> 模式 B（精确）· 工程图/装配图 → 三维模型 → 装配图
> 生成模型：DeepSeek V4 系列（低成本档位）
> 规模：10 个零件 + 3 套装配（每套 9 个组件）+ 3 张工程图

## 1. 任务

输入是一份减速器试卷（`inputs/试卷.pdf`）和从试卷里裁出的零件图截图。要求按图建出全部零件、装成减速器、出爆炸图和透明涂色图，并输出装配图与两张零件图。

试卷本身有缺失：**XXJSQ-001 连接法兰、XXJSQ-005 挡板只有明细栏条目，没有零件图**。本包按“能建的全建”，缺图的两件在装配图说明栏里写明缺失，没有凭空补画。

## 5. 装配与上色

### 5.1 装配

9 个组件全部用 `IComponent2.Transform2.ArrayData` 定位（列主序旋转 + 米制平移），不用配合：

| 组件 | 放置 |
|---|---|
| 006 下盖 | z=0（基准） |
| 010 上盖 | z=112.3 |
| 唇形密封圈 | z=10 |
| 009 齿圈 | z=20 |
| 008 齿轮 | (37.5, 0, 20) |
| 007 传动轴 | 绕 Y 转 90°，(37.5, 0, 15) |
| 004 固定轴 | 绕 Y 转 90°，(−37.5, 0, 20) |
| 003 垫块 | 绕 Y 转 90°，(−37.5, 0, 77) |
| 002 旋转套 | z=130 |

零件都按世界系建模，位置表就是全部装配定义。这套装配是静态展示件，没有运动要求，所以不用配合、也不用运动算例。

### 5.2 透明涂色

`colorize_assembly.py` **先复制** `XXJSQ_减速器.SLDASM` 为 `XXJSQ_减速器_透明涂色.SLDASM`，再在副本上按组件级别上色；原件不改。

| 零件 | 颜色 | 透明度 |
|---|---|---|
| 下盖 / 上盖 | 冷灰 / 暖灰 | 0.82 / 0.82 |
| 旋转套 | 蓝 | 0.35 |
| 齿圈 | 金 | 0.10 |
| 齿轮 / 传动轴 / 固定轴 / 垫块 | 红 / 绿 / 紫 / 青 | 0（不透明） |
| 密封圈 | 近黑 | 0.40（橡胶感） |

红色齿轮、绿色传动轴透过半透明壳体一眼可见；齿圈只降到 0.10，保留金黄色的环状轮廓。

`check_all.py` 对每个组件回读 `MaterialPropertyValues`，容差 0.02：

```json
{"上盖": 0.82, "下盖": 0.82, "旋转套": 0.35, "齿圈": 0.10}
```

## 7. 干涉分类（不是“忽略干涉”）

汇总报告里 `compact_interference_ok = true` 的含义是：**没有未登记组合、没有超上限项**。判定逻辑在 `check_all.py` 的 `DOCUMENTED_INTERFERENCE` + `classify_interference()`：

| 组合 | 体积上限 | 实测 | 原因 |
|---|---|---|---|
| 密封圈 ↔ 齿圈 | 1700 | 1608.5 | 唇口过盈压在齿圈外圆：唇形密封必须径向过盈才能封油，属于设计过盈 |
| 上盖 ↔ 旋转套 | 700 | 659.4 | 试卷图两件长度冲突：上盖中心凸台伸进旋转套实心端面 |
| 齿圈 ↔ 齿轮 | 100 × 7 处 | 79.7 / 69.1 / 69.1 / 38.0 / 38.0 / 0.55 / 0.55 | 零侧隙内啮合，齿面数值重叠；量产需加 0.06 mm 侧隙 |
| 齿圈 ↔ 固定轴 | 40 × 3 处 | 33.6 / 24.3 / 24.3 | 试卷图固定轴头 R20 超出齿圈齿顶圆 2.5 mm |

出现**任何新组合**或**旧组合超过上限**，检查立即失败。这样既不用假数据掩盖试卷图冲突，也不会让真正的新干涉混过去。

## 8. 真实修正记录

1. **侧窗 61 个碎实体**（2026-10-25）：旋转套侧窗最初用 60 段折线近似圆弧，SolidWorks 把每根弦切成独立薄片，宗量回读 **61 个实体**。改成“两段真圆弧 + 两条径向线”的单一闭合轮廓后恢复 **1 个实体**。结论：圆弧轮廓必须用 `CreateArc`，折线近似会碎体。
2. **SW2023 上色静默失效**：装配体还在解析时给前几个组件设的颜色会被丢掉，回读仍是零件原色。`colorize_assembly.py` 先设一轮、回读比对，失败的组件在 `ForceRebuild3` 后**重新取组件再设一次**（`apply_colours` → `retry` 分支），仍然失败就 `SystemExit`，绝不静默交付错色。
3. **零侧隙与试卷图冲突**：按图建的齿轮副没有侧隙，齿面数值重叠约 70 mm³；上盖/固定轴与相邻件也有试卷图自带的尺寸冲突。处理方式是**保留图纸尺寸 + 登记干涉上限**，而不是改尺寸让报告变绿。
4. **爆炸图/透明图不覆盖原件**：两个脚本都先 `shutil.copy2` 再打开副本，原件 SHA-256 不变——这是技能“交付透明版必须先复制”的硬规则。
5. **装配图明细栏**：001/005 没有零件图，明细栏对应行保留占位并在图上写明“原始资料缺失，本次未建模、未装配”。

## 9. 已知偏差与限制

1. **XXJSQ-001 连接法兰、XXJSQ-005 挡板缺失**：试卷只有明细条目，没有零件图；未建模、未装配，装配图为 9 个组件而不是明细栏的 11 项。
2. **装配是静态展示**：没有配合、没有运动算例；组件位置由变换矩阵固定。
3. **齿面为零侧隙理论轮廓**：没有修形、没有侧隙，不能直接用于加工；量产需按 0.06 mm 侧隙重新生成齿廓。
4. **零件图为尺寸驱动出图**：两张零件图的标题栏“图样名称/代号”是模板占位，没有填企业图号。
5. **没有材料与热处理**：模型只保证几何，未赋材质、未做强度校核。
6. **上色只到组件级**：透明图按组件设颜色，不区分同一零件的不同面。

## 11. 备注

- 预览统一为 PNG（SolidWorks 原生 `SaveBMP` 先写 BMP，PIL 转 PNG 后删 BMP）。建造过程中产生的 `_asm_*.bmp/jpg` 是临时文件，已从交付目录删除。
- 零件脚本里的 `*_preview.png` 参数会被 `save_preview()` 自动改成 `.bmp` 输出，这是 SW2023 `SaveBMP` 的格式限制，不是路径写错。
- `check_all.py` 的干涉分类表是**本案例的图纸冲突登记**，不是通用白名单；换一个装配必须重新评估，不能照抄。
