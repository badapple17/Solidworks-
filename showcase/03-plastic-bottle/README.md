# 03 · 百岁山风格 PET 水瓶（约 570 ml）

> 模式 A（示意）· 尺寸由用户授权自定（`user_delegated`）
> 生成模型：DeepSeek V4 系列（低成本档位）

## 1. 任务

用户只给了文字需求：做一瓶“百岁山风格”的塑料矿泉水瓶，没有给容量、直径、高度，也没有给瓶盖或标签。

技能判定为 **A 示意模式**，并把尺寸处理为**设计自由度**：不追问具体数值，但结构约束（壁厚、颈/口尺寸、肩部相切、容量）必须写清，并在交付说明里注明哪些值是自定的。

## 3. 建模思路

水瓶是**闭合薄壁回转体**，因此不用“实体 + 抽壳”，而是把外轮廓和内腔**一次旋转成形**：

```text
Front Plane 剖面（外轮廓 → 瓶口顶面 → 内轮廓 → 瓶底闭合）
  → 绕轴旋转 360°（唯一实体特征）
```

这样做的好处：

- 壁厚由内外轮廓的间距直接保证，不需要抽壳，也不会在肩部出现抽壳失败；
- 颈环、示意螺纹棱、标签浅槽全部并入主轮廓，特征树干净；
- 肩部用**两段相切圆弧**：凸弧与直筒竖直相切、凹弧与颈部竖直相切、两弧在拐点外切（G1 连续）。这避免了“折线密采样”在模型表面留下几十道棱边，也让体积可以用解析式精确验证。

轮廓细节：

- 瓶底是简单凹底：中心上凹 8 mm，外圈支撑环落地；
- 瓶身有一段深 0.3 mm 的标签浅槽（`y = 48–120`）；
- 颈部有防盗环（支撑环）和 3 道示意螺纹棱（梯形截面，高 0.8、宽 2.2），**不是真实螺旋牙**；
- 瓶口有凸缘和顶部倒角，不含瓶盖。

## 5. 验证证据

| 门禁 | 结果 |
|---|---|
| 实体数 | 1 |
| 包围盒 | `66.0 × 235.0 × 66.0 mm` |
| 实体特征 | 1 个旋转（特征树共 20 项，含默认文件夹） |
| 解析材料体积 | `51,381.777 mm³`（Pappus） |
| 实测材料体积 | `51,381.767 mm³` |
| 体积相对误差 | 约 `0.00002%` |
| 满口容量 | `568.4 ml` |
| 关键圆柱面 | φ66（瓶身）、φ64.4/63.8（内腔）、φ26/27.6（颈与螺纹棱）、φ30.8（防盗环）、φ21.8（瓶口内径）均存在 |
| 审查 | `pass`，100 分 |

> 体积不是“看起来差不多”：剖面由直线 + 4 段圆弧组成，`bottle_geom.py` 用 Pappus 定理 `V = 2π·x̄·A` 对圆弧细分离散，先算出解析期望值，再和 SolidWorks 的 B-Rep 实测值对比。两者差 0.01 mm³，说明轮廓没有画错、旋转没有缺段。

## 6. 已知偏差与限制

1. **没有瓶盖**，瓶口螺纹是 3 道环棱，不能与真实瓶盖旋合。
2. **瓶底是简单凹底**，不是真实 PET 瓶的耐压花瓣底；不能用于吹瓶工艺或压力仿真。
3. **壁厚 0.8 mm 是示意值**，比真实 PET 瓶偏厚；材料体积 51.4 ml 不代表真实克重。
4. **没有标签、印刷、防滑纹**；标签位置只有一条浅槽。
5. **没有材料牌号、收缩率、吹塑工艺、跌落/耐压校核**。
6. 防盗环与瓶口是同一实体，不是可断裂的独立环。
7. 尺寸全部为设计自由度，不对应任何现有产品；如果要复刻真实瓶型，需要按 B 模式逐项确认尺寸。

## 7. 复现

先复制整个目录到工作区，再执行：

```powershell
cd 03-plastic-bottle

# 只看设计参数与解析体积，不启动 SolidWorks
py -3.12 build_bottle.py --dry

# 真机建模 + 四视图审查
py -3.12 build_bottle.py
```

脚本用 `Path(__file__).parent` 作为输出目录，模型与 `previews/` 会写回脚本所在目录；在包内直接跑会覆盖随包交付的成果。
