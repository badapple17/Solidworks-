# 04 · 折叠手机支架（照片反求）

> 模式 A（示意）· 照片 → 模型
> 生成模型：DeepSeek V4 系列（低成本档位）
> 规模：8 个零件 + 2 个姿态装配

## 1. 任务

用户给了 15 张实物照片，要求按照片做一个可折叠的手机支架，尺寸不要求精确，但要能看出结构、能摆出展开和收拢两个姿态。

这是四个实例里唯一**以照片为输入**的案例。技能按 A 模式处理：

- 照片能读出的结构 → 建模；
- 照片读不出的关键尺寸 → 先估读，再向用户确认；
- 用户明确指定的（螺钉数量/布局、手机型号）→ 按用户值，不按照片猜。

## 2. 输入照片分析

15 张照片先用接触表（`input_photos/contact.png`）筛选，按“能看清结构 + 能读出尺寸关系”选出 3 张，再各做半幅裁切放大：

| 文件 | 作用 |
|---|---|
| `38ad4e06_top_view.jpg` | 俯视：底座圆形轮廓、转盘偏置、托钩位置 |
| `446d968c_side_detail.jpg` | 侧面：臂厚、背板角度、铰链位置 |
| `8fa3569d_folded_detail.jpg` | 收拢态：托钩翻转关系、背板与臂的贴合方式 |
| `*_half.png` | 对应照片的半幅裁切，便于读局部 |
| `contact.png` | 15 张照片的接触表（筛选依据） |

关键判断：

- 底座直径按俯视图标尺实测约 **10.3 cm**，原估 Ø110 偏大，修正为 **Ø104**。
- 转盘上的 U 型座**不在转盘圆心**，而是骑在转盘边缘：销轴中心径向偏置 **22 mm**；U 座底板外伸到转盘边缘外 7 mm，从底座顶面上方掠过（间隙 2.2 mm）。
- 螺钉数量/布局照片看不清，用户明确指定：**3 颗绕圆心 120° 均布，落在 3 个脚垫之间**，不留通孔。
- 手机型号由用户告知：OPPO Reno 14，按厂商标称三围 `157.9 × 74.73 × 7.42 mm` 建参考件。

## 4. 零件参数

| 零件 | 关键尺寸（mm） |
|---|---|
| 01 底座 | Ø104 × 10；中心沉槽 Ø50 × 2.6；3 条弧形脚垫（外 R46.5 / 内 R39 / 厚 1.2，30°/150°/270°）；3 颗十字螺钉（PCD R12，90°/210°/330°，与脚垫错开） |
| 02 转盘 | 盘 Ø48 × 4.2，凸台 Ø40 × 0.6；U 座底板 26 × 18 × 6；双耳内距 8.5；销孔 Ø4.2；销轴中心 `(0, −22, 18)` |
| 03 立柱臂 | 截面 26 × 6；下端舌片宽 8.5、深 14；上端叉口间隙 4；上销孔中心 `z = 92`；杆身 6 mm 长圆孔 |
| 04 下销轴 | Ø4 × 18.5，两端 Ø7 × 1.2 头，总宽 20.9 |
| 05 上销轴 | Ø4 × 26，平头 |
| 06 背板 | 宽 96，高 109.5（`z=14.5–124`），厚 3，顶部 R14；3 条长圆槽 + 1 个梯形减重窗；底部 Ø5 卷边 |
| 07 托钩 | C 形抱箍包角 240°，内孔 R2.55 配 Ø5 卷边，外径 R3.4；托板 + 前挡边 + 硅胶垫；中心到板中心 27 |
| 08 手机 | 157.9 × 74.73 × 7.42，四角 R10（参考件） |

配合关系（展开位 18 个 / 收拢位 15 个，全部写入特征树）：

| 组 | 配合 | 作用 |
|---|---|---|
| 底座 | `FixComponent()` | 固定整台支架；`AddComponent5` 插入的第一个件默认**不是**固定件 |
| 转盘 | 同心 Ø48/Ø50 + 座面重合 | 只留绕 Z 转动 |
| 下销 | 同心 + 销头内侧面重合 M04 | 只留绕 X 转动，不许沿 X 窜 |
| 立柱臂 | 同心 + 侧面重合 M06 | 只留绕 X 转动 |
| 上销 | 同心 + 端面重合 M08 | 只留绕 X 转动 |
| 背板 | 同心 + 凸舌侧面重合 M10 | 只留绕 X 转动，不许沿销滑出 |
| 托钩 ×2 | 同心 + 距背板侧面 10 mm M12 | 只留绕卷边转，不许横向滑出 |
| 两钩同步 | 胶垫顶面重合 M16 | 左钩跟随右钩，摆姿态只给右钩加角度 |
| 手机（仅展开位） | 背面贴板 + 底面贴钩 + 右视基准面重合 M15 | 参考件，同时锁住最后 X 向平移 |

- 每个转动件只留**一个绕铰链轴**的转动自由度，其余自由度全部用定位配合消掉；
- 销轴 Ø4 在 Ø4.2 孔内留 **0.1 mm 间隙**，不会与其它零件融合；
- 姿态用**临时角度配合**驱动，摆好后删除配合，姿态保留；
- 收拢位不能用“垂直参考面 + 90°”（会求解到另一分支，背板压到臂上，干涉 11 处），改用“平行参考面 + 0°”，解唯一。

> **装配体几何测量的边界**：`run_review()` 对装配体调用 `GetPartBox` / `GetBodies2` 会失败（报告 `cad_spec.errors` 里有记录），所以装配级包围盒/体积不由审查报告给出。装配的几何正确性靠三件事保证：每个零件脚本自己的 `check()`、两姿态的**干涉检查**、以及预览图目视。这也是技能把“装配”列为 `pilot` 能力、要求人工审查的原因。

## 6. 设计过程中的修正（真实记录）

1. **背板凸舌**：原设计伸到 `z=18`，装进手机下沿 151 mm³；改为止于 `z=14.5`，与板体下缘共面。
2. **连接筋**：原 ±25 与托钩抱箍重叠；收到 ±15，离抱箍内端留 1 mm。
3. **托钩坐标系**：首版把背板坐标里的屏面 `Y=−4.42` 直接当成托钩坐标，挡边切进手机 150 mm³；零件自身的体积/包围盒校验发现不了，**装配干涉检查**才查出来。修正后挡边与屏面留 0.58 mm。
4. **收拢姿态**：用“垂直参考面 + 90°”时求解器把背板折回压到臂上（干涉 11 处）；改用“平行参考面 + 0°”后唯一解，干涉归零。
5. **手动运动轨迹错误**（交付后由用户发现，2026-10-25 修复）：现象是拖动任何零件，整台支架平移、部分零件沿铰链轴窜出；顶部关节还能左右平移而不是只前后转。自由度探针复现：底座 `IsFixed=False`；下销、上销、背板、双钩、手机各有 10 mm 的 X 向窜动。修复为“固定底座 + 7 个轴向定位配合”：M04 下销、M08 上销、M10 背板、M12 左右钩距离配合、M15 手机中心面、M16 双钩同步。重建后所有非底座零件三向强推位移归零，98°→88° 角度驱动的 X 漂移为 0；再补一条**铰链转轴探针**，证明上/下关节都只绕 X 转（实转 5.000°、轴 (1,0,0)、原点漂移 0.000 mm）。**这个问题零件脚本和干涉检查都发现不了，只有运动学探针能抓到。**
6. **探针本身的两次假信号**（2026-10-25）：①用「推移旋转」（`SetTransformAndSolve2` 直接改旋转）测转动自由度，SW2023 会把整块旋转退回，plate/turntable/hook 全读成 0°，而它们其实能转——**推移只能测平移约束，测转动必须用临时角度配合驱动**；②重建后继续用之前取到的 `IFace2` 会报「被调用的对象已与其客户端断开连接」，**每次加配合前必须重新取面**。

这六条都写进了脚本注释，是“门禁真的拦住了错误”而不是“一次就画对”的证据。

## 7. 已知偏差与限制

1. **照片反求只保证拓扑与比例**，不保证尺寸；底座 Ø104、转盘偏置 22、臂长等都是从照片估读 + 用户确认的结果。
2. **手机是参考件**：尺寸用厂商标称值（`estimated`），没有摄像头凸起、按键、曲面背板。
3. **没有弹簧、阻尼、摩擦片**；铰链是“销轴 + 间隙配合”，不能保持任意角度，实际产品需要阻尼结构。
4. **没有材料、表面处理、强度校核**；托钩和背板是按示意厚度做的。
5. **两个姿态是两个独立装配文件**，不是配置或运动算例。单个装配内可以手动拖动臂/背板/托钩（底座固定、只保留转动自由度），但没有阻尼，松手不能停在任意角度；也不能在一个文件里保存两个姿态。运动学正确性由 `a04_motion_check.py` 验证。
6. 3 颗螺钉是用户指定布局，不是照片反求结果；螺钉头是简化十字槽。
7. 装配体不含爆炸图、BOM、工程图。

## 8. 复现

先复制整个目录到工作区，再按顺序执行（`p04_pins.py` 会同时生成 04/05 两个销轴，没有单独的 p05）：

```powershell
cd 04-phone-stand

py -3.12 p01_base.py
py -3.12 p02_turntable.py
py -3.12 p03_arm.py
py -3.12 p04_pins.py
py -3.12 p06_plate.py
py -3.12 p07_hook.py
py -3.12 p08_phone.py

# 两个姿态（每次都会重建并保存对应 SLDASM）
py -3.12 a01_build.py deployed
py -3.12 a01_build.py folded

# 干涉检查 + 两姿态审查 + PNG 预览
py -3.12 a03_check.py

# 运动学探针（不保存交付文件）
py -3.12 a04_motion_check.py
```

所有零件写入 `deliverables/`，预览与审查写入 `previews/`。脚本结束时会 `CloseAllDocuments(True)` 卸载引用零件，避免下一次保存报错误码 1。
