# 02 · 汽车轮毂（前后双面 5 辐）

> 模式 A（示意）· 文字需求
> 生成模型：DeepSeek V4 系列（低成本档位）
> 版本：v3（用户反馈后重建的前后对称双面结构）

## 1. 任务与迭代

用户提出用文字描述一个汽车轮毂：5 辐、有轮辋、中心孔和螺栓孔，尺寸不指定，先看形状。

- **v1 / v2**：按单面轮辐建模——正面有辐条和轮辐板，背面是空的。
- **用户反馈**：“轮子只有一面，另一边是空的。”
- **v3**：这不是加装饰能修的，属于拓扑改变。按 G2 过程门禁停下，重建为**前后对称双面结构**：轮辋前后各一套轮辐板与轮毂，辐窗、中心孔、螺栓孔贯穿切除时自然同时切穿两面。

本包只保留 v3 的建造与验证脚本；v1/v2 的方向错误记录在这里，作为“用户反馈改变拓扑”的实例。

## 3. 建模思路

```text
Right Plane 半剖轮廓 + 中心线
  → 绕 Z 轴旋转 360°
     （轮辋 + 前后轮辐板 + 前后轮毂一次成形）
  → 5 个梯形辐窗贯穿切除
     （同时切穿前后轮辐板，窗间材料形成前后各 5 根辐条）
  → φ70.5 中心孔贯穿前后轮毂
  → 5×φ14 螺栓孔，PCD 114.3，前后贯通，与辐条中心对齐
  → 顶部径向 φ11.5 气门嘴孔
  → 隐藏临时偏置面 Plane_Valve
```

关键点：

- 用**一个半剖旋转**同时做出前后两面，避免“先建一半再镜像”带来的接缝和特征翻倍。
- 辐窗是“切穿两面板”的通窗，不是各切一刀；这样前后辐条天然对齐。
- 螺栓孔与辐条中心对齐，PCD 半径 57.15 mm。
- 气门嘴孔是径向孔，位于 `z = −80`，用临时偏置面定位，完成后隐藏该面。

## 6. 已知偏差与限制

1. **全部尺寸为示意取值**（`assumed`），不对应任何真实车型或轮辋标准（如 17×7.5J）。
2. **没有轮胎**，也没有胎圈座/轮缘的详细曲线；轮辋与轮胎的配合面未按标准建模。
3. **没有螺栓、螺母、气门嘴零件**，孔是光孔。
4. **没有圆角/倒角**：辐窗边缘、轮辋边缘均为尖角，不能直接铸造或锻造。
5. **没有材料、强度、疲劳、动平衡校核**；7.8 L 材料体积只是几何结果，不代表可制造重量。
6. 单实体：轮辋与轮辐不是可拆分零件，不能直接用于装配 BOM。
7. 气门嘴孔位置是设计选择，不是从真实轮毂反求。

## 7. 复现

先复制整个目录到工作区，再执行：

```powershell
cd 02-car-wheel

# 1) 建模型 + 导出 STEP + 生成六视图和审查报告
py -3.12 build_car_wheel_v3.py

# 2) 重新打开模型复测，写回参数表与 verify.json
py -3.12 verify_car_wheel_v3.py
```

两个脚本都从**当前工作目录**读写 `car_wheel_v3.SLDPRT`、`previews/` 和参数表；在包内直接跑会覆盖随包交付的成果。
