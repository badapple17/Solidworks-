# 训练与验收用例

可执行用例清单在技能根目录的 [`test-prompts.json`](../../test-prompts.json)。

| ID | 路线 | 通过证据 |
|---|---|---|
| `d2p_b_link_001` | 图 → 模型 | 包围盒 `67.37778 × 38.107013 × 10.0` mm，1 实体，φ15/φ8 贯穿 |
| `d2p_b_plate_holes` | 图 → 模型 | 包围盒 `120 × 80 × 12`，6 个圆柱面，体积 `99794.337 mm³` |

| `d2p_a_ambiguous_object` | 图 → 模型 | 对象不清时先问清对象和拓扑，再按 A 模式估尺寸 |

## 用例来源

- 64 题库 `001`：三视图 + 答案 SLDPRT，已做完整尺寸复建。
- 40 题库：105 个答案零件，用于特征树统计与配方顺序。
- 合成用例：板件、台阶轴、图幅切换、缺尺寸提问。

## 运行方式

1. 按 `SKILL.md` 判定路线与模式。
2. 只读该路线文档 + `references/quick-snippets.md`（低成本模型约束）。
3. 按用例 `expected` 字段逐项核对；失败信号出现即返工。
4. 真机脚本串行执行，不要并发打开 SolidWorks。

题库原始文件在临时目录，不随技能交付；`dataset_ref` 仅用于追溯。
