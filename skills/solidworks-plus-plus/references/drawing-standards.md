# GB 工程图规范（读图与出图共用）

适用：模式 B（精确模式）的读图、建模后的出图、交付前审查。
示意模式只执行第 1、2 节；第 8 节只检查视图/比例，不检查公差与粗糙度。精确模式全执行。
出图命令和 API 见 `part-to-drawing.md` / `drawing.md`；本文件只讲“图上必须有什么、为什么”。

> **能力边界（2026-10-24）**：`sw_three_view.py` 目前只自动插入模型尺寸、
> 创建视图、设图幅、导出 PDF；**公差、配合代号、Ra、形位公差、技术要求
> 和标题栏字段仍需按本文件人工补**。不要对用户声称“脚本已自动标注公差/粗糙度”。

## 1. 一张合格零件图的六件套

缺任何一项都不是可交付图纸：

| # | 内容 | 检查点 |
|---|---|---|
| 1 | 一组视图 | 主视图 + 必要视图，能唯一确定形体；第一角布局 |
| 2 | 全部定形尺寸 | 每个特征的长、宽、直径、半径、角度都有且只标一次 |
| 3 | 全部定位尺寸 | 孔距、边距、中心高、角度定位；与设计基准连成尺寸链 |
| 4 | 公差与配合 | 有配合/功能的尺寸标极限偏差或配合代号；其余按未注公差 |
| 5 | 表面粗糙度 | 每个加工面有 Ra 要求；统一要求可写在右上角 |
| 6 | 技术要求 + 标题栏 | 材料、热处理、未注圆角/倒角、去毛刺、表面处理 |

**判定规则**：图上任何一个尺寸，如果加工者需要回问“这里多少”，就是漏标；
任何一个尺寸如果标了两遍，就是过约束。两种情况都要返工。

## 2. 视图选择（先定主视图，再定其他）

### 2.1 主视图三原则

1. **形状特征原则**：主视图应最能反映零件的形状特征。
2. **加工位置原则**：轴、套、盘类按车削/磨削状态放主视图（轴线水平）。
3. **工作位置原则**：支架、箱体、壳体按装机位置放主视图。

三条冲突时，优先级：加工位置 > 工作位置 > 形状特征（回转件）。
非回转件：形状特征 > 工作位置。

### 2.2 视图数量

| 零件 | 最少视图 | 常加视图 |
|---|---|---|
| 等厚板 | 2（主视 + 俯视） | 局部剖、局部放大 |
| 阶梯轴 | 1（主视，轴线水平） | 键槽处断面图、退刀槽局部放大 |
| 法兰/盘 | 2（主视剖 + 左视） | 局部放大（密封槽） |
| 支架 | 3 | 局部剖（孔）、斜视图（斜面） |
| 箱体 | 3～4 | 多组剖视、局部放大 |

**不要为了凑视图数量加视图**。一个视图能表达清楚的，不加第二个。

> **交付口径**：GB 允许单视图（如光轴、等厚圆板），但本技能默认交付
> “主视 + 俯视 + 左视”三视图，自动门禁也要求视图数 ≥ 3。
> 确实只需单视图时，必须在任务卡写明理由并人工放行，不能把单视图
> 说成“已通过三视图门禁”。

### 2.3 剖视图选择

| 情况 | 用哪种 | 规则 |
|---|---|---|
| 内部结构全对称、外形简单 | 全剖 | 剖切平面通过对称面 |
| 内外都有结构、基本对称 | 半剖 | 以对称中心线为界，一半剖一半不剖 |
| 只需表达局部内部结构 | 局部剖 | 波浪线分界，波浪线不穿空、不与其他线重合 |
| 肋板、轮辐、薄壁 | 剖中不剖 | 沿纵向剖切时这些结构按不剖处理，用粗实线分界 |
| 回转体上的均布孔 | 旋转剖 | 两个相交剖切平面，交点在回转中心 |
| 多个不在同一平面的结构 | 阶梯剖 | 剖切符号的转折处用粗实线；剖视图内不画转折线 |
| 倾斜内部结构 | 斜剖 | 剖视图可旋转，标注“A-A 旋转” |

剖切符号：剖切线（粗短画）+ 箭头（投射方向）+ 大写字母；剖视图上方标 `A-A`。
**箭头方向决定视图方向，画反等于剖视方向反了。**

### 2.4 简化画法（GB/T 16675.1）

- 均布孔、肋、齿、槽：可只画一个，注明“n×”或“均布”。
- 相同结构有规律分布：可画一组，用细实线连对角线并注数量。
- 小倒角、小圆角：可省略不画，但在技术要求写“未注倒角 C1 / 未注圆角 R2”。
- 长轴：可断开画，断开处用波浪线；标注仍按实际长度。
- 平面：可在平面上画细实线对角线（表达“此面是平面”）。

## 3. 尺寸标注（GB/T 4458.4）

### 3.1 基准

| 基准类型 | 常见选择 | 建模对应 |
|---|---|---|
| 设计基准 | 底面、端面、对称面、孔轴线 | 原点放在设计基准上 |
| 工艺基准 | 加工面、装夹面 | 出图时优先从工艺基准标 |
| 测量基准 | 卡尺/三坐标能测到的面 | 避免标“到虚拟交点”的尺寸 |

**尺寸必须完整，但不得形成封闭尺寸链**：`总长 = Σ 分段长` 用来校验是否漏标；
标了总长就不要再把全部分段都标上（除非有工艺需要）。
首尾相接、一整圈没有开口的封闭尺寸链禁止。

### 3.2 标注方式

| 特征 | 标法 | 示例 |
|---|---|---|
| 圆孔 | 直径 + 数量 | `4×φ8`、`2×φ6 通` |
| 沉孔 | 沉孔符号 + 大径 + 深度 + 小径 | `⌴φ11 深6 4×φ6.6 通` |
| 沉头孔 | 沉头符号 + 大径 + 角度 | `⌵φ12×90° 4×φ6.6 通` |
| 螺纹孔 | M + 规格 + 深度 | `M8-6H 深20` |
| 外螺纹 | M + 规格 + 长度 | `M20×1.5-6g` |
| 半径 | R + 数值 | `R5`；球面写 `SR5` |
| 倒角 | C + 数值 或 角度×长度 | `C1`、`2×45°` |
| 键槽 | 宽 + 深 + 长度 | 轴槽 `10N9 深5`，毂槽 `10JS9 深3.3` |
| 中心距 | 直接标两孔中心 | `60±0.05` |
| 均布孔 | 数量 + 孔径 + 角度 | `6×φ8 均布` + `60°` |

**直径必须带 φ**，半径带 R，螺纹带 M，沉孔/沉头带符号。
**不要用“38 宽”代替“φ38”**，也不要把半径标成直径。

### 3.3 尺寸布置

> 基准、尺寸链、零件族配方、自动排版算法与已知限制，见 `dimension-layout.md`。本节只列交付前必查项。

- 尺寸尽量标在视图轮廓外；孔位尺寸标在反映孔分布的视图上。
- 第一根尺寸线距轮廓约 8 mm；平行尺寸线间距 5–8 mm 且大致相等。
- 大尺寸在外、小尺寸在内；同一层不得有两条区间重叠的尺寸线。
- 尺寸线单独画，与所标线段平行，不与其他线重合、不在其延长线上。
- 尺寸界线超出尺寸线终端约 2 mm；数字不得被任何图线穿过。
- 同一特征的尺寸集中标注，不分散到三个视图；每个尺寸只标一次。
- 数字：水平写在线上方；竖直写在左侧、字头向左；避免 ±30° 竖直区。

### 3.4 常见漏标清单（交付前逐项过）

- [ ] 总长/总宽/总高是否齐全
- [ ] 每个孔的直径、深度/通孔、数量、定位
- [ ] 每个圆角的 R、每个倒角的 C
- [ ] 键槽的宽、深、长度、定位
- [ ] 螺纹的规格、螺距（细牙）、旋向（左旋才标）
- [ ] 中心高、中心距、角度
- [ ] 配合面的公差/配合代号
- [ ] 表面粗糙度（每个加工面）
- [ ] 热处理、表面处理、材料
- [ ] 未注公差、未注圆角/倒角的说明

## 4. 公差与配合

### 4.1 公差等级选择

| 等级 | 加工方式 | 典型用途 |
|---|---|---|
| IT5～IT6 | 精磨、研磨 | 量规、精密轴承配合、精密机床主轴 |
| IT7 | 精车、精磨 | 一般配合孔/轴、齿轮孔、轴承座 |
| IT8 | 精车、铣 | 一般机械配合、定位面 |
| IT9 | 车、铣 | 非配合尺寸、一般结构尺寸 |
| IT10～IT11 | 粗车、钻孔 | 螺栓孔、非配合面 |
| IT12～IT14 | 粗加工 | 下料尺寸、非加工面 |

**默认规则**：有配合 → IT7（孔）/ IT6（轴）；无配合但有功能 → IT8～IT9；
无功能 → 不标公差，按 GB/T 1804-m。

### 4.2 配合选择（基孔制优先）

| 配合 | 性质 | 典型场景 | 装配方式 |
|---|---|---|---|
| H7/g6 | 间隙 | 滑动导向、定位销 | 手推可动 |
| H7/h6 | 间隙（最小 0） | 定位、可拆连接 | 手推/木锤 |
| H7/k6 | 过渡 | 齿轮、联轴器、带键连接 | 木锤/压入 |
| H7/n6 | 过渡（偏紧） | 轴承内圈、定位套 | 压入 |
| H7/p6 | 过盈 | 冲击载荷、不需拆卸 | 压力机/加热 |
| H7/r6 | 过盈（紧） | 重载、钢套 | 加热/压力机 |
| H7/f7 | 间隙（较大） | 一般滑动轴承 | 手推 |
| H8/f7 | 间隙 | 中等转速滑动轴承 | 手推 |
| H11/c11 | 间隙（大） | 粗糙运动件、农业机械 | 自由 |

**优先选基孔制（H）**；只有用冷拔钢材直接做轴时才用基轴制（h）。
**同一根轴上的多个配合，尽量用同一公差等级**，减少刀具和量具。

### 4.3 公差标注

- 孔：`φ30H7`；轴：`φ30g6`；非配合：`φ30`。
- 极限偏差：`φ30 +0.021/0`，上偏差写上方，下偏差写下方。
- 对称偏差：`φ30±0.01`。
- 角度公差：`45°±30′`。
- 未注公差：技术要求写 `未注线性尺寸公差按 GB/T 1804-m`。
- 未注形位公差：写 `未注形位公差按 GB/T 1184-K`。

常用极限偏差（μm，GB/T 1800.1）。H7 下偏差为 0，h6 上偏差为 0：

| 尺寸段 / mm | IT6 | IT7 | H7（+ / 0） | h6（0 / −） |
|---|---:|---:|---:|---:|
| ≤3 | 6 | 10 | +0.010 | −0.006 |
| >3～6 | 8 | 12 | +0.012 | −0.008 |
| >6～10 | 9 | 15 | +0.015 | −0.009 |
| >10～18 | 11 | 18 | +0.018 | −0.011 |
| >18～30 | 13 | 21 | +0.021 | −0.013 |
| >30～50 | 16 | 25 | +0.025 | −0.016 |
| >50～80 | 19 | 30 | +0.030 | −0.019 |
| >80～120 | 22 | 35 | +0.035 | −0.022 |
| >120～180 | 25 | 40 | +0.040 | −0.025 |
| >180～250 | 29 | 46 | +0.046 | −0.029 |
| >250～315 | 32 | 52 | +0.052 | −0.032 |
| >315～400 | 36 | 57 | +0.057 | −0.036 |
| >400～500 | 40 | 63 | +0.063 | −0.040 |

`H7/g6`、`H7/k6` 等其他配合的偏差不要用本表推算；
查 `基本偏差表` 或让用户给数值。本表只解决 H7/h6 两种最常用标注。

### 4.4 形位公差（GB/T 1182）

| 符号 | 名称 | 典型用途 |
|---|---|---|
| ⏤ | 直线度 | 导轨、轴线 |
| ▱ | 平面度 | 密封面、安装面 |
| ○ | 圆度 | 轴颈、活塞 |
| ⌭ | 圆柱度 | 精密轴颈、液压阀芯 |
| ∥ | 平行度 | 两平面、两轴线 |
| ⊥ | 垂直度 | 端面与轴线、安装面 |
| ∠ | 倾斜度 | 斜面 |
| ◎ | 同轴度 | 阶梯轴、轴承位 |
| ⌯ | 对称度 | 键槽、对称结构 |
| ⌖ | 位置度 | 孔组、螺栓孔 |
| ↗ | 圆跳动 | 回转件端面/外圆 |
| ⌰ | 全跳动 | 精密回转面 |

**选用原则**：能用位置度就不用尺寸公差链；能用面轮廓度就不用坐标尺寸堆叠。
基准优先选安装面、轴线、对称面；基准数量不超过 3 个。

## 5. 表面粗糙度（GB/T 1031 / GB/T 131）

### 5.1 Ra 优先系列（μm）

`0.012, 0.025, 0.05, 0.1, 0.2, 0.4, 0.8, 1.6, 3.2, 6.3, 12.5, 25, 50, 100`

只选优先系列，不要写 `Ra 1.5` 这种非标值。

### 5.2 按功能选

| 表面 | Ra（μm） | 加工 |
|---|---:|---|
| 密封面、O 形圈槽 | 0.4～0.8 | 精磨/研磨 |
| 轴承配合面、齿轮齿面 | 0.8～1.6 | 磨 |
| 一般配合面（H7/h6） | 1.6～3.2 | 精车/精铣 |
| 一般加工面、非配合面 | 3.2～6.3 | 车/铣 |
| 孔壁（钻、铰） | 3.2～6.3 | 钻/铰 |
| 非加工面（铸造、锻造） | 12.5～25 | 不加工 |
| 自由曲面、外观面 | 0.8～3.2 | 抛光/精铣 |

**规则**：配合精度越高，Ra 越小；但不要盲目全图标 0.8，加工成本会失控。
同一张图只保留 3～5 种 Ra 值。

### 5.3 标注

- 符号尖端指向加工面，从材料外指向内。
- 右上角统一标注：`其余 Ra 6.3`（或 `其余 ▷`）。
- 需要去除材料写 `▽`（旧符号）或新符号带横线；不去除材料写 `⌒`。
- 同一表面只标一次；重复表面可写“其余”。

## 6. 标准结构的画法

### 6.1 螺纹（GB/T 4459.1）

| 类型 | 大径 | 小径 | 终止线 |
|---|---|---|---|
| 外螺纹 | 粗实线 | 细实线（画到倒角内） | 粗实线 |
| 内螺纹（剖） | 细实线 | 粗实线 | 粗实线 |
| 内螺纹（不剖） | 细实线（虚线大径） | 粗实线 | 粗实线 |
| 螺纹连接（剖） | 按外螺纹画，旋合段按外螺纹 | — | — |

- 螺纹牙型不按真实比例画，用细实线表示小径/大径。
- 需要表示牙型时用局部放大图，标注螺距、牙型角。
- 左旋螺纹标 `LH`；细牙标螺距 `M20×1.5`。
- 螺纹盲孔：孔底画 120° 钻尖，螺纹终止线到孔底留 2～3 倍螺距。

### 6.2 齿轮（GB/T 4459.2）

| 圆 | 线型 | 说明 |
|---|---|---|
| 齿顶圆 | 粗实线 | 可见 |
| 分度圆 | 细点划线 | 必须画 |
| 齿根圆 | 细实线（剖）或省略（视） | 可见时细实线 |
| 基圆 | 细点划线 | 必要时画 |

- 单个齿轮：主视图画剖视，左视图画分度圆（点划线）+ 齿顶圆。
- 啮合图：节圆用点划线相切，齿顶圆一粗一细（可见/不可见）。
- 参数表放在右上角：模数 m、齿数 z、压力角 α、精度等级、变位系数、跨齿数/公法线。
- 齿面粗糙度标在分度圆附近，不逐个齿标。

### 6.3 键与键槽（尺寸 GB/T 1095/1096；画法按 GB/T 4458.1）

- 轴上的键槽：主视图画局部剖，断面图画键槽宽、深。
- 毂上的键槽：剖视图画通槽，标 `b×t1`。
- 键本身：按 GB/T 1096 画长方体，两端 A 型圆头 / B 型平头 / C 型单圆头。
- 键槽尺寸标法：`10N9`（宽）+ `5`（轴槽深 t）或 `3.3`（毂槽深 t1）。
- 键槽长度按键长 L 标，不标到圆头中心。

### 6.4 滚动轴承（GB/T 4459.7）

- 简化画法：外圈、内圈画矩形，滚动体画圆/球，不画保持架。
- 剖视图：两半圈用粗实线，滚动体用细实线，剖面线方向相反。
- 规定画法：只画一半，另一半画简化线；同一轴上多个轴承只详细画一个。
- 标注：轴承代号写在引出线上，如 `6204 GB/T 276`。
- 轴承内外圈与轴/孔的配合：内圈随轴转（H7/k6 或 H7/n6），外圈固定（H7/g6 或 H7/h6）。

### 6.5 弹簧（GB/T 4459.4）

- 压缩弹簧：主视图画全剖或半剖，有效圈数用 `n`，支承圈数用 `n2`。
- 左视图只画最大外径圆和簧丝圆。
- 参数表：簧丝直径 d、中径 D、自由高度 H0、有效圈数 n、总圈数 n1、旋向、刚度。
- 右旋不标，左旋标 `LH`。
- 弹簧画法可只画 2～3 圈，用波浪线断开，标注实际圈数。

## 7. 技术要求（模板，按需删减）

写在标题栏上方，从左到右、从上到下编号：

```text
技术要求
1. 材料：45 钢，调质处理 220～250 HBW。
2. 未注线性尺寸公差按 GB/T 1804-m。
3. 未注形位公差按 GB/T 1184-K。
4. 未注圆角 R2～R3，未注倒角 C1。
5. 去毛刺、锐边倒钝。
6. 表面处理：发黑处理（或按图样指定）。
7. 未注表面粗糙度 Ra 6.3。
```

常用替换项：

- 铸件：`铸件不得有砂眼、气孔、裂纹；时效处理`。
- 焊接件：`焊后消除应力；焊缝质量按 GB/T 19418`。
- 热处理：调质、正火、淬火+回火、渗碳淬火、氮化；写硬度范围。
- 表面处理：发黑、镀锌、镀铬、阳极氧化、喷砂、喷塑。
- 齿轮：`齿面硬度 45～50 HRC；精度 7 级 GB/T 10095.1`。

**不要写空的“按国家标准”**，要写具体标准号和等级。

## 8. 出图前自检（模式 B 必过）

| # | 检查 | 失败处理 |
|---|---|---|
| 1 | 视图数量足够唯一确定形体 | 加剖视/局部视图，不得靠轴测图代替 |
| 2 | 第一角布局（俯视在下、左视在右） | 改 `--projection first` 重出 |
| 3 | 长对正、高平齐、宽相等 | 调整视图位置，重出 |
| 4 | 每个特征有定形 + 定位尺寸 | 回模型补草图尺寸，重新插入 |
| 5 | 尺寸不重叠、不穿标题栏 | 调整视图比例/位置 |
| 6 | 有配合的尺寸有公差/配合代号 | 补标；无法确定时列问题问用户 |
| 7 | 每个加工面有 Ra | 补右上角统一标注或逐面标注 |
| 8 | 技术要求完整 | 按第 7 节模板补 |
| 9 | 标题栏材料/名称/图号/比例/日期 | 手工补或改图纸格式 |
| 10 | PDF 首屏目视无空白、无裁切 | 重出并渲染检查 |

**红线**：以下任一情况禁止交付——

- 按三视图交付时视图数 < 3（单视图特例必须已在任务卡声明并人工放行）；
- 尺寸数为 0；
- 用第三角布局交国内加工图；
- 预览空白或视图在纸外；
- 尺寸与模型回读值不一致（以模型为准，先改模型或改标注，不能两头不一致）。

## 9. 读图时的反查（图 → 模型）

拿到一张现成工程图时，用同一套规则反查，能提前发现图纸本身的问题：

1. 视图是否满足第一角？投影关系是否对得上？
2. 尺寸链是否闭合？有没有漏标/重复/封闭链？
3. 剖视图的剖切位置是否明确？A-A 标记是否对应？
4. 配合代号与公差数值是否自洽？（H7 的偏差值是否写对）
5. 粗糙度符号是否指向加工面？有没有标在非加工面上？
6. 标题栏材料与技术要求是否矛盾？（如 45 钢却写“铸件”）
7. 发现图纸矛盾时：**不要自行选一个值继续建**。在模式 B 下列入问题清单，
   最多问 4 个，每个带推荐值和影响；模式 A 按最合理值建并标 `assumed`。

## 10. 常见错误（出现即返工）

- ❌ 主视图选了信息量最少的那个方向。
- ❌ 轴类零件竖着画（应轴线水平，符合车削加工位置）。
- ❌ 剖视图箭头方向与视图方向相反。
- ❌ 半剖的分界线不是对称中心线。
- ❌ 肋板纵向剖切时画了剖面线（应不剖）。
- ❌ 尺寸标在虚线上，或尺寸线穿过尺寸数字。
- ❌ 封闭尺寸链。
- ❌ 配合尺寸只写 `φ30`，不写 H7/g6。
- ❌ 所有表面统一标 Ra 0.8（成本失控且不必要）。
- ❌ 螺纹孔只标 M8，不标深度和精度等级。
- ❌ 齿轮图没有参数表。
- ❌ 技术要求写“按国家标准”但不写标准号。
- ❌ 用轴测图代替缺失的视图。
