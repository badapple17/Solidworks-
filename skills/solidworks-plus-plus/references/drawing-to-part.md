# 三视图 + 直观图 → 三维模型 实操手册

适用：用户给出三视图、工程图、剖视图、轴测图（直观图）、照片或它们的组合，要求建出可编辑零件。
配套：`references/modes-and-questions.md`（模式与提问）、`references/quick-snippets.md`（代码）、`scripts/sw_part.py`。
读图时按 `drawing-standards.md` 检查视图/尺寸链/公差是否自洽；标准件按 `standard-parts.md` 查表。

## 1. 输入清点（先做，不许跳）

1. 列出全部图片/PDF 页，编号 `V1..Vn`。
2. 给每张图打标签：主视图 / 俯视图 / 左视图 / 右视图 / 剖视图 / 局部放大 / 轴测图 / 照片 / 尺寸表。
3. 记下每张图的尺寸来源：清晰标注 / 模糊 / 无标注 / 只有比例。
4. 如果只有一张图且不是轴测图：先判断它是否是三视图之一；缺视图时按模式处理（A 直接假设，B 提问或要求补图）。

输出一张输入表：

| 编号 | 文件/页 | 视图类型 | 尺寸情况 | 用途 |
|---|---|---|---|---|
| V1 | p1 左上 | 主视图 | 完整 | 外形+特征 |
| V2 | p1 左下 | 俯视图 | 完整 | 孔位/宽度 |
| V3 | p1 右 | 轴测图 | 无 | 拓扑确认 |

## 2. 投影制度判定（中国图纸默认第一角）

| 判据 | 第一角（GB/T，默认） | 第三角（ANSI/ISO-E 部分） |
|---|---|---|
| 俯视图位置 | 主视图**下方** | 主视图**上方** |
| 左/右视图位置 | **左视图**在主视图**右方** | **右视图**在主视图右方 |
| 剖视图标记 | A-A 箭头指向剖切方向 | 同理 |
| 标题栏 | 常见“第一角法”符号 | 圆锥/圆台符号方向相反 |

判定后写在任务卡：`Projection: first|third`。
SolidWorks 出图时第一角用 `*Left` 放在右侧，第三角用 `*Right` 放在右侧。

## 3. 读图算法（形体分析法 + 线面分析法）

按顺序执行，每步都要在笔记里留下结果：

1. **分线框**：每个封闭线框可能是一个平面、一个曲面轮廓或一个体素轮廓。
2. **对投影**：用“长对正、高平齐、宽相等”把三个视图的线框配对。
3. **定体素**：把配对结果翻译成基本体（长方体、圆柱、圆台、球、肋板、槽、孔）。
4. **定组合**：叠加（加）还是切割（减）；先大后小，先主后次。
5. **消歧**：用第三视图或轴测图排除多解；仍有多解时按第 8 节处理。
6. **定基准**：选出设计基准（底面、中心线、端面、孔轴线），作为原点。

### 3.1 线框/线型对照表

| 图上看到 | 通常含义 | 建模动作 |
|---|---|---|
| 粗实线封闭矩形 | 平面/长方体轮廓 | 拉伸/切除 |
| 圆/同心圆 | 圆柱、孔、沉孔、凸台 | 拉伸/旋转/孔切除 |
| 半圆 + 两条平行线 | 长圆孔/槽 | 槽切除 |
| 斜线 | 斜面、倒角、锥面 | 拉伸斜轮廓/倒角/旋转 |
| 虚线 | 不可见轮廓 | 背面/内部特征，不要当外轮廓 |
| 点划线 | 中心线/轴线 | 用于对称、旋转轴、孔中心 |
| 剖面线区域 | 剖切到的实体 | 截面形状，用于旋转/拉伸 |
| 波浪线 | 断裂边界 | 忽略或按完整件处理 |
| 细实线折线 | 过渡线/相贯线 | 结果自然产生，不要手画 |

### 3.2 特征 → SolidWorks 操作

| 几何 | 首选特征 | 备注 |
|---|---|---|
| 等截面主体 | 拉伸凸台（对称用中面） | 先做主包络 |
| 回转体（轴、套、轮） | 旋转凸台 | 草图画半个剖面 + 中心线 |
| 孔、型腔、槽 | 拉伸切除 | 圆孔优先用圆草图切除 |
| 沉孔/沉头孔 | 两级圆切除或 `sw_hole_features.py` | 记录大孔/小孔/深度 |
| 螺纹孔 | 底孔 + 装饰螺纹/属性（见子技能） | 不默认做真实螺旋牙 |
| 均布孔 | 圆周阵列 | 先做一个，再阵列 |
| 对称结构 | 镜像 | 以基准面镜像特征 |
| 薄壁壳体 | 抽壳 | 先实体后抽壳 |
| 加强筋 | 闭合三角形草图 + 薄拉伸（本机 `rib()` 返回 None） | 注意拔模方向 |
| 圆角/倒角 | 最后做 | 失败不影响主几何 |

### 3.3 尺寸提取表（三张表，缺一不可）

**表 A：总体尺寸**

| 参数 | 数值 | 来源 | 置信度 | 备注 |
|---|---:|---|---|---|
| 总长 | 180 | V2 明确 | high | X |
| 总宽 | 97 | V2 明确 | high | Z |
| 总高 | 70 | V1 明确 | high | Y |

**表 B：特征尺寸**

| 特征 | 参数 | 数值 | 来源 |
|---|---|---:|---|
| 主孔 | 直径 | φ36 | V1 |
| 主孔 | 深度 | 通 | V3 剖视 |
| 凸台 | 外径/高度 | φ28 / 8 | V1/V2 |

**表 C：定位尺寸**

| 特征 | 基准 | 定位 | 数值 | 来源 |
|---|---|---|---:|---|
| 4×M6 | 左端面/底面 | X/Z | 20 / 15 | V2 |
| 主孔 | 中心 | X/Y | 90 / 35 | V1 |

规则：
- 每个尺寸必须能追到某张图或某个推导公式；追不到就标 `assumed`。
- 尺寸链要闭合：总长 = 各段之和；孔距 + 边距 = 总长。
- 直径优先标 `φ`，半径标 `R`，螺纹标 `M`，沉孔标 `⌴`，沉头标 `⌵`。

## 4. 坐标系与基准（固定约定）

| 方向 | 含义 | SolidWorks 基准面 |
|---|---|---|
| X | 长度（主视图左右） | Front/Top 共用 |
| Y | 高度（主视图上下） | Front/Right 共用 |
| Z | 深度（俯视图上下） | Top/Right 共用 |

SW2023 实测的基准面 +法向与草图坐标映射（不要按教科书的正方向猜）：

| 基准面 | 草图坐标映射 | +法向（2026-10-24 实测，auto_flip=False） |
|---|---|---|
| Front Plane | (X=u, Y=v) | +Z |
| Top Plane | (X=u, Z=−v) | +Y |
| Right Plane | (Z=−u, Y=v) | +X |

两个封装的 `direction` 语义**相反**（2026-10-24 实测，auto_flip=False；
照抄拉伸的 direction 去切除，方向必反）：

| 封装 | `direction=True` | `direction=False` |
|---|---|---|
| `extrude_boss` | 沿 −法向拉伸 | 沿 +法向拉伸 |
| `extrude_cut` | 沿 +法向切除 | 沿 −法向切除 |

- 常规图纸：主视图画在 **Front Plane（XY）**，俯视图对应 **Top Plane**，
  左视图对应 **Right Plane**。
- **视图角色例外**：若主视图是侧剖面（L 形支架、台阶轴、盘类剖面），
  就把侧剖面画在 Front Plane，平面轮廓放 Top 或 Right。任务卡写
  `ViewRole: front=<图纸视图>`；交付说明必须写清生成图 Front/Top 分别是哪个
  图纸视图，不能让用户按错的主视图加工。
- **拉伸只选一种方向约定**：推荐 `direction=False` 全零件向正轴拉伸。
  切除方向不要照搬拉伸值——两个封装的语义相反，永远按材料所在侧选：
  `extrude_cut` 材料在正法向侧用 `True`，负法向侧用 `False`。
- 在哪个面上建主体，就在同一面上做孔槽切除。
- 需要从第二个面加工时，用 `insert_offset_plane()` 建偏置面（它先选中基准面；
  直接调 `InsertRefPlane` 在 SW2023 返回 `None`）。**偏置面的切除方向语义与
  基准面相同**：2026-10-24 实测（auto_flip=False）Front 偏置面 Z=+10、
  材料 Z=0..10 时 `direction=True` 切空、`False` 才切进材料——原因不是方向
  整体反转，而是偏置面贴在材料外端，朝 +法向切就是朝空处切。`extrude_cut()`
  默认 `auto_flip=True` 会自动反向重试，但首次仍只做一个试验孔，回读包围盒后再批量。
- 对称件把对称面放在原点；但**有通孔时优先“基准面=加工面”**，不要用中面拉伸，否则通孔只能切一半。
- 非对称件把设计基准（底面/端面/孔轴线）放在原点。
- 第一特征后用 `GetPartBox(True)` 回读包围盒，确认三个方向与预期一致。

## 5. 建模顺序（固定七步）

1. **基础体**：最大包络（板、块、回转体）。
2. **主体**：主要承载/外形结构（凸台、台阶、锥面）。
3. **功能性凸台/筋**：先加后减。
4. **孔/槽/型腔**：按基准定位，先主孔后次孔。
5. **阵列/镜像**：做一个，再阵列/镜像。
6. **圆角/倒角**：最后做，按图纸 R/C 值。
7. **收尾**：命名特征、写属性、保存、导出、审查。

每步规则：
- 草图必须闭合（圆角/倒角特征除外）。
- 每次特征调用后检查返回值是否为 `None`。
- 特征命名：`01_BASE_180x97x70`、`02_BORE_D36`、`03_HOLES_4xM6`。
- 方向不确定时先按默认方向做一次，读包围盒，再决定是否翻转。

## 6. 生成脚本骨架（照抄后改参数）

```python
import sys
from pathlib import Path

sys.path.insert(0, r"<skill>\scripts")

from sw_connect import mm
from sw_part import sketch, sketch_rectangle, sketch_circle, extrude_boss, extrude_cut
from sw_session import SolidWorksSession
from sw_review import run_review

# ---- 参数区（全部 mm）----
L, W, H = 180, 97, 70
BORE_D = 36
HOLE_D = 6.6          # M6 底孔
HOLE_PITCH_X, HOLE_PITCH_Z = 71.8, 56
OUT_DIR = Path(r"<workdir>\demo")
PART_PATH = OUT_DIR / "part.SLDPRT"
# --------------------------

OUT_DIR.mkdir(parents=True, exist_ok=True)
session = SolidWorksSession()
part = session.new_part()

# Top Plane 上建主体：direction=False → +Y，材料位于 Y∈[0, H]
with sketch(part, "Top Plane") as sk:
    sketch_rectangle(part, 0, 0, mm(L), mm(W))
extrude_boss(part, sk, mm(H), direction=False)

# 同一基准面贯穿切除：材料在 +Y 侧，切除用 direction=True（切除 True=+法向）
with sketch(part, "Top Plane") as sk:
    sketch_circle(part, 0, 0, mm(BORE_D / 2))
extrude_cut(part, sk, 0.0, direction=True)

# 先删旧文件再保存，避免旧文件让 saved=False 假通过
if PART_PATH.exists():
    PART_PATH.unlink()
saved = session.save(part, str(PART_PATH))
if not PART_PATH.is_file() or PART_PATH.stat().st_size == 0:
    raise RuntimeError(f"保存失败: {PART_PATH} (save 返回 {saved})")
report, path = run_review(part, str(OUT_DIR / "review"), basename="part",
                          expected_outputs=[str(PART_PATH)])
if report["evaluation"]["status"] != "pass":
    raise RuntimeError(f"审查未通过: {report['evaluation']['issues']}")
print(report["evaluation"], path)
```

说明：上面只是骨架；实际按第 3 节的特征表逐项添加。所有尺寸用 `mm()` 转换，SolidWorks API 单位是米。

## 7. 验证（缺一不可）

1. **包围盒**：`collect_geometry_measurements()` 的 `envelope_mm` 与表 A 对比。
   - B 模式：误差 ≤ max(0.1 mm, 0.2%)。
   - A 模式：误差 ≤ 5%。
2. **实体数**：`GetBodies2(0, False)` 必须等于任务卡 `BodyCount`。
3. **孔证据**：`measurements["holes"]` 的直径/位置与表 B/C 对比。
4. **特征名**：关键特征存在且未失败（`ForceRebuild3(False)`）。
5. **视觉**：`run_review()` 导出 iso/front/top/right BMP，逐张看：
   - 生成图 Front 与任务卡 `ViewRole` 指定的图纸视图一致（常规图纸 = 图纸主视图；
     侧剖面例外时 = 图纸的侧剖视图，且 Front/Top 角色已写进交付说明）；
   - 俯视图孔位/宽度一致；
   - 左视图高度/深度一致；
   - 轴测图无穿模、无多余实体、无悬空。
6. **工程图反查**（可选但强烈建议）：用 `sw_three_view.py` 出三视图，与原始图纸并排比较。

## 8. 多解与歧义处理

出现以下情况时不要硬猜：

| 歧义 | 处理 |
|---|---|
| 同一线框可解释为凸台或凹坑 | 看第三视图虚实线；仍不定则按轴测图 |
| 孔是通孔还是盲孔 | 看剖视图/虚线；B 模式提问，A 模式按通孔 |
| 单件还是焊接件/装配体 | 看零件序号、剖面线连续性、标题栏；影响拓扑，必须问 |
| 圆角是铸造圆角还是加工圆角 | A 模式统一 R2–R3；B 模式按未注圆角说明 |
| 缺一个视图 | B 模式要求补图或提问；A 模式按对称/最常见解释 |
| 尺寸链不闭合 | 先检查是否看错基准；仍不闭合则提问 |
| 同一尺寸在不同视图/说明里给出不同值 | 列出冲突点和出处，问用户取舍；不许静默取一个（`modes-and-questions.md` §2.1 第 9 条） |
| 标注有 `4×`/`TYP`/`均布`/`对称`/沉孔/沉头/剖面深度 | 先翻译成数量+规格再建；建完逐项核对数量与类型（4×M6 = 4 个螺纹孔；csk 90° ≠ cbore 平底） |

每条判据的教材依据与完整清单（读图侧 10 条 + 建模侧 7 条，含消歧方法、尺寸完整性
五例外、过渡线判据）见 `expert-thinking.md` §1.4/§1.5/§6——本表是操作版，
拿不准“该不该问”时查那份清单，命中即停手提问。

## 9. 常见坑（来自题库复盘）

- 把虚线当外轮廓，导致多切一块。
- 忘记“长对正”，俯视图宽度与主视图高度混用。
- 把轴测图的斜线当成真实角度（轴测图不反映真实角度）。
- 沉孔只画了小孔，漏了大孔/沉头角度。
- 均布孔只画了一个，漏阵列。
- 圆角在主体前做，导致后续切除失败；圆角必须最后。
- 草图未闭合就拉伸，SolidWorks 生成薄壁或失败。
- 中面拉伸用错平面，导致模型偏在原点一侧。
- 螺纹孔做成光孔且没写规格。
- 只保存不审查，预览发现方向反了。
- 把 `4×φ9` 只建了一个孔，或把沉头孔当成沉孔（类型变了）。
- 分段尺寸之和与总长不一致，却把总长硬改成分段和。
- 多视图尺寸冲突时自己挑一个“看起来合理”的，不列出来问。
