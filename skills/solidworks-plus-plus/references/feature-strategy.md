# 特征策略与设计意图（零件）

来源：《SOLIDWORKS 零件与装配体教程（2024版）》P1–359 的 6 份提炼（训练区
`digests/parts_assembly_p001_060.md` … `p301_361.md`）。教材数值只作示例；
OCR 存疑数值已标注“存疑/待核”，不要当确定值。本文件回答四个问题：
**先建什么、用什么特征、按什么顺序、改的时候怎么不炸。**

## 1. 开工前：五步分析与意图断言

零件分析五步（P51–55）：**标准视图 → 主要凸台 → 最佳轮廓 → 草图平面 → 设计意图**。

- **最佳轮廓** = 一次拉伸能覆盖最多模型几何的主截面。选小了会导致特征数膨胀、
  依赖链变长（P52、P54）。
- **设计意图要写成可验证断言**，不能只存在脑子里。示例（P55）：
  “所有孔是通孔；底部凹槽与基体凸起对齐；前沉头孔与基体凸起圆面共享圆心。”
  每条断言都应能映射到后面的包围盒、孔位、同轴或体积检查。
- 交付前的自检顺序：断言 → 草图状态 → 特征树 → 包围盒 → 体积 → 孔证据 → 预览。
- **同一数值出现多次 → 用相等/对称/中点等几何关系表达，不重复标注**；
  同一半径的多条边 → 一次圆角命令选完。失败模式：设计意图靠重复数值实现，
  改一处漏一处（P46、P55、P195）。与 §2.2 第 2 条（先约束后尺寸）配合使用。

### 1.1 孔定位标注三法，语义完全不同（P16）

| 标注法 | 改板宽时孔的行为 | 用在哪 |
|---|---|---|
| 孔到两对边各标距离 | 孔跟随边界，保持对称 | 对称布置、要求居中 |
| 只相对一个基准边标注 | 孔位固定，不随另一边移动 | 以安装面/工艺边为基准 |
| 标两孔中心距 | 保证孔间距，整体位置另定 | 孔系配合、齿轮/销孔 |

**规则**：标注前先问“以后哪个尺寸会变”，再选基准；不要默认双边距。
API 侧 `add_dimension` / `auto_dimension_sketch` 只能落尺寸，**选哪种基准是设计决策**。

**第 4 种定位法是几何关系，不是尺寸**：孔点与已有圆面同圆心时，光标悬停圆弧
激活圆心 → 出现〖重合〗符号 → 单击放置点，得到与圆心的重合关系；孔点欠定义时
编辑位置草图补约束（端点与边线重合即全约束，P62–63、P67–68）。API 侧用
`add_sketch_relation` 加重合关系，不要用两个距离尺寸凑同心。

### 1.2 回转件三种建模法（P16–17）

| 方法 | 做法 | 优点 | 代价 |
|---|---|---|---|
| 层叠蛋糕 | 逐层拉伸 | 特征含义清楚 | 改下层厚度会带动上层位置 |
| 制陶转盘 | 单草图一次旋转 | 特征少 | 信息集中，改一处牵动全部 |
| 制造法 | 棒料凸台 + 系列切除 | 模拟车削，符合工艺 | 特征多、切除顺序要规划 |

判据不是“哪种快”，而是**改动将如何传播**。长期维护的阶梯轴优先制造法或层叠法；
一次成型、不再改的示意件才用单旋转。

## 2. 草图规划（决定 80% 的可改性）

### 2.1 草图平面三判据（P53–54）

1. **显示方位**：标准视图下看哪个面最舒服。
2. **装配姿态**：首特征平面决定零件进装配体后的默认朝向。
3. **工程图前视图一致**：模型前视 = 最终工程图前视，能省大量投影/旋转。

三条冲突时，**优先第 3 条**（可交付性）。教材结论：多数板类件把最佳轮廓画在
**上视基准面**最省事。`start_sketch(model, plane_name="Top Plane")` 直接支持。

### 2.2 绘制与标注顺序（P31、P39–41、P46）

1. 先画近似几何，长度不必精确——尺寸驱动。
2. **先几何 → 后约束 → 再尺寸**；先标尺寸会干扰后续加约束。
3. 尺寸**先小后大、先近后远**，避免小几何体被大尺寸压住误选。
4. **从原点起笔**，自动获得重合关系，少一个自由度。
5. 选直线时避开中点（会捕到中点关系）。
6. 智能尺寸按实体推断：圆弧→半径、圆→直径、两平行线→线性、两不平行线/三点→角度。
   角度尺寸的放置位置决定内角/外角、锐角/钝角。回转件用“中心线+外侧轮廓线”
   标注时，光标在中心线哪一侧决定出半径还是直径（移到中心线外侧→直径）；
   放错得到半径时，在尺寸 PropertyManager 的〖引线〗选项卡改成〖直径〗
   （P150–152）。回转件应驱动直径，不要用半径尺寸凑。
7. 直线接圆弧用**切线弧**（UI 中按 A 键）；`sketch_arc` 没有切线语义，
   切点需要调用方自己算，算不准就改用“直线+圆角草图”或特征圆角。

### 2.3 草图状态（P33、P35）

| 状态 | 含义 | 处理 |
|---|---|---|
| 欠定义（蓝） | 仍可建特征 | 早期设计允许；**交付前必须完全定义** |
| 完全定义（黑） | 尺寸/关系闭合 | 目标状态 |
| 过定义（红） | 重复尺寸或冲突关系 | 先诊断（SketchXpert）核对红斜线项是否承载设计意图，再删冲突项；无诊断时删最近添加的重复项（P224–225） |
| 无解 | 约束互相矛盾 | 删关系重加，不要硬拉伸 |
| 无效 | 几何本身坏 | 必须修复，不能建特征 |

端点与线段可以处于不同状态；不要用“能拉伸”代替“已完全定义”。

### 2.4 轮廓类型（P34）

| 轮廓 | 结果 | 注意 |
|---|---|---|
| 单封闭 | 标准凸台 | 默认 |
| 嵌套封闭 | 一次拉伸带内腔 | 内环方向自动判断 |
| 开环 | 薄壁特征（需薄壁选项） | 开环旋转会问“是否自动封闭”，选否 |
| 多独立封闭 | 多实体 | 必须用轮廓选择工具指定 |

### 2.5 对称、借用边线与修剪（P89–103、P189–190）

- **对称件画一半再镜像**：先画中心线，再画半边；**半边不能跨过中心线**，
  否则出现重复几何、轮廓不闭合。
- **等距实体选“面”不选单条边**：选面在后期改尺寸/删边时关联更稳；
  方向反了用〖反向〗，不要手动拖几何。
- **转换实体引用**把模型边线投影到草图平面（边线可不在该平面）；
  源边线被后续特征吃掉会悬空。
- **剪裁/延伸**：强劲剪裁、边角、在内/在外剪除、剪裁到最近端；
  剪完常变欠定义，补一个半径/长度尺寸即可完全定义。
- **草图镜像、等距、转换、剪裁、延伸均未封装**（见 §10）；需要时用
  “画一半 + 特征镜像”或“重新画轮廓”绕开，不要臆造 API。

## 3. 特征顺序骨架

默认顺序（与 `SKILL.md` 路线 A 一致）：

**基础体 → 主体 → 凸台/筋 → 孔/槽 → 阵列/镜像 → 圆角/倒角 → 收尾**

必须偏离默认顺序的场景：

| 场景 | 调整 | 理由 | 依据 |
|---|---|---|---|
| 薄壁件内外都要圆角 | **先圆角，后抽壳** | R外 > 壁厚 t 时内圆角自动生成，R内 = R外 − t | P185 |
| 壳体上要开孔 | **先抽壳，后打孔** | 孔先做会被壳包出多余壁面 | P230 |
| 铸/塑件要拔模 | 主体后、细节前做拔模分析+中性面拔模 | 拔模会改面，圆角/孔随后做才不悬空 | P183–184 |
| 装饰性圆角 | 放最后 | 避免被后续切除打断 | P64 |
| 同半径多边圆角 | **一个命令一次选完** | 改半径只改一处 | P64、P108 |
| 不同半径圆角 | 通常**先大后小** | 小圆角留在大圆角之后，边集稳定 | P64 |
| 新位置需要已有同半径圆角 | **编辑已有圆角追加边线**，不新建 | 半径联动、下游自动更新 | P108 |
| 阵列源含圆角 | 要各实例圆角连续→先阵列后统一圆角；要每实例自带圆角→把圆角与源一起选入阵列 | 阵列只复制被选入的特征，圆角不会自动跟随（P116 只讲阵列选项，未讲圆角） | 规则推演 |
| 圆角后要抽壳 | 壁厚与圆角半径的关系 | 凸外圆角 R外>t 时内圆角自动生成（R内=R外−t）；**t>R外 时内角变尖角（合法，不报错）**；凹面或局部曲率半径小于壁厚处才可能报最小曲率半径；塑料壳警告可忽略 | P185；曲率门禁见曲面文档 §4 |

**孔排在抽壳之后**是最高频的顺序错误；**圆角先于抽壳**是第二高频。

## 4. 特征选型决策表

| 情境 | 首选 | 关键参数/判据 | 依据 |
|---|---|---|---|
| 板类、箱体类主体 | 拉伸凸台 | 最佳轮廓一次覆盖尽量多几何 | P52–54 |
| 回转体/阶梯轴 | 旋转或制造法（凸台+切除） | 轮廓不穿旋转轴；中心线作轴 | P150–152 |
| 一次拉伸带内腔 | 嵌套封闭轮廓 | 内外环都闭合 | P34 |
| 等壁厚壳体 | 抽壳 | 壁厚与最小圆角/曲率半径的关系见 §6.2；凸圆角 **t>R** 只得到尖角，不报错 | P184–185 + 曲面文档 §4 |
| 等壁厚回转/拉伸件 | 薄壁特征（开环+壁厚） | 比“实心+抽壳”少一步 | P191–192 |
| 薄壁加强筋 | 筋特征 | 草图可欠定义，筋自动延伸到壁 | P186–188 |
| 三面相切过渡 | 完整圆角 | 三个面组，同组内必须相切连续；每个不相连的加强筋单独建完整圆角特征，不能共享一次命令 | P190–191 |
| 对称零件 | 画一半 + 镜像特征/镜像实体 | 镜像面必须是平面 | P89–90、P129–131 |
| 多实例孔/凸台 | 阵列 | 源-实例关联，装配可复用 | P116 |
| 个别相似但独立的特征 | 复制粘贴 | 仅简单草图特征/圆角倒角可复制 | P107–108 |
| 轮廓沿模型边线偏移 | 等距实体选面 | 结果自动完全定义 | P101 |
| 需要内部空腔但外形复杂 | 多实体分开建，最后合并/组合 | 分离特征用多实体最有效 | P156 |
| 连接两实体的变截面杆/轮辐 | 扫描：闭环轮廓 + 开环路径 | 轮廓必须完全定义；扫描后合并为单实体 | P157–159 |
| 多个特征共用同一布局 | 共享草图 + 轮廓选择工具 | 按闭合区域分别建特征；轮廓参数未封装 | P228–230 |

## 5. 终止条件与方向

| 终止条件 | 语义 | 何时用 |
|---|---|---|
| 给定深度（Blind） | 固定深度 | 尺寸明确、目标面不移动 |
| 完全贯穿（Through All） | 贯穿所有实体 | 通孔、通槽；不用给深度 |
| 成形到下一面（Up To Next） | 路径上第一个面 | 目标面会随设计移动，优先用它 |
| 成形到一面（Up To Surface） | 只受所选面约束 | 明确指定终止面 |
| 到离指定面指定的距离 | 从面/基准面起量等距 | 留余量、非贴合终止 |
| 两侧对称（Mid Plane） | 深度=总深度，每侧一半 | 关于草图平面对称的实体 |

- **成形到一面 ≠ 成形到下一面**：目标会移动时用“下一面”，避免悬空参考（P193）。
- “到离指定面”里的〖转化曲面〗：勾选=沿拉伸方向线性复制曲面，不勾=按法向投影；
  非平面终止面结果不同，平面时相同（P104）。
- 方向错时先做一个特征，回读 `GetPartBox(True)` 再继续；不要一次做到底。
- **API 现状**：`extrude_boss` 只有盲深；`extrude_cut` 支持盲切与完全贯穿
  （`depth=0`）；`extrude_midplane` 支持两侧对称。`UpToNext / UpToSurface /
  OffsetFromSurface` 未封装（§10）。

## 6. 圆角、抽壳、拔模、筋

### 6.1 圆角七条规则（P64、P66–67、P108、P160–162）

1. 装饰性圆角最后建。
2. 同半径多边用一个命令一次做完。
3. 不同半径通常先大后小。
4. 新位置同半径 → 编辑已有圆角追加边线，不新建。
5. 切线延伸可让圆角沿相切边扩展；本机封装把 `Options` 固定为 195，
   **切线延伸被硬编码为开启**，不能关闭——需要不传播的单边圆角时标“需人工”。
   （195 = 1+2+64+128，其中 1 是 `swFeatureFilletPropagate`，枚举名取自
   `swconst` 类型库；不是凭经验猜的开关。）
6. **圆角特征可以转成倒角特征**（P64、P66–67）；批量倒角不想重选边时用这个转换。
7. **边线会随尺寸变动时，按面选边**而不是逐条选边：一次选面内的边，
   尺寸改动后边集不失效（P160–162）。

失败处理：圆角缺边线显示为虚线 → 编辑特征里“修复所有缺失的参考”；
仍失败用 `FeatureXpert`（仅圆角/拔模，需在系统选项启用）。

### 6.2 抽壳（P184–185、P230）

- 先圆角后抽壳；R外 > t 时内圆角自动生成，R内 = R外 − t；t > R 时内角为尖角。
- 可选多个移除面；同一命令可对不同面设不同壁厚（多壁厚未封装）。
- 不选移除面 = 完全中空密封体。
- **孔排在抽壳之后**，否则抽壳沿孔生成多余壁面。
- **API 注意**：`shell(model, thickness, faces_to_remove=[face, ...])` 会自动选择
  传入的面并返回新建的抽壳特征；不传时使用当前选择集，不选任何面 = 完全中空密封体。
  SW2023 动态派发找不到 `InsertFeatureShell`，封装已改用 raw IDispatch::Invoke，
  不要改回 `model.InsertFeatureShell(...)`。

### 6.3 拔模（P182–184）

1. 先〖拔模分析〗：设脱模方向与角度（示例 2°），欠拔模面变色。
2. 再〖中性面拔模〗：分型面作中性面 + 拔模面 + 角度。
3. 方向反了用〖反向〗；无侧凹的面不需要拔模。
4. 拉伸自带的拔模选项只适用于简单拉伸；复杂面用独立拔模特征。
5. **拔模未封装**（`advanced_geometry.py` 只有计划校验，无建模执行）。

### 6.4 筋（P186–188）

- 草图只需表达筋顶位置与走向，**可以欠定义**；筋自动延伸到相邻壁。
- 简单直线草图可垂直/平行于草图平面拉伸；复杂轮廓只能垂直。
- 参数：厚度、在草图面处/两侧、拔模角、材料方向（不对时反转）。
- `rib(model, sketch_name, thickness, two_sided=True)`：第 1 参数是 Is2Sided
  （两侧加厚），不是拉伸方向；实测简单 L 形支架仍返回 `None`，
  **弱模型改用闭合三角形草图拉伸**，不要依赖筋特征。

## 7. 阵列与镜像

### 7.1 阵列选型（P116–141）

| 情境 | 选择 | 关键点 |
|---|---|---|
| 实例几何与源完全相同（等厚板、贯通孔） | 勾〖几何体阵列〗 | 只复制几何，忽略源的终止条件；快且稳 |
| 源用“到指定面指定距离”，各实例应不同 | **不勾**几何体阵列 | 保留终止条件，实例各自成形 |
| 个别位置不需要实例 | 跳过实例 | 源不可删；实例按 (2,3) 定位 |
| 知道间距、实例数由边界决定 | 〖到参考〗 | 间距 80→3、70→4、50→5（示例）；间距微增可能回退实例数 |
| 双向对称 | 方向2 勾〖对称〗 | 非对称双向用〖仅阵列源〗 |
| 孔位不规则、由点位表控制 | 草图驱动阵列 | 草图只放点；点不能直接落在已有端点上，先画点再加重合 |
| 绕轴均布 | 圆周阵列 | 轴可来自圆柱面/基准轴/临时轴/圆边线/角度；角度≠360° 时反向才有意义 |
| 对称零件 | 镜像特征或镜像实体 | 镜像面必须为平面；镜像实体用面镜像全部实体 |

**轴怎么来（弱模型最常卡住的一步）**：圆周阵列的轴优先用圆柱面、圆边线或
临时轴；基准轴有 5 种建法（直线/边线、两点、点+面、两平面、圆柱面，P123–128、
P132–133）。临时轴每个圆柱/圆锥特征自带，需在系统选项里勾选显示。草图里若有
两条中心线，系统无法判断旋转轴——在命令前后显式选中心线，否则会绕错轴
（P123–124）。API 侧只封装了 `insert_offset_plane`；基准轴、坐标系、临时轴
均未封装，需人工创建或改选圆柱面/圆边线。

**阵列优于复制粘贴**：源只建一次、实例随源更新、装配体可特征驱动、支持智能扣件。

### 7.2 镜像后过切（P129–131）

镜像结果过切时，**改源特征**（位置尺寸、把深度改为“成形到下一面”）再重建，
不要改镜像出来的实例。镜像面必须是平面；镜像实体需要一个面代表全部几何。

### 7.3 API 缺口（实测）

`linear_pattern` 的 1D/2D 已修好（2026-10-24 实测）：内部自动建辅助 3D 草图
表达方向，数量是含源实例的总数；**没有** geometry pattern、跳过实例、对称、
到参考。`circular_pattern` 未实测，`DName` 传 `"None"` 不可靠；`mirror_feature`
只有特征镜像，没有镜像实体。需要这些选项时，在任务卡里标“需人工/新增封装”，
不要传不存在的参数。

## 8. 编辑、修复与重建

### 8.1 错误级联：先修最早的那个（P201–204）

- 错误=特征失败（红）；警告=几何生成但有隐患（黄）。
- 从特征树最上面的错误开始修，下游常自动恢复。
- 〖停止并修复〗把退回棒放在问题特征之后；平坦树视图（Ctrl+T）按创建顺序显示。
- 不弹错误框时，在系统选项里勾“每次重建模型时显示错误”。

### 8.2 草图修复（P205–208）

1. 〖检查草图合法性〗按目标特征用法校验轮廓类型（如基体拉伸不允许多个非连通轮廓）。
2. 〖修复草图〗设缝隙容差（约 0.01 mm 量级；OCR 残缺推断值，待核原书）：
   删微小/无关实体、合并端点缝隙、
   删除多余线。连续轮廓中**单个缝隙可接受**。
3. 远处无意几何体用〖整屏显示全图〗找。
4. 过定义时用状态栏〖过定义〗→〖诊断〗（SketchXpert）列出候选解；
   **红斜线=将被删除的尺寸/关系**，选择前核对它是否承载设计意图，
   不要机械地接受第一个方案（P224–225）。

### 8.3 悬空关系（P208–211）

- 父几何被删 → 草图关系/尺寸变红：拖动控标到新边线；尺寸会自动更新为新几何值。
- 或用〖显示/删除几何关系〗过滤〖悬空〗→〖替换〗实体。
- 草图平面丢失 → 〖编辑草图平面〗换面（新面不必与旧面平行）。

### 8.4 退回、冻结、压缩（P67–68、P213、P222）

| 手段 | 作用 | 注意 |
|---|---|---|
| 退回控制棒 | 在历史中间插特征；限制重建范围 | 完成后必须“退回到尾” |
| 冻结栏 | 上方特征不重建、不可编辑 | 锁已验证区段，改其尺寸会报“已禁用” |
| 压缩 | 特征视作不存在，子特征连带压缩 | 配置可组合不同压缩集 |
| 重排 | 调整特征顺序 | 子特征不能排到父特征之前；先移除依赖 |

### 8.5 编辑优于删除重建（P217、P220）

编辑特征保留工程图/装配体引用；删除会丢引用并连带子特征。删除前看依赖清单：
子特征随父删；异形孔向导的草图随孔删，普通草图保留。

### 8.6 重建性能（P122–123）

- 用性能评估按重建时间排序，压缩/修改占比最高的特征；0.02 s 与 0.01 s 的差异属舍入噪声。
- 草图特征慢通常源于查找外部参考与终止条件：**把几何关系附加到最早的特征上**，
  草图平面同理；父特征越多，重建越慢。
- 大模型改早期特征时，用退回棒限制重建范围，或用冻结栏锁住已验证区段（§8.4）。
- **改尺寸/特征后必须重建**：`update_dimension_mm` 或特征编辑后调用
  `model.EditRebuild3()`；怀疑下游未更新时用 `ForceRebuild3(False)` 全重建
  （对应 Ctrl+Q），再回读包围盒/体积验证（P78–79）。保存时也会自动重建，
  但不要依赖保存代替显式重建——改参不重建是自动化里最常见的静默失败源。

### 8.7 替换草图实体（P233）

改轮廓形状又不想破坏下游引用：加新实体 → 删旧实体 → 删除确认里选〖替换实体〗
→ 指到新实体。直接删+重画会造成下游悬空级联。

## 9. 配置与参数化

### 9.1 配置 = 压缩状态 + 尺寸值 + 材料/颜色/终止条件（P241–245）

- 同一文件表达毛坯/机加工、长短规格、FEA 简化版，不另建零件。
- 特征属性/尺寸修改都可选作用范围：**此配置 / 指定配置 / 所有配置**。
- **压缩父特征会压缩全部子特征**；父子关系由“草图画在谁的面/边上”决定。
  因此把大特征拆成小而独立的特征，才有按需压缩的灵活性（P242、P247）。
- 被其他文档引用的配置**不要重命名**；要改名先复制配置。
- 新配置对话框的“压缩特征”默认勾选：此后新特征只在激活配置中解除压缩（P248）。

### 9.2 简化配置（P247）

为 FEA/大装配/快速成型做简化版：压缩圆角、扫描、放样等细节，只保留
**配合、干涉检查、方程式所需的关键几何**；插入零部件时选对应配置
（`add_component(config_name=...)` 已支持）。

### 9.3 方程式与全局变量（P257–266）

教材注塑件规则（示例，不是通用标准）：

| 量 | 关系 |
|---|---|
| 抽壳壁厚 W | 4–6 mm；圆角/筋厚关系的唯一自变量（与 DA 并列驱动） |
| 筋厚 | 2W/3 |
| 内圆角 | W/2 |
| 外圆角 | 1.5W |
| 筋圆角 | W/4 |
| 拔模角 DA | 疑 1°–5°（OCR 残缺，待核）；全局变量统一 |

语法与陷阱：

- 形式“因变量 = 自变量”；运算顺序 幂→乘除→加减，括号优先。
- `int()` 截断小数（int(5.25)=5）；要求整数的尺寸加 `int()`，
  **但筋厚度不要取整**，否则可能过薄。
- 单位=文档单位；`thickness` 是钣金保留关键字，避开。
- 方程式生效后尺寸不能直接改；先定驱动/被驱动。
- 勾“自动求解组序”避免循环引用。
- 全局变量未创建时显示黄色。

### 9.4 链接数值 vs 方程式 vs 从动尺寸（P259、P267–272）

| 需求 | 工具 |
|---|---|
| 多个同类型尺寸永远相等 | 链接数值（不创建方程式，只是共享值） |
| 倍数/和差关系 | 方程式 |
| 共享中间值 | 全局变量 |
| 派生量只需显示、不该被改 | 从动尺寸（括号显示，随模型变，不可驱动模型） |

### 9.5 尺寸命名（P255–256）

尺寸全名 = `名称@特征名`（如 `Inside_Radius@Fillet1`）。建方程式/全局变量前，
先重命名参与的关键尺寸与特征；默认 `D1@草图1` 不可维护。

### 9.6 API 现状

`update_dimension_mm(..., configuration_mode="current"/"all"/"specific")` 可用；
`inspect_configurations` 只读枚举。**配置创建/复制、特征压缩、激活配置切换、
方程式/全局变量、链接数值、从动尺寸、尺寸改名均未封装**（§10）。

## 11. 失败模式速查

| 现象 | 原因 | 一线修复 | 兜底 |
|---|---|---|---|
| 抽壳报最小曲率半径 | 凹面或局部曲率半径小于壁厚（凸外圆角**壁厚 t>R** 只得到尖角，不报错） | 减小壁厚或加大圆角 | 局部改面/分段抽壳；塑料件可接受警告 |
| 抽壳后孔周围多出壁面 | 孔先于抽壳 | 把孔特征排到抽壳之后 | 删除孔重做 |
| 圆角失败/缺边线 | 边集被后续特征改掉 | 编辑圆角重选边；“修复所有缺失参考” | 拆成多个小圆角；最后再做装饰圆角 |
| 镜像后过切 | 源特征终止条件被强加 | 改源特征位置/改“成形到下一面” | 改用镜像实体并单独切除 |
| 阵列实例形态不一致 | 源用“到指定面”且未勾几何体阵列 | 勾几何体阵列，或改盲深 | 拆成独立特征 |
| 改尺寸后下游乱 | 草图约束没表达设计意图 | 回到草图补几何关系/对称 | 重画关键草图，不要叠切除补救 |
| 特征重排被禁止 | 子特征不能先于父特征 | 先编辑子特征移除对父面的依赖 | 删除依赖特征再重排（会丢引用） |
| 打开同名零件冲突 | 文件名不唯一，按内部 ID 判定 | 保证文件名唯一 | 选“无此文档打开”压缩实例；不要盲目“接受此文件” |
| 配置改名后引用失败 | 其他文档引用了该配置 | 复制配置再改名 | 恢复原名 |

## 12. 给弱模型的执行边界

- **只做能验证的**：每加一个特征，确认返回对象非 None；关键节点回读包围盒/体积。
- **不要用未封装参数**：本文件 §10 标“未封装”的能力，写进任务卡让人工完成，
  不得臆造 API 名称或枚举值。
- **阵列优先 `linear_pattern`**：1D/2D 已实测；它会在模型里留一个辅助 3D 草图，
  不要删。圆周阵列轴没把握时标“需人工”。
- **抽壳先传面**：`shell(part, mm(2), [face])`；不传面会抽成完全中空密封体。
- **筋不要用 `rib()`**：实测返回 None；用闭合三角形草图拉伸。
- **顺序优先于技巧**：先圆角后抽壳、孔在抽壳后、装饰圆角最后；这三条能挡掉大部分返工。
- **一个特征一个目的**：不要把多个凸台/切除塞进同一草图；配置和修复都需要粒度。
- **交付前至少四项证据**：包围盒、体积、孔证据、四视图预览；缺一项不算完成。
