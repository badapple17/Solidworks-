# 尺寸排版与标注策略

> 用途：`sw_three_view.py --dims` 出图前后读这一份；人工检查“数值都对、但就是乱”的图也读这一份。
> 与 `drawing-standards.md` §3 的分工：那里管**标什么、用什么格式**；这里管**先标哪个、放在哪、为什么人的图好看**。
> 算法真源：`scripts/sw_dimension_layout.py`。自动排版能落地的规则列在 §4.3；其余靠人工或目视。

## 0. “乱”不是感觉，是六种可指认的形态

| # | 人眼看到的 | 机器出图的典型根因 | 修复 |
|---|---|---|---|
| 1 | 尺寸线钻进零件轮廓里 | 按文字当前位置就近摆放，没按视图外框推 | `_preferred_side` + `offset_mm` 从外框起算 |
| 2 | 数字被轮廓线/中心线/尺寸界线穿过 | 只检查数字之间是否重叠，没检查数字与图线 | `_clear_of_levels` 沿尺寸线跳过挡路界线 |
| 3 | 两条尺寸线在同一层共线，箭头互相切断 | 只避让数字，不避让尺寸线区间 | `_band_free` 同时记录 span 与 text 区间 |
| 4 | 小尺寸被挤到最外层，大尺寸反而在里层 | 按 COM 返回顺序摆放 | 按 `span` 升序 first-fit，小内大外 |
| 5 | 同一形体的尺寸散落在三个视图 | 每个视图各自为政 | 尺寸归属由“最清晰视图”决定，人工先删重复 |
| 6 | 一圈尺寸首尾相接，没有开口 | 把模型尺寸全量倒出来 | 先做尺寸链审查，删一个非重要分段 |

前三种是排版问题，第 4 种是层级问题，第 5、6 种是**标注策略**问题——排版算法救不了策略错误。顺序必须是：先定策略（§2），再排版（§3–§4）。

## 1. 人怎么标：固定动作顺序

三条底层思维，先记住再谈规则：

- **尺寸是给加工和检验看的，不是给模型看的。** 每标一个先问：谁来量、从哪个面量、量了干什么。
- **能算出来的不标，必须保证的直接标。** 配合/安装尺寸不能靠链算；不重要的一段留给开口环。
- **美观是结果，不是目标。** 分组、对齐、留白做对了，图自然不乱；只追求“摆下”只会越摆越挤。

教材和视频里的老师傅动作高度一致，顺序不是随意的：

1. **定主视图**：选包含特征最多的视图；必要时用剖视图替掉一个外形视图（轴承座案例直接把侧视图换成剖视）。
2. **补中心线**：圆/圆弧中心符号线、对称中心线、槽口两圆弧圆心连线。中心线是尺寸的落脚点，先有它才标得稳。
3. **标外形尺寸**：总长/总宽/总高，回转件是外径 + 厚度（先标下料尺寸）。
4. **标功能/配合尺寸**：轴承位、配合面、安装孔距，直接标、带公差，绝不用别的尺寸减出来。
5. **标特征定形 + 定位**：先基本体大小，再从基准出发定位置；钻孔先定位后定形。
6. **标工艺结构**：退刀槽、倒角、清根、螺纹长度，直接标不计算。
7. **标公差/形位/粗糙度**：等所有尺寸定稿后再加，避免边标边改。
8. **查三件事**：封闭链有没有开口、同一尺寸是否标了两次、每个特征是否都标全。

证据（视频字幕，ASR 术语已按国标校正）：

| 案例 | 动作顺序 |
|---|---|
| 传动轴 | 先建圆/槽口/对称中心线 → 总长 400 → 轴承位分段 → 槽口位置与宽深 → 各轴径 → 退刀槽；明确说“标工程图不要形成封闭尺寸链”，不重要的中间段故意不标 |
| 轴承座 | 主视图取特征最多者 → 侧视图换剖视 → 连通孔中心线与回转中心线 → 外径 + 厚度 → 轴肩/轴承位/孔位 → 调箭头朝内“美观一点” → 公差/形位/粗糙度 |
| 安装板 | 先加对称中心线 → 外宽/外高/板厚 → 以底面为基准标孔组 → 槽/孔中心线 → 侧视图标槽深 → 最后才给公差，并反复“对齐一下”“这样比较美观” |

### 1.1 人眼审美的四条底层规则

风格不是玄学，人的图好看是因为同时满足了这四条：

1. **读图动线**：从外到内、从主视图到辅助视图。总体尺寸永远在最外圈，局部尺寸往里收。
2. **分组**：同一工序/同一形体的尺寸靠在一起，组与组之间留明显空档；不是等距撒满。
3. **对齐**：并排尺寸线互相平行、端点大致对齐；数字落在同一条视觉基线上。
4. **留白**：只标加工需要的尺寸。空白多不是漏标，塞满才是没想清楚。

### 1.2 图面分区

| 区域 | 放什么 |
|---|---|
| 图面中心/左上 | 主视图，其余视图按第一角投影排布 |
| 视图四周 | 尺寸线分层环绕，外侧是总体尺寸 |
| 右上角 | 齿轮参数表（齿轮类） |
| 右下角标题栏上方 | 技术要求 |
| 两视图之间 | 与两个视图都有关的尺寸（如跨视图的孔距/中心高） |

尺寸不能压标题栏、技术要求、参数表；空间不够时先缩视图比例或换大图幅，不是把尺寸塞进视图里。

## 2. 下笔之前：基准与尺寸链

### 2.1 基准怎么选

| 场景 | 基准 | 备注 |
|---|---|---|
| 某方向对称 | 对称中心线/对称面 | 对称件先画中心线再标 |
| 某方向不对称 | 较大端面、底面、较大回转体轴线 | 优先安装面/支承面/装配结合面 |
| 轴类径向 | 轴线 | 设计基准与工艺基准重合 |
| 轴类轴向 | 设计：轴肩端面；工艺/测量：轴端面 | 两者可不重合，各从各的基准标 |
| 板类 | 底面/安装面 | 孔组从同一基准出发，不要一半左一半右 |
| 箱体/壳体 | 安装底面 + 两定位孔 | 孔系用坐标或中心距 |
| 阶梯孔轴向 | 外端面 | 从端面标大孔深度，方便测量 |

硬规则：

- 长、宽、高每个方向至少一个主要基准；辅助基准必须与主要基准有直接尺寸联系。
- 设计基准与工艺基准尽量重合；不重合时设计基准作主、工艺基准作辅。
- 特征面与基准面重合，或圆心落在中心线上 → **定位尺寸省略**，不要重复标 0。
- 同一方向最多允许一个毛坯面与加工面发生尺寸联系；加工面与加工面之间不受限。

### 2.2 重要尺寸与一般尺寸

| 类别 | 判据 | 标法 |
|---|---|---|
| 重要尺寸 | 影响性能、工作精度、配合、安装 | **直接标出**，带公差；绝不由其他尺寸相减得到 |
| 一般尺寸 | 非配合的直径、长度、外轮廓 | 可无公差；可充当封闭环 |

### 2.3 尺寸链：必须留一个开口

- 禁止箭头首尾相接的封闭尺寸链；每个方向至少留一个开口环吸收累积误差。
- 开口环选**最不重要**的尺寸：无孔、无配合、多标少标都不影响装配的那一段。
- 有配合/功能要求的尺寸优先直接标，不能靠链算。
- 并联尺寸：大尺寸在外、小尺寸在内；串联尺寸：首尾相连，端点连续。
- 快速自检：某方向若“总长 = 各分段之和”且每个分段都标了，就是封闭链，删一个分段。

> 常见误区：薄板上三个相同的 1.2 mm 台阶，逐个标三遍不是“完整”，人的写法是 `3×1.2` 或一个 `1.2 EQS`。工具不能改尺寸文字，遇到这种图要在报告里提示人工合并，而不是硬排三个。

## 3. GB 版面硬指标

| 项 | 数值 | 说明 |
|---|---|---|
| 第一根尺寸线到轮廓 | 约 8 mm（7–10） | 工具 `offset_mm=8` |
| 平行尺寸线间距 | 5–8 mm，且大致相等 | 工具 `pitch_mm=8` |
| 尺寸界线超出尺寸线 | 约 2 mm | 太贴近轮廓可倾斜，但两界线仍平行且出头 2 mm |
| 中心线超出轮廓 | 3–5 mm | 两中心线相交必须长画相交；φ<12 mm 圆用细实线 |
| 尺寸数字高度 | 常用 3.5 mm（可选 2.5/3.5/5）；同一图样必须一致 | 长仿宋，宽高比约 0.7 |
| 箭头 | 长约 3 mm，尾宽约 0.5 mm（粗实线宽） | 全图一致 |
| 平行图线最小间距 | ≥7 mm | 粗实线 0.5–2 mm，细线取粗线一半 |
| 尺寸线 | 必须单独画，平行于所标线段 | 不得用轮廓线/中心线代替，不得画在其延长线上 |
| 尺寸线关系 | 彼此不相交，不与任何图线重合 | 包括中心线、剖面线 |
| 数字位置 | 水平尺寸在上方；竖直尺寸在左侧、字头向左 | 避开 ±30° 竖直狭小区，否则用指引线折成水平 |
| 数字避让 | 不得被任何图线穿过 | 无法避免时图线必须断开 |
| 标注位置 | 尽量在视图轮廓外 | 轮廓内只允许极特殊情形 |
| 禁止标注对象 | 虚线、相贯线、截交线 | 标基本体尺寸与位置，交线自生 |
| 圆弧 | >半圆标 φ，≤半圆标 R | R 只能标在圆弧上且尺寸线过圆心；R 不乘数量 |
| 直径计数 | `2×φ10`，数量在前 | 禁止 `φ10×2` |
| 角度 | 尺寸线为以顶点为圆心的圆弧，界线径向，数字水平 |  |
| 圆角过渡处 | 用细实线延长轮廓，从交点引尺寸界线 | 不能从圆角切点引，否则尺寸偏大/偏小 |
| 对称结构 | 不拆成两半标 | 30 不拆 15+15；孔组标中心距 40 不拆 20+20 |
| 重复要素 | 只标一次 + 数量/EQS | 孔、槽、齿均适用 |
| 视图归属 | 标在反映该结构最清晰的视图 | 同一形体的尺寸集中，不分散 |
| 直径标注视图 | 优先标在非圆视图（直径显示为直线的那一面） | 圆视图上避免堆一列 φ，容易与中心线/其他直径交叉 |
| 跨视图尺寸 | 与两个视图都有关的尺寸放在两视图之间 | 不要让读图人来回找 |

### 3.1 拥挤时的四级退让

按顺序用，越往后越伤版面：

1. **箭头朝内**：同一尺寸线两端箭头翻到内侧（视频里“调朝内侧，美观一点”）。
2. **加层**：往外交错一层，间距保持 8 mm；不要挤在同一层。
3. **整组平移**：同一工序的尺寸作为一组一起挪，保持组内相对位置。
4. **改视图/图幅**：缩比例、换 A2/A1，或把某个视图换成剖视/局部放大。

禁止的“退让”：删掉该标的尺寸、让数字压线、把尺寸塞进轮廓内、缩字高。字高和箭头必须全图一致。

## 4. 自动排版怎么工作

### 4.1 流程

```text
读取每个显示尺寸
  → 用 ModelToViewTransform 把 ReferencePoints 转到图纸毫米（含视图比例）
  → 分类：linear / circular / other
  → 按锚点位置选边（左/右/上/下）
  → 线性尺寸按 span 升序 first-fit（小内大外）
  → 每层用 _band_free 同时避让尺寸线区间与数字区间
  → 小尺寸数字用 _clear_of_levels 沿尺寸线跳过所有挡路界线
  → SetPosition 写入 → 回读，误差 >0.05 mm 记为失败
```

### 4.2 参数

| 参数 | 默认 | 含义 |
|---|---|---|
| `offset_mm` | 8.0 | 第一层尺寸线到视图外框 |
| `pitch_mm` | 8.0 | 层间距 |
| `margin_mm` | 10.0 | 图框安全边距 |
| `_MAX_LEVELS` | 3 | 8 + 2×8 = 24 mm，仍在 PDF 检查器 25 mm 悬浮阈值内 |
| `_TEXT_HEIGHT_MM` | 3.5 | 数字高度 |
| `_MIN_TEXT_GAP_MM` | 2.0 | 同层数字最小间隙 |
| `_MIN_LEADER_MM` | 10.0 | 放射尺寸文字离圆心的最小引出长度 |

### 4.3 规则 → 代码落点

| 规则 | 代码 |
|---|---|
| 小内大外 | `dimensions.sort(key=(kind_order, span))`，线性尺寸按 span 升序占层 |
| 尺寸线不进轮廓 | `_preferred_side` 选边 + `_side_offset` 从 `box` 外推 |
| 同层不共线 | `_band_free` 比较 `(span_center, span_extent)` |
| 数字不压线 | `_clear_of_levels` 跳过 `axis_levels` 中所有挡路界线 |
| 数字互不重叠 | `_band_free` 比较 `(text_center, text_extent)` + `_MIN_TEXT_GAP_MM` |
| 放射尺寸在空白方向 | `_place_circular` 按 45°/135°/… 顺序找第一个不越界、不压视图/文字的角；`_place_other` 用 `_exit_distance` 从中心外推 |
| 不压标题栏/纸边 | `Sheet.fits` + `title_block` 矩形 |
| 不压其他视图 | `_inside(rect, other_boxes)` |
| 摆完必须回读 | `_apply` 读 `GetPosition`，容差 0.05 mm |

### 4.4 报告怎么读

`_drawing_report.json` 的 `dimension_placement.views[].placed[]` 每条包含：

```json
{
  "text": "20",
  "kind": "linear",
  "side": "right",
  "level": 1,
  "span_mm": 20.0,
  "anchor_mm": [0.0, 0.0],
  "x_m": 0.2714,
  "y_m": 0.1234,
  "readback_m": [0.2714, 0.1234],
  "verified": true,
  "issue": null
}
```

- `status == "pass"` 只代表**每个 SetPosition 都写入并回读成功**，不代表每个尺寸都找到了不冲突的位置；`warn` 表示有回读失败；`blocked` 表示连视图/图幅都读不到。
- `verified_count == placed_count` 才算写入证据齐全。
- 必须逐条看 `issue`：`NO_FEASIBLE_SLOT` = 没排成、保留原位（按失败处理）；`BAND_CROWDED` / `RADIAL_CROWDED` = 排下了但该处拥挤（必须目视）。全为 `null` 才是真正的无冲突排布。
- 看 `level` 判断层级：正常情况下小 span 占小 level；若小 span 的 level 反而比大 span 大，说明内层被别的尺寸占满，需目视确认是否可接受。

本机实测（2026-10-25，SW2023）：

| 样件 | 排版 | PDF 检查 | 观察到的层级 |
|---|---|---|---|
| 齿轮 | 4/4 | 0 findings | φ20/φ36 分别在 45°/135°；12 在右 L0、20 在右 L1 |
| 薄板（base） | 5/5 | 0 findings | 两个 1.2 在 L0，10 在 L1/L2；小内大外 |
| 叠板（06_plate） | 6/6 | 0 findings | 左侧 0.5→4.5→11 由内到外；96 在顶侧 |

这三组是当前算法的回归基线；改算法后先复跑它们，再看新样件。

### 4.5 已知限制（必须在交付说明里保留）

1. **同心直径线在圆心交叉**：SW2023 的直径尺寸默认画穿圆心的双箭头线，两个同心圆直径必然交叉。`DisplayAsLinear=True`、`SetLeader3` 在该版本实测不可用；人工出图可用单箭头引线，自动出图暂不能。
2. **极小尺寸仍可能拉出长线**：工具只能移动数字，不能把箭头翻到外侧，也不能批量改成朝内/圆点；span 远小于文字宽时，尺寸线会显得长。遇到薄板叠尺寸，优先人工合并成 `n×`/EQS，或按 §3.1 退让。
3. **不能改尺寸文字**：`GetText` 只读；`3×1.2`、`EQS`、括号参考尺寸都要人工改。
4. **只重排已插入的模型尺寸**：模型里没有的尺寸不会凭空生成；`--dims` 的完整性上限由模型尺寸决定。
5. **文字宽度是估算**：`GetText` 常为空，按字符数合成；带小数点会补一个尾零宽度，仍可能与实际字体有 1–2 mm 偏差。
6. **PDF 检查器有盲区**：能查悬空数字、数字重叠、出框；查不出“同层尺寸线共线”“小尺寸在外”“封闭尺寸链”。这三项必须目视或按 §7 清单人工过。

## 5. 零件族配方

### 5.1 轴类

- 径向：全部从轴线标直径，每个轴颈单独标；轴承位直接标并带公差。
- 轴向：总长 → 功能段（轴承位/齿轮位）→ 槽/键槽 → 退刀槽/倒角；留一个非重要段作开口环。
- 键槽：宽度、深度、长度、轴向定位四项齐全；槽宽在键槽最清晰的视图上。
- 两端相同的轴承位也要**分别标**：它们是两个不同特征，不是重复尺寸。
- 中心线先画：圆、圆弧、槽口圆心、整轴对称线。

### 5.2 板类

- 先加对称中心线（对称件），再标外宽、外高、板厚。
- 孔组以底面/安装面为基准：组内标中心距，组间标定位；不要一半从左、一半从右。
- 槽标宽 + 深；深度放在能看见槽深的视图（通常是侧视/剖视）。
- 沉孔/沉头/螺纹孔用孔标注一次性带出，不拆成多个尺寸。
- 薄板多层台阶：相同尺寸合并成 `n×`，不要逐层标三遍。

### 5.3 回转体 / 轴承座 / 法兰

- 主视图取特征最多者；内部结构用剖视替换外形视图。
- 外形先标：外径 + 厚度（下料尺寸）。
- 轴向从一端面起标各台阶/轴承位；两端都有特征时，两边分别标，中间凸起不能共用一个尺寸。
- 孔系：PCD + 孔数 + 孔径；均布加 EQS 或角度。
- 箭头可调朝内，减少尺寸线伸出；公差/形位/粗糙度最后加。

### 5.4 齿轮 / 盘类

- 齿轮参数表放右上角，不在视图上逐个标齿形尺寸。
- 视图上标：齿顶圆/分度圆（必要时）、宽度、中心孔、键槽、轮毂。
- 同心直径多时，人工出图优先用引线，避免圆心交叉（见 §4.5）。

### 5.5 钣金

- 标折弯方向、折弯角度、折弯半径、边距；展开尺寸可作参考尺寸加括号。
- 孔/切口标到折弯线的距离，不标到虚拟尖角。
- 未注折弯半径在技术要求统一说明。

### 5.6 箱体 / 壳体

- 安装底面 + 两定位孔作主基准；孔系用坐标尺寸或中心距。
- 主视图 + 剖视表达内部；壁厚、筋厚单独标。
- 毛坯面与加工面每方向最多一条尺寸联系；加工面之间可连续标。

## 6. 标注格式速查

| 结构 | 写法 | 要点 |
|---|---|---|
| 45° 倒角 | `C2` 或 `2×45°` | 非 45° 必须标角度 |
| 退刀槽 | `2×φ8` 或 `2×1` | 前者 2 是槽宽，不是个数 |
| 螺纹孔 | `3×M6-7H 深10` | 不标深度默认通孔；深度不含锥角 |
| 沉孔 | `4×φ6.4 沉孔φ12 深4.5` | 小径 + 大径 + 深度三要素 |
| 锪平孔 | `4×φ9 锪平φ20` | 不标深度，锪到毛坯面 |
| 埋头孔 | `6×φ7 埋头φ13×90°` | 大径 + 锥角 |
| 均布孔 | `6×φ4 EQS` | 只标一次 |
| 球面 | `Sφ30`、`SR24` |  |
| 厚度 | `t6` |  |
| 正方形 | `36×36` 或 `□36` |  |
| 对称槽 | 槽宽 + 槽深 | 宽在槽特征最明显视图 |

完整的“标什么”清单见 `drawing-standards.md` §3.2 与 §3.4。

## 7. 交付前自检

### 7.1 机器检查

```bash
py -3.12 "<skill>\scripts\sw_three_view.py" --part "<part>" --out-dir "<out>" --dims
py -3.12 "<skill>\scripts\check_drawing_pdf.py" "<out>\<part>_drawing.pdf"
```

通过线：

- `dimension_placement.status == "pass"`，且 `verified_count == placed_count`。
- `placed[]` 中无 `issue == "NO_FEASIBLE_SLOT"`；`BAND_CROWDED` / `RADIAL_CROWDED` 逐条目视后放行。
- `check_drawing_pdf.py` 的 fail 级 finding 为 0（`DIM_NO_LEADER`、`DIM_FLOATING`、`OUT_OF_FRAME`）。
- 警告级（`TEXT_OVERLAP`、`TEXT_ON_VIEW`）逐条看，不自动放行。

### 7.2 人工 60 秒

- [ ] 总体尺寸在最外圈，小尺寸在里圈，没有反层级
- [ ] 没有一条尺寸线钻进轮廓内
- [ ] 没有数字被任何线穿过（含中心线、尺寸界线）
- [ ] 同一侧没有两条共线的尺寸线
- [ ] 每个特征只标一次；对称结构没拆成两半
- [ ] 每个方向尺寸链有开口；重要尺寸直接标、带公差
- [ ] φ/R 没混用；R 没过圆心、没乘数量；数量写在 φ 前
- [ ] 尺寸集中在最清晰视图；没有标在虚线/相贯线上
- [ ] 中心线出头 3–5 mm；标题栏、技术要求区没被压
- [ ] 尺寸数与模型特征数匹配，没有整片漏标

## 8. 不要做

1. 不要把尺寸放进视图轮廓内“省地方”。
2. 不要让数字压在任何图线上，也不要靠“线断开”蒙混。
3. 不要在同一层放两条区间重叠的尺寸线。
4. 不要把大尺寸放内层、小尺寸推外层。
5. 不要把对称尺寸拆成两个半距。
6. 不要形成封闭尺寸链；不要把所有分段都标上再加总长。
7. 不要在相贯线、截交线、虚线上标尺寸。
8. 不要重复标同一尺寸，也不要漏掉配合尺寸的公差。
9. 不要用 `φ10×2`、`4×R5` 这类格式。
10. 不要用自动排版的 `pass` 代替目视；PDF 检查器看不到共线与层级。
