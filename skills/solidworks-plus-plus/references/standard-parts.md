# 标准件与外购件（建模策略 + 常用数据）

适用：图纸上出现螺栓、螺母、垫圈、键、轴承、齿轮、弹簧、链轮、销时。
原则：**标准件按标准值建，不按图面比例猜；能用简化画法就不做真实牙型。**

> 数值来源：GB/T 5782、GB/T 6170、GB/T 97.1、GB/T 5277、GB/T 1095/1096、
> GB/T 276、GB/T 1356、GB/T 1243 等。下表是**常用规格速查**，不是全表；
> 交付前若用户给了具体标准年号，以用户标准为准。查不到就列入问题清单，不要编。

**外购件先查后建**：螺栓、螺母、轴承、齿轮、弹簧、链轮等可购买件，先按标准系列
查表（本文件或厂商数据）确认规格存在，再建模；查不到就记录“未命中”并向用户
确认替代方案。**不许随手画一个形状相似的占位件当标准件交付**。确实需要占位
（如选型未定）时：零件名加 `PLACEHOLDER`、交付说明单列，并且不得用占位件的
几何做装配干涉或强度结论。

## 1. 建模策略（先选路线）

| 零件 | 建模路线 | 不要做 |
|---|---|---|
| 六角头螺栓 | 六角头拉伸 + 光杆 + 螺纹段（装饰螺纹） | 真实螺旋牙 |
| 内六角螺钉 | 圆柱头 + 六角沉孔切除 + 光杆 | 真实内螺纹 |
| 螺母 | 六角拉伸 + 中心孔 + 倒角 + 装饰螺纹 | 真实螺旋牙 |
| 垫圈 | 圆环拉伸 | 倒角细化 |
| 平键 | 长方体 + A/B/C 型端部 | 键槽配作 |
| 轴承 | 内圈 + 外圈 + 滚动体（简化） | 保持架、真实滚道 |
| 齿轮 | 轮坯旋转 + 齿形（精确或简化） | 逐齿手画 |
| 压缩弹簧 | 螺旋路径 + 圆截面扫描 | 用圆环堆叠代替 |
| 链轮 | 轮坯 + 齿槽阵列 | 真实链条 |
| 销 | 圆柱/锥体 | 真实倒角 |

**装配体里的标准件**：一个零件一个实体；螺栓、螺母、垫圈分别建，不要在装配体里合并。

## 2. 螺纹：装饰螺纹优先

- 工程图只需要螺纹的大径/小径线和标记，**不需要真实螺旋牙**。
- SolidWorks 用“装饰螺纹线”（Cosmetic Thread）表示；出图自动按 GB/T 4459.1 画细实线。
- 精确模式：底孔直径按表；螺纹段长度按标准；标记写全（M8-6H 深20）。
- 示意模式：光孔 + 注释即可，不建螺纹特征。
- 只有用户明确要求“可打印的真实螺纹”时才做螺旋切除，并在交付说明里写清牙型/螺距/精度。

| >12～17 | 5×5 | 3.0 | 2.3 | 10～56 |
| >17～22 | 6×6 | 3.5 | 2.8 | 14～70 |
| >22～30 | 8×7 | 4.0 | 3.3 | 18～90 |
| >30～38 | 10×8 | 5.0 | 3.3 | 22～110 |
| >38～44 | 12×8 | 5.0 | 3.3 | 28～140 |

| >50～58 | 16×10 | 6.0 | 4.3 | 45～180 |
| >58～65 | 18×11 | 7.0 | 4.4 | 50～200 |
| >65～75 | 20×12 | 7.5 | 4.9 | 56～220 |
| >75～85 | 22×14 | 9.0 | 5.4 | 63～250 |
| >85～95 | 25×14 | 9.0 | 5.4 | 70～280 |
| >95～110 | 28×16 | 10.0 | 6.4 | 80～320 |

建模：

1. 键：长方体 `b×h×L`；A 型两端加半径 `b/2` 的圆头（总长仍为 L）。
2. 轴槽：在轴的外圆柱面上切 `b×t` 的槽，长度 L；用偏置基准面或 Top 面下刀。切除方向要指向材料内部——切除的 `direction` 与拉伸语义相反（`True`=+法向、`False`=−法向，2026-10-24 实测）；偏置面贴在材料外端时用 `direction=False`。
3. 毂槽：在轮毂孔内壁切 `b×t1`，与轴槽对齐。
4. 键槽宽度公差：轴槽 N9，毂槽 JS9；深度公差按 GB/T 1095。
5. 标记：`键 10×50 GB/T 1096`（A 型省略 A；B/C 型写 `键 B10×50`）。

**坑**：轴槽深 t 是从**轴的外圆表面**量到槽底，不是从轴线量；毂槽深 t1 是从**孔壁**量起。
SolidWorks 里用“从面偏置”的切除深度最容易对。

## 6. 直齿圆柱齿轮

### 6.1 基本参数与公式

| 参数 | 符号 | 公式 |
|---|---|---|
| 模数 | m | 由强度/标准系列选 |
| 齿数 | z | 由传动比定 |
| 压力角 | α | 标准 20° |
| 分度圆直径 | d | `d = m·z` |
| 齿顶圆直径 | da | `da = m(z+2)` |
| 齿根圆直径 | df | `df = m(z−2.5)` |
| 齿顶高 | ha | `ha = m` |
| 齿根高 | hf | `hf = 1.25m` |
| 全齿高 | h | `h = 2.25m` |
| 齿距 | p | `p = πm` |
| 中心距（外啮合） | a | `a = m(z1+z2)/2` |

标准模数系列（第一系列）：1, 1.25, 1.5, 2, 2.5, 3, 4, 5, 6, 8, 10, 12, 16, 20。

斜齿轮：`d = m_n·z / cosβ`，`da = d + 2m_n`，`a = (d1+d2)/2`；
端面模数 `m_t = m_n / cosβ`。

### 6.2 建模路线

1. 轮坯：旋转（外圆 da、内孔、轮毂、辐板）。
2. 齿形：
   - **精确**：按渐开线方程画单齿，拉伸/放样，圆周阵列 z 个。
   - **简化（示意/普通出图）**：用梯形齿或圆弧近似，保证 da、df、d 三个圆正确。
3. 齿根圆角：R0.38m（标准齿根圆角），最后加。
4. 参数表：右上角列出 m、z、α、精度、变位系数、公法线长度。

**红线**：模式 B 且用户要求“可加工齿轮”时，齿形必须按渐开线或标准齿条范成，
不能用梯形齿冒充；交付说明写清齿形精度。

### 6.3 齿轮图纸标注

- 分度圆用细点划线，齿顶圆粗实线，齿根圆细实线（剖视）或省略（视图）。
- 参数表：m、z、α、精度等级（GB/T 10095.1）、齿厚/公法线、材料/热处理。
- 啮合图：节圆点划线相切，齿顶圆一粗一细。

## 7. 压缩弹簧

### 7.1 参数

| 参数 | 符号 | 关系 |
|---|---|---|
| 簧丝直径 | d | 标准系列 0.3～10 |
| 中径 | D | `D = (D1+D2)/2` |
| 外径 | D2 | `D2 = D + d` |
| 内径 | D1 | `D1 = D − d` |
| 有效圈数 | n | 设计给定 |
| 总圈数 | n1 | 两端并紧磨平 `n1 = n + 2` |
| 节距 | t | `t = (H0 − 1.5d)/n` |
| 自由高度 | H0 | `H0 = n·t + 1.5d`（两端并紧磨平） |
| 旋向 | — | 默认右旋，左旋标 LH |

`t` 和 `H0` 只能先定一个：设计通常给 `H0` 和 `n`，用 `t=(H0−1.5d)/n`
反算节距；若先定节距，再用 `H0=n·t+1.5d` 求自由高度。两个都当已知会自相矛盾。

刚度：`k = G·d⁴ / (8·D³·n)`，弹簧钢 G ≈ 79 000 MPa。
应力：`τ = 8FD/(πd³)·K`，`K = (4C−1)/(4C−4) + 0.615/C`，`C = D/d`（常用 5～10）。

### 7.2 建模路线（L3，需验证）

1. 草图画圆 φd（簧丝截面），圆心在螺旋起点。
2. 建螺旋线：中径 D、节距 t、高度 H0、起始角 0、右旋。
3. 扫描：圆截面沿螺旋线扫掠，`twist=0`，保持法向。
4. 两端磨平：用两个平行平面切掉端部，切后高度 = H0。
5. 出图：主视图全剖/半剖，左视图画 D2 圆和 d 圆，参数表列出 d、D、H0、n、n1、旋向。

**当前限制**：本机 `sw_part.py` 没有经过真机验证的螺旋线/扫描封装。
执行前先查 `capabilities.yaml`；未验证时用 SolidWorks 界面建一次，
记录菜单路径和参数，再补脚本。**不要凭记忆拼 `InsertHelix`/`InsertProtrusionSwept` 签名。**

示意模式替代：用“圆柱 + 螺旋装饰线”或直接画 2D 弹簧示意图，交付说明标注“非实体弹簧”。

## 10. 标准件交付检查

| 检查 | 通过标准 |
|---|---|
| 规格 | 与图纸标记一致（M10×50、6204、键 10×50） |
| 关键尺寸 | 对边/头高/内径/外径/宽度与上表一致，误差 ≤0.1 mm |
| 螺纹 | 装饰螺纹线存在，标记正确；没有真实螺旋牙（除非用户要求） |
| 通孔 | 与螺栓规格匹配（M8 → φ9 中等装配） |
| 沉孔 | 大径/深度正确，开在有材料的一面 |
| 键槽 | 宽 b、深 t/t1、长度 L 正确，轴槽与毂槽对齐 |
| 轴承 | d/D/B 正确，内圈随轴、外圈固定 |
| 齿轮 | da/d/df 三个圆正确，参数表齐全 |
| 装配 | 标准件是独立零件，未与主体合并；配合面无干涉 |
| 属性 | 零件名/代号/材料/数量写入自定义属性，供 BOM 使用 |

## 11. 不要做的事

- ❌ 按图面像素比例猜标准件尺寸（图上没标就查表）。
- ❌ 把 M8 螺栓画成 φ8 光杆就交（缺少头型、螺纹标记）。
- ❌ 用真实螺旋牙做标准螺栓（模型巨大、出图不需要）。
- ❌ 轴承画成实心圆柱（剖视图无法表达内外圈）。
- ❌ 齿轮只画齿顶圆，不画分度圆/齿根圆。
- ❌ 键槽深度从轴线量（应从外圆/孔壁量）。
- ❌ 沉孔开在无材料的悬空面（切除会返回 `None`）。
- ❌ 在装配体里把螺栓和法兰合并成一个实体。
- ❌ 没查标准表就画一个“看起来像”的占位件，当标准件交付或拿去做装配结论。
