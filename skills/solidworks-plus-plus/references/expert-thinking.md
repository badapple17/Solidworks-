## 1. 读图思维（先看懂，再建模）

### 1.1 四步流程

1. **初步了解，判组合形式**：以反映形状特征最多的视图入手，粗判叠加式还是切割式。
   判据：叠加式——各封闭线框能各自独立对应成基本体；切割式——把缺角补齐后外形是
   完整基本体（长方体等）〔工3；工CAD；画几3D〕。这一步决定第 2 节主用哪种方法，写下来。
2. **分线框**：线框=首尾相连不相交的封闭平面图形。每个线框可能是面（平/曲）、
   平面+曲面相切组合、或孔；相邻线框必不同面；相邻线框在另一视图合成一个大线框时
   **先按“一个基本体”合并考虑**，试不通再细分（防过度切分）〔画几3D；机制〕。
3. **对投影定含义**（“长对正、高平齐、宽相等”配对后逐条判）：
   - 定面：**若无类似形，必有积聚性投影**（n 边形类似形仍是 n 边形，圆仍是椭圆）〔机制；工3〕。
   - 定线：图线只有三种含义——两表面交线 / 曲面转向轮廓素线 / 面的积聚投影〔工3；机制〕。
   - 定孔：线框在另一视图对应两条虚线或同轴小圆 → 孔/洞〔画几3D；工3〕。
   - 定前后凹凸：相邻线框借可见性配对；主视图左右相邻线框在左视图“两实线：右框在前”、
     “一实一虚：左框在前”〔机制〕。
   - 定表面连接：平齐无线、不平齐有线、相交有线（交线）、相切无线〔工3〕。
4. **综合想整体，默画对照**：把想象出的组合体默画成视图，与给定视图逐处对照修正
   〔机制〕。建模后这一步就是 §5 的反投影核对。

典型错误：只看一个视图就下结论〔机制〕；机械细分线框而不先试“基本体假设”。

### 1.2 形体分析 vs 线面分析：选法与切换信号

| 判断 | 选择 | 理由（出处） |
|---|---|---|
| 叠加特征明显，各线框独立对应基本体 | 形体分析法 | 主要适用于叠加式组合体〔机制；工3〕 |
| 以挖切为主，补缺角后是完整基本体 | 线面分析法 | 主要适用于挖切体〔机制；岗位〕 |
| 大体叠加、局部看不懂 | 形体分析为主 + 局部线面分析 | 〔工CAD〕 |
| 遇到难分形体或其交线 | 对局部用线面分析 | 〔机制〕 |

线面分析挖切体固定套路：先复原未挖切形体 → 逐个找截平面的积聚性投影（每个线框对应
某视图一条斜线/直线 = 一次切割）→ 分析切割面间交线（注意一条线可同时是两条交线的投影）
→ 综合〔机制；工3〕。

切换信号（建模 agent 操作化）：
- 线框在另一视图找不到完整类似形（只有积聚线）→ 斜切面，停柱体假设，转线面分析。
- 视图出现非圆曲线且两侧形体关系不明 → 截交线/相贯线，先分析产生交线的两个基本体，
  **不直接拟合曲线**〔画几3D〕。
- 对应关系多解 → 用类似形/可见性规则消歧，消不掉 → 问。

### 1.3 特征视图与“第一张草图选哪个视图”

- 形状特征视图 ≠ 主视图：各形体的特征视图可能分散在不同视图〔工3；机制〕。
- 位置特征视图：圆形/方形凹凸只靠主俯两视图无法判，第三视图才定——经典凸台/凹坑判据
  〔工3〕。
- **柱状体：特征视图 = 截面/端面轮廓实形视图**（线框端点是平行棱线投影）〔机制〕。
  因此第一张草图 = 形状特征视图的轮廓，拉伸方向 = 该视图投射方向。
- 各形体特征视图分散 → **先大后小分向拉伸**，多个拉伸特征分别建，不要一张草图装全部
  轮廓〔机制〕。
- 孔槽虚线明显 → 先建主体后补切（虚线剔除法）〔工3〕。
- 回转体例外：草图是半剖面+中心线，不是任何视图的完整线框〔工3〕。

典型错误：把位置特征视图当形状特征视图画草图；把主视图无条件当第一张草图。

### 1.4 多解与信息不足判定（建模前必过）

投影是多对一映射；判定“是否唯一”靠数约束。教材口径：**一个视图不能唯一确定；
两个视图仍可能不唯一；三视图齐全且无虚实线重影、无简化省略才“唯一确定”**〔工3；画几3D〕。

| 图上现象 | 消歧判据 | 消不掉时 |
|---|---|---|
| 一个封闭线框 | 孔→两虚线或同轴小圆；曲面→有转向轮廓线；面→有积聚线或类似形 | 问 |
| 线框 + 积聚性斜线 | 另两视图应同为 n 边类似形；不对→不是同一表面 | 问 |
| 相邻线框分界实线 | 不共面凸出（肋板一块）；虚线→前后相错（两肋板/凹槽）〔机制〕 | 问 |
| 圆/方凹凸不明 | 找位置特征视图（第三视图） | **必问** |
| 虚线 | 形状非常明显→先剔除读主体；深度/通盲无佐证 | **必问**（深度/通盲） |
| 细实线弧线 | 过渡线不与圆角接触、不到头；真交线与轮廓相接 | 问（决定是否建圆角） |
| 非圆曲线 | 视为相贯/截交线，按“两基本体+相对位置”重建让交线自动生成，不手画 | 两基本体形状/位置不定→**问** |
| 相切处无线 | 相切无分界线，建模用相切约束，不是漏画 | — |

工艺可行性关：读出的形体之间只有点/线接触 → 视图吻合也无法成型，要么读错了、
要么图是构型练习，**列入必问**〔工3〕。

### 1.5 尺寸完整性检查（生成缺失清单）

完整 = 长宽高三个方向定形+定位+总体齐全、不遗漏不重复〔工3；岗位〕。五个例外
（图上“没有”≠漏标）：
1. 总体尺寸可兼作某基本体定形尺寸；2. 一端为回转面时该方向不标总体（由轴线定位+
直径间接确定）；3. 截交线/相贯线上不标尺寸（基本体尺寸+位置定，交线自生）；
4. 括号参考尺寸不当真值用；5. 封闭尺寸链禁止——某分段无直接尺寸可能故意空出，
用“总长−Σ分段”推导即可；**缺口两处以上无法分配才是真信息不足**〔工3〕。

缺失清单五步：形体分解成基本体清单 → 每体列定形需求（棱柱=长宽高、圆柱=φ+高、
孔=φ+深/通）→ 每体列定位需求（每方向各一个，从该方向基准起标）→ 对照图纸逐项查、
套用五例外 → 能推导的标 `derived` 写推导式，不能推导的进“必须问”清单〔工3；岗位〕。

### 1.6 尺寸基准与建模原点

- 每方向一个主基准 + 可选辅助基准（两者必须有尺寸直接联系，没有→图纸有问题，问）
  〔工3〕。
- 按类型选：轴套/盘盖类 = 轴线 + 轴肩端面；叉架/箱体类 = 工作轴线、对称面、
  与部件连接的接触面〔工3〕。
- 读图反推：**重要尺寸（配合、孔中心高、安装孔距）直接注出且从设计基准起标**——
  图上从哪个面/轴起标的尺寸最重要，哪个就是设计基准，建模原点放那里，不是随便一角
  〔工3〕。
- 对称件原点放对称面；轴类原点放轴线+轴肩端面交点；箱体/支架高度原点放底面（安装面）。
- 定位尺寸从哪个基准起标，草图几何就相对哪个基准约束——照搬图纸标注方式可避免换算错。

## 2. 分解思维（拿到零件先想 5 分钟，再动手）

### 2.1 五步分析，顺序固定

标准视图 → 主要凸台 → **最佳轮廓** → 草图平面 → 设计意图，五步走完才新建文件。
前四步的输出直接决定“第一特征是什么、画在哪个面上”；跳步 = 整棵树建在错误地基上〔零件 P51–55〕。

- **最佳轮廓 = 一次拉伸能覆盖最多几何的主截面**。选小了特征数膨胀、依赖链变长；
  把细节轮廓（孔、槽、凸起）当起步轮廓，主体反而要靠后续特征拼出来〔零件 P52、P54〕。
- **把意图写成可验证断言**：如“所有孔是通孔；底部凹槽与基体凸起对齐；沉头孔与凸起
  圆面共享圆心”——每条断言都能映射到包围盒/孔位/同轴检查，成为后面的验收清单。
  意图只存在脑子里，改模时无从校验〔零件 P55〕。
- **草图平面三条判据**：①显示方位 ②装配体中的姿态 ③**模型前视 = 最终工程图前视**；
  三者冲突时优先第③条。出图后前视对不上 = 全部视图投影返工〔零件 P53–54〕。
- **原点与起笔**：先找对称（能用的对称尽量用），再找功能表面（配合面、圆形瓶颈、
  平基座）作起始位置——功能表面是已被外部锁死的区域，从它起步配合基准才不漂
  〔曲面 P25–26〕。
- **特征粒度 = 未来可压缩粒度**：按“将来哪些要单独改/压缩/重排”拆分；压缩父特征
  连带压缩全部子特征，单特征“一把抓”灵活性最低〔零件 P242、P247–248〕。

### 2.2 特征树统计的启发式（题库 198 个原生件实证，〔树统计〕）

格式：情境信号 → 首选建法 → 切换条件 → 证据。

- **R1 回转核判据**：剖面有回转中心线/同心圆组，或主体 = 绕轴轮廓回转 + 附加件 →
  旋转做首特征（剖面含全部台阶）；方截面/回转只是局部凸台 → 拉伸。证据：26/198
  旋转首特征中 13 例包围盒是块状（阀体 75×93.5×75）；近回转包围盒 31 例中拉伸 15
  对旋转 11——**包围盒不裁决，剖面裁决**。
- **R2 第一草图平面 = 图纸信息量最大的视图**：向最薄方向拉伸；L/U 形件侧剖面定形 →
  侧剖面为草图；多凸台共享底面 → 底面贴草图平面、向 + 轴拉伸（76/174 件满足）。
  证据：草图面分布随题库作者习惯变化（a64 以 Top 为主 27/34、sw150 以 Right 为主
  37/77）——不存在固定基准面，只存在“跟随视图”。
- **R3 特征粒度对齐图纸标注粒度**：整体异形轮廓 → 一草图一次拉伸/切除；逐段标注 →
  一尺寸一特征。证据：sw150 中位特征数 1（68% 单特征）对 a40 中位 8（箱体 35）；
  同尺寸件一个用 2 特征、另一个用 8 特征，无优劣。
- **R4 加减比例自检**：板类以加为主（74:11），块类约 3 增 2 减（352:244）；全局
  ADD:SUB = 502:295 ≈ 1.7:1。发现减特征远多于加 → 检查是否把“主体轮廓”错画成
  “切除留形”（主体用凸台表达，缺口才用切除）。
- **R5 主序列**：基体 → 主体凸台/切除 → 孔 → 筋 → 阵列/镜像 → 圆角/倒角。
  证据：HoleWzd 平均位置 0.71、Rib 0.75、Mirror 0.76、Fillet 0.74、Chamfer 0.77，
  修饰类全部集中在后 1/4。出现父子依赖才打乱（R6–R10 例外全有依赖理由）。
- **R6 孔与阵列**：标准孔在主体与筋完成后用 HoleWzd；重复孔先打 1 个紧跟阵列
  （种子 → 阵列 → 收尾）。证据：HoleWzd 34 例位置 0.71；阵列前是种子特征
  （Cut 16/Boss 17），阵列后 19 次直接收尾；麦克纳姆轮两级 CirPattern。
- **R7 回转体上的槽优先旋转切除**：环槽/卡簧槽/半圆座 → RevCut；直槽/键槽 → 普通
  拉伸切除；对称缺口 → 切+镜像。证据：RevCut 23 例位置 0.59；传动轴
  Rev → Cut×2 → Chamfer → Fillet 三拍。
- **R8 圆角两种身份，位置随身份**：装饰圆角放最后（103 例位置 0.74，31 例末位）；
  轮廓圆角紧跟基体；过渡圆角紧跟被过渡特征（阀体 5 个 Fillet 分散在特征间）；
  后续特征以圆角边为基准时圆角提前。证据：17 例早期圆角全部落入这三类。
- **R9 抽壳永远在壳内特征之前**：外形（可含轮廓圆角）→ Shell → 内部筋/凸台/切除/
  镜像；壁厚不一致 → 抽壳后补凸台，不用 Shell。证据：仅 2 例 Shell 均在前半程，
  从未见到抽壳在最后。
- **R10 镜像中置技术**：关于面对称且存在跨缝特征（中线上的孔、横贯凸台）→ 建半边
  → MirrorPattern → 再加跨缝特征；无跨缝特征 → 镜像放最后。证据：MirrorPattern 35
  例位置 0.76（14 例末位）；6 例中置（车身/炮塔/后壳）全在镜像后继续加特征。
- **R11 混合体模板：板基体 + 回转凸台**：拉伸板 → 紧跟旋转凸台（第 2 特征）→
  切除/孔；回转核占主体 → 旋转起步（R1）；两实体相交复杂 → 分别建模 +
  CombineBodies。证据：非首 Revolution 42 例位置 0.23。
- **R12 阶梯轴/套筒一次旋成**：剖面含全部轴段与倒角台阶 → 键槽/环槽切除 → 轴端
  倒角；逐段拉伸不推荐（特征数多、同轴度靠标注保证）。证据：26 例旋转首特征中
  13 例轴/套/轮坯类，均为 Rev → 切 → 倒角三拍。
- **R13 相同特征重复 ≥2 即阵列/镜像**：种子 1 个 → 阵列或镜像；尺寸/形状有差异 →
  逐个建；份数 2 且对称 → 用镜像。证据：联轴器修改版用 2 个 LPattern 替换 6 处
  手画槽。
- **R14 薄壁件专用薄壁特征**：等壁厚钣金罩 → ExtruThin/BossThin 或外形+Shell；
  普通实体件绝不用薄壁特征代替拉伸。证据：ExtruThin 仅 3 例、CutThin 6 例——
  少数派专用。
- **R15 裁决顺序（合成决策链）**：① 剖面有回转中心线/同心圆组且主体绕轴 → 旋转
  起步（R1）；② 否则找信息量最大的平视图 → 该面为草图、向薄方向拉伸（R2）；
  ③ 按图纸标注粒度拆特征（R3）；④ 主序列 R5，遇依赖按 R6–R10 调整；
  ⑤ 重复 ≥2 阵列（R13）。

## 3. 选型思维（同一形状多种建法怎么选）

**总判据不是“哪种快”，而是“改动将如何传播”**〔零件 P16–17〕。教材明言“没有完全标准
的答案”——答案藏在需求里；需求没给就停下来问（§6），不要背一个“标准做法”生搬硬套。

### 3.1 选型判据排序

改动传播 > 重建代价（少父/子引用、优先简单特征）> 特征数量〔零件 P16–17；曲面 P59–66〕。

| 情境信号 | 首选 | 备选/理由 |
|---|---|---|
| 阶梯轴，长期维护 | 制造法（棒料+系列切除）或层叠法 | 单旋转信息集中、一处改动牵动全部，只适合一次成型不再改的示意件〔零件 P16–17〕 |
| 等壁厚旋转/拉伸体 | 开环轮廓 + 薄壁特征 | 形状复杂、内外都要圆角才走“实心→圆角→抽壳”〔零件 P191–192〕 |
| 薄壁件底面必须平 | 封闭体积→缝合→圆角→抽壳 | 加厚=偏移+放样，弯曲面偏移后底边不平；抽壳壁厚须 < 圆角半径〔曲面 P29–31、P37〕 |
| 锐边过渡 | 圆角加到**实体**上，同半径合并一次命令，先大后小 | 草图圆角改一处漏一处〔零件 P52、P64、P66–67〕 |
| 标准紧固件孔（沉头/锥孔/螺纹） | 异形孔向导（带规格语义，装配可配智能扣件） | 纯形状孔/槽才用草图切除〔零件 P62–63〕 |
| 同一特征多次出现且有规律 | 阵列（改源即改全部实例） | 个别且需独立修改才复制粘贴〔零件 P116–120〕 |
| 终止位置由已有几何决定 | **成形到下一面**（目标会动） | 盲深=把几何关系硬编码成数值；成形到一面 vs 下一面在角度面上结果不同〔零件 P61、P95–96〕 |
| 变截面/沿路径杆件 | 截面恒定→扫描；截面显著变化→放样 | 扫描=一个轮廓+一条路径，信息结构最小〔零件 P157–159〕 |
| 曲面同形四法（成形到面/使用曲面切除/替换面/删除面） | 按重建代价选（教材实测使用曲面切除多一步却最快 1.78s，因不建新引用） | 问自己“这步引入了什么引用”〔曲面 P59–66〕 |
| 补洞/封口 | 四边开口→边界曲面；窄条→放样（长边界当轮廓）；不规则多边→填充曲面 | 放样引导线不支持曲率连续，只轮廓支持〔曲面 P103–106〕 |
| 放样方案有疑 | 建两版（引导线版 vs 中心线版）并列对比曲率定案 | 只建一版凭渲染图定案，局部凹陷发现不了〔曲面 P152–155〕 |
| 实体特征相同步数能出结果 | 用实体，不上曲面 | 曲面必须手动剪裁缝合；避免模型留开放曲面〔曲面 P21–22〕 |

### 3.2 草图里的意图编码（背数值 = 埋雷）

- 先画近似几何 → 加几何关系 → 最后标尺寸；尺寸先小后大、先近后远〔零件 P31、P39–41〕。
- 同一数值出现多次、或“对齐/同心/相切/对称”意图 → 用**几何关系**表达，不用重复数值；
  改一处全联动 vs 改一处漏一处〔零件 P46、P55、P195〕。
- 孔定位三种标注法语义完全不同：①到两对边各标距离=孔跟随边界；②只对一边标=孔位
  固定；③标孔心距=保证孔间距。板宽变化时三者行为不同——**标注方式就是设计意图的
  编码，先问“哪个尺寸以后会变”再选基准**〔零件 P16〕。
- 从原点起笔（自动重合、少一个自由度）；对称件画中心线+半边再镜像，半边不跨中心线
  〔零件 P46、P89–90〕。
- 回转件：显式选中心线为轴；轮廓不穿轴；标注选中心线+外侧线（光标在中心线哪侧决定
  半径/直径）〔零件 P150–152〕。
- **完全定义是交付门槛**：欠定义可建特征，交付前每个草图必须完全定义（黑）；
  过定义（红）先诊断再删冲突，无解删关系重加〔零件 P33、P78–79〕。

### 3.3 顺序与稳健性

- **顺序三铁律**：孔排在抽壳之后、圆角先于抽壳（R外>t 内圆角自动生成）、装饰圆角
  最后。任何一条反了都是“看不见但改不掉”的返工〔零件 P230、P184–185、P64〕。
- **父子关系 = 草图画在谁的面/边上**：草图尽量画在基准面而非模型面上；压缩父特征
  连带全部子特征；子不能排到父之前〔零件 P242、P220〕。
- 外部引用按源稳定性选层级：**面 > 单条边 > 硬编码数值**〔零件 P101、P193、P189–190〕。
- 编辑优于删除重建（删除丢工程图/装配引用）；镜像/阵列实例是从源派生的，改源不改
  实例〔零件 P217、P129–131〕。
- 特征顺序 = 影响范围控制：按“后面特征看到的前面几何”排，不按图纸尺寸出现顺序排；
  重排前先移除依赖〔零件 P222–223、P228–230〕。

### 3.4 回转体轮廓：圆弧/样条 > 密采样折线

薄壁回转件（瓶、杯、套）的母线不要把 smoothstep 等函数密采样成上百段折线：几何上
“看着光滑”，模型上每段之间都是真实棱边（预览/工程图出现几十道环线），且折线端点
容易被草图推理吸附打断（`pitfalls.md` §4）。

- **首选两段相切圆弧**（几何精确、可解析验算）：直筒段与凸弧竖直相切、颈部与凹弧
  竖直相切、两弧在拐点外切。已知半径差 Δr、高度差 Δh：
  `R1+R2=(Δr²+Δh²)/(2Δr)`，`C1=(r0−R1,y0)`、`C2=(r1+R2,y1)`，切点 T 在 C1C2 连线上
  距 C1 为 R1；R1 取两半径和的 0.5~0.6 倍即可定形。
- 形状有多个拐点/非圆约束时用样条：6~10 个控制点，端点补相切关系。
- 密采样折线只作示意占位，必须 `exact=True`，并在交付说明标“折线近似、肩部有棱边”。
- 直线/圆弧轮廓的体积可用 Pappus 定理解析验算（§5 第 12 条）。

## 4. 功能思维（这零件靠什么“活着” → 哪些尺寸关键 → 没给的怎么填）

判断尺寸是否关键，先走功能链，再套五判据：**关键档缺信息 → 问；次要档缺信息 → 按
公式推荐**（推荐也必须写出处与适用条件，见 4.7 纪律）。完整数值表见
`digests/thinking_design_function.md`，本节是操作版。

### 4.1 功能 → 结构 → 尺寸推理链

**判断**：拿到零件先归族，再问它靠什么“活着”。
**选择**：按链条走：四族 → 功能 → 载荷类型（拉压/弯/扭/接触/摩擦）→ 主要失效形式
（整体断裂〔机械零件断裂大部分为疲劳〕/过大变形/表面破坏/破坏正常工作条件）→ 设计准则
（强度/刚度/寿命/振动稳定性/可靠度）→ 结构 → 关键尺寸〔机设 2.4〕。

| 零件族 | 结构特征 | 建模主策略 |
|---|---|---|
| 轴套类 | 圆柱面为主 + 键槽/退刀槽/倒角/螺纹 | 旋转/制造法（凸台+切除） |
| 轮盘类 | 短粗回转体 + 轮辐/轴孔/键槽/螺孔 | 旋转 + 切除（孔系+辐板） |
| 叉架类 | 不规则肋板主体，工作部分常为孔/叉 | 主体凸台 → 连接筋/肋 → 孔 |
| 箱体类 | 空心铸件 + 轴孔/螺孔/凸台/凹坑/肋板 | 外形 → 抽壳 → 孔系 → 筋 → 圆角 |

**理由**：族决定毛坯与加工方法，加工方法反过来决定必须有的结构要素（退刀槽、拔模、
铸造圆角，见 4.6）；“毛坯类型、工艺、标准”正是推荐缺失尺寸的依据来源，不是随机值
〔识图2 表4-5；机设基 绪论〕。

### 4.2 功能面三分类（哪些面重要、哪些面自由）

1. **功能面（工作面/配合面）**：执行功能或与相邻件配合的面。例：支承轴颈 IT5~7、
   配合轴颈 IT6~9〔结构工艺 11.3.2〕；箱体轴承支承孔 IT6~7、装配基准面 Ra0.63~2.5μm
   〔结构工艺 13.1.2〕。→ 必须问或查标准。
2. **安装基准面/定位面**：决定整件在机器中位置（箱体底面/导向面）；装配基准与加工
   定位基准应一致，基准重合消除基准不重合误差〔结构工艺 13.1.2；制造 5.1.1〕。
   → 决定建模原点（§1.6）。
3. **自由面（非加工面）**：其余面（例：箱体“其他平面 Ra2.5~10”档）→ 错了只影响
   外观/重量，可用 4.5 公式推荐。

### 4.3 关键尺寸五判据（该问还是该推荐的分界线）

| # | 问一个问题 | 是 → 关键尺寸（必问/必查/必算） | 否 → 次要尺寸（可推荐默认值） | 出处 |
|---|---|---|---|---|
| 1 | 它是否决定功能/传动/配合性质？ | 配合轴颈、支承轴颈、轴承孔、孔系中心距（啮合侧隙）、键槽宽深、凸轮工作面 | 外观圆角、非加工面形状、倒角大小 | 结构工艺 11.3.2、13.1.2 |
| 2 | 它是否与标准件/系列件互换？ | 轴承轴颈=内径系列；轴头=标准直径系列；螺纹/键/退刀槽查表；轴颈长=轴承宽 | 非配合轴身直径（取整数即可） | 机设 13.2.4 |
| 3 | 它是否影响强度/寿命/刚度？ | 危险截面直径、键槽削弱修正、过渡圆角 r（应力集中）、过盈配合处结构 | 同轴其余轴段圆角（统一即可） | 机设 13.2.3 |
| 4 | 它是否影响装配/装拆/定位可靠性？ | 轴肩高 h 与 r<C<h 关系、轴承定位轴肩（要能拆轴承）、轴头比轮毂短 2~3mm、扳手空间、定位销直径 | 非定位轴肩高度（1~2mm 惯例） | 机设 13.2.2/13.2.4/13.2.5 |
| 5 | 它是否约束整机外形/安装？ | 总长总宽总高、安装孔位、中心高 | 内部退刀槽宽度、越程槽 | drawing-standards.md §3 |

旁证（加工视角）：工艺路线“先主后次”——主要表面 = 装配基面和工作表面，次要表面 =
键槽、紧固光孔和螺纹孔；**能进“主要表面”名单的尺寸就是关键尺寸**〔制造 7.2.5〕。

### 4.4 必问清单 vs 可推荐清单

**必问**（图/照片没给且无法由标准件反推，命中 §6 设计侧即停手提问）：
1. 配合面直径与公差等级（轴承轴颈、配合轴颈、孔系）。
2. 孔系中心距/啮合相关尺寸（有啮合关系的孔以彼此中心为设计基准）。
3. 安装孔位置与规格、总长总宽总高、中心高。
4. 键槽/螺纹/轴伸等标准接口规格（影响相邻件互换）。
5. 轴肩定位关系：轴上装哪些件、装配方向——决定阶梯顺序与轴肩高度。

**可推荐**（用 4.5 公式 + 交付注明“按《书名》X.X 推荐，适用条件…，待用户确认”）：
轴肩高度、非定位轴肩、轴环宽、轮毂直径/长度、倒角圆角、退刀槽/越程槽（查标准）、
铸件壁厚与筋厚、箱体凸缘与螺栓布局、钣金圆角与孔边距。

校验规则：尺寸必须完整（总长=Σ分段校验），但不得形成封闭尺寸链；同一数值多次出现
用几何关系表达（§3.2）。

### 4.5 经验公式速查（按“哪个量已知”选公式）

### 4.6 工艺约束 → 特征选择

- **机加**：磨削段留砂轮越程槽（GB/T 6403.5）、螺纹段留退刀槽（GB/T 3）、轴端倒角；
  轴上圆角/退刀槽/倒角各取相同尺寸；铣槽圆角=铣刀半径、槽越深 R 越大、避免封闭槽；
  斜面钻孔会钻偏/断钻头 → 设垂直凸台（D=d+2~4mm）；过盈轴段与其余段直径不同
  （避免擦伤、便于装卸）〔机设 13.2.5；禁忌 18 章；结构工艺 9.2〕。
- **铸造**：拔模 → 圆角 → 孔；壁厚均匀不突变（内壁<外壁、壁厚在最小~临界之间）；
  加工面凸台高出非加工面；转角避免锐角（十字改 T 形）；筋不阻碍收缩〔结构工艺 9.2；
  禁忌 9.5〕。
- **钣金**：等厚件用薄壁/钣金特征；孔避开弯曲线；边缘缺口的弯曲件留连接带
  〔结构工艺 7.2.4〕。
- **焊接**：不模仿铸件——平板+型钢直线轮廓拼接，焊缝不建模；焊缝避开折弯处；
  焊接箱体壁厚=铸造值 1/2~4/5〔禁忌 12 章；结构工艺 8.2〕。
- **装配**：不允许装不上/拆不下；避免两配合面同时装入（依次装入的阶梯孔）；留扳手
  空间；对称结构简化装配〔机设 2.6.1；禁忌 19 章〕。

### 4.7 执行纪律（推荐默认值的规矩）

1. **判断**信息属于 4.3 哪一档：关键档缺 → 提问；次要档缺 → 按 4.5 推荐。
2. **选择**公式先找“已知量”：已知 d → 轴类公式；已知 a → 箱体全套；已知 t → 钣金圆角。
3. **理由**必须写进交付报告：`该尺寸按《书名》X.X 经验公式推荐：h=(0.07~0.1)d=…，
   适用条件…，待用户确认`。禁止出处不明的“常见值”。
4. 两书数值不一致（非定位轴肩 1~2 vs 0.5~3mm、铸铁轮毂 1.7 vs 1.8 等）→ 取更保守/
   更常用者并注明另一说。
5. OCR 残缺表格不抄 → 标“存疑”并指路标准号（GB/T 6403.4、GB/T 6403.5、GB/T 3、
   JB/ZQ 4254~4257、GB/T 1243），宁可查标准也不抄残缺值。

## 5. 自检思维（专家怎么发现自己错了）

1. **心算体积先行**：任何零件都能按“基本体体积±孔槽”心算期望体积，脚本断言差
   >0.1% 即停。孔漏切、缺口没开、凸台高度错，包围盒看不出来，体积立刻露馅
   （实测：拖拉机左轮埋进车身，视觉审查 100 分，体积/实体数门禁抓到）。
2. **反投影核对**（读图的逆循环）：先大后小 → 先实线后虚线 → 逐线框核对三等关系 →
   线数性质核对（平齐无线/相交有线/相切无线）→ 点线接触排除〔工3；机制〕。
   线型差异（相贯线/过渡线简化）允许，轮廓差异不允许。
3. **逐特征回读**：每个特征调用后检查返回值，`None` 即停；方向不确定先做一个特征
   回读 `GetPartBox(True)`。
4. **视觉审查 ≠ 几何正确**：预览打分 100 分也可能有埋进主体的特征，以机器门禁
   （体积/实体数/包围盒）为准，预览只作人工复核。
5. **补第三视图的顺序即验证顺序**：先主后次、先外后内、每步守三等关系〔机制；岗位〕。
6. **逐步检查不攒尾**：曲面/复杂件每完成关键几何立即查（开环边线、短边线、最小曲率
   半径点）——坏几何会传导给所有依赖特征，攒到最后错误已扩散〔曲面 P26–27〕。
7. **特征落定前看预览**：方向、成形到下一面到没到位、拔模勾没勾反——方向类错误
   重建最贵，预览一眼可挡〔零件 P43、P95〕。
8. **用“能拖动吗”验证约束**：颜色是状态提示，拖动是行为验证；欠定义可拖、完全定义
   拖不动〔零件 P35〕。
9. **错误级联从最早修起**：先修特征树最上面的错误（红=失败、黄=几何生成但有隐患），
   下游常自动恢复；跳过早期错误直接修下游 = 反复重建〔零件 P201–204〕。
10. **数值化验收不用目测**：曲面看最小曲率半径（≈0.0002mm 直接否决）与斑马条纹
    连续性；应力看 FOS < 1 不安全；“看着光”不算合格〔曲面 P89–90；零件 P168–173〕。
11. **改参后显式重建再验证**：改尺寸不重建是自动化最常见的静默失败源；
    交付前按需开“重建模型时验证（高级实体检查）”全量重建一遍再关（常年开=性能灾难）
    〔零件 P78–79；曲面 P26–27〕。
12. **回转体体积用 Pappus 定理独立验算**：闭合材料剖面（外轮廓 + 内腔，含壁厚）的有向
    面积 A 与形心半径 x̄ 满足 `V=2π·x̄·A`；直线/圆弧细分离散后按多边形累加，圆弧用
    300~500 点。与 SW 读数比，差 >0.1% 即停。2026-10-25 实测两段圆弧水瓶
    （66×235，材料 51.382 ml）：SW 51381.767 mm³ vs 解析 51381.777 mm³，差 2×10⁻⁷。

## 6. 该问的时刻（汇总判据，命中即停手提问）

通用六条（`modes-and-questions.md` §2.1）：改拓扑的 / 改接口的 / 改包络或关键功能尺寸
且不可推导的 / 用户目标冲突的 / 对象本身不清的 / 关键结构读不懂的。

读图侧十条（教材判据，本文 §1.4、§1.5 展开）：
1. 视图数 < 3 且非轴测图——任何“补全”都是猜（等厚板、光轴等教材明示可省略视图的
   简单件除外，此时明确假设并标 `assumed`）〔工3〕。
2. 圆/方凹凸无任何视图可判（位置特征视图缺失）。
3. 虚线表达的深度特征（通孔/盲孔/背面凸台）无剖视或另一视图佐证。
4. 同一线框按 §1.4 表核对后仍有两种以上解释。
5. 三视图存在实虚线重影，两种解释都合法。
6. 尺寸缺项且不可推导（过 §1.5 五步清单后仍缺）。
7. 尺寸链不闭合，缺口不止一处且无法归因参考尺寸/故意空段。
8. 疑似过渡线需区分“圆角件 vs 尖角件”。
9. 构件间只有点/线接触（无法成型）。
10. 相贯/截交线处的两个基本体形状或位置本身不定。

建模侧七条（SW 教材，决定模型骨架的信息缺失即停）：
11. 不知道“哪个尺寸以后会变、变了希望什么跟着动” → 先问变更源，再选孔定位标注法
    /尺寸基准〔零件 P15–16〕。
12. 不知道最终工程图前视图取向 → 先问再定第一特征草图平面（草图平面决定模型前视）
    〔零件 P53–54〕。
13. 不知道模具开模方向 → 先问再做拔模分析〔零件 P182–184〕。
14. 不知道零件用途（FEA？快速成型？大装配？外观件还是结构件？）→ 先问再定简化
    配置/曲面连续性〔零件 P247；曲面 P23–24〕。
15. 识别不出功能表面 → 问“哪个面和别的零件配合”〔曲面 P25–26〕。
16. 处理外部导入件 → 问“源文件以后还会不会改”（断 3D Interconnect 链不可撤销）
    〔曲面 P82–85〕。
17. 教材明言“没有标准答案”的选型（层叠/转盘/制造法、混合建模四法）→ 把“改动如何
    传播/重建代价/维护周期”摆出来问用户，不默认选最快路径——此处背“标准做法”
    生搬硬套正是“背答案”症状〔零件 P17；曲面 P59〕。

设计侧五条（功能判据，本文 §4.3/§4.4 展开）：
18. 配合面直径与公差等级（轴承轴颈、配合轴颈、孔系——轴 IT5~9、箱体孔 IT6~7）
    图上没有且无法由标准件反推。
19. 孔系中心距/啮合相关尺寸（有啮合关系的孔以彼此中心为设计基准）。
20. 安装孔位置与规格、总长总宽总高、中心高（约束整机外形与安装）。
21. 键槽/螺纹/轴伸等标准接口规格（影响相邻件互换）。
22. 轴肩定位关系：轴上装哪些件、装配方向（决定阶梯顺序与轴肩高度）。

**问法**（`modes-and-questions.md` §2.3 固定五段：问题/我的理解/为什么关键/选项/推荐），
一次最多 4 问，可多轮；只有用户说“你定/随便”或确认“确定不了”才采用推荐值并标记
`user_delegated`/`assumed`。模式 A 同样先问对象和拓扑，只免问具体数值。

## 7. 背答案的典型症状与纠正

| 症状 | 为什么会错 | 正确做法 |
|---|---|---|
| 见“板+孔”就套 plate-with-holes 配方 | 没判断零件是否真是这个族（键槽轴、带凸台板都像板） | 先过 recipes/README“判断先行”五问再套配方 |
| 主视图永远画 Front Plane | 主视图可能只是位置特征视图，形状特征在俯/左视 | 按 §1.3 找形状特征视图当第一张草图；侧剖面主视图才画 Front |
| 缺尺寸就填个“合理值” | 任何补全在没有约束时都是多解之一 | §6 命中即问；用户确认“确定不了”才编并标 `assumed` |
| 圆角/阵列/孔的位置背成固定先后 | 特征顺序由设计意图和父子依赖决定，不是口诀 | 按 `feature-strategy.md` 的终止条件与依赖判断，能说出理由再执行 |
| 把过渡线当真实棱边 | 铸件圆角处的过渡线是细实线、不与圆角接触 | §1.4 表：细实线弧线先判过渡线；拿不准就问 |
| 三视图齐全就宣布“唯一确定” | 虚实线重影、简化省略下仍多解 | 过 §1.4 全表再下结论 |
| 问过一轮就不再问 | 用户第一轮可能只答了一部分 | 剩余关键不确定项继续下一轮，直到全确定或用户授权 |
