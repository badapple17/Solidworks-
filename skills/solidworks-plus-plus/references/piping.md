# 管道与布线（Routing）

> 来源：《SOLIDWORKS 管道与布线教程 2024》p1–322 五段提炼合成。教材数值一律标"示例"；OCR 存疑数值不收。
> 标 [通用] 的规则不依赖 Routing 插件、换模型仍成立；其余为 Routing 专属 UI 流程，需人工执行。
> Routing 为独立插件（Premium 包），插件加载、库路径配置属环境操作，本技能不代办。

## 1. 能力边界（本技能未封装 Routing）

- 本文件用于选型、规划、人工执行与验收；不生成 Routing 原生特征（线路子装配体、3D 草图、步路点）。
- 本机没有可用的 Routing API 封装；不得臆造 API 名称/签名/枚举。
- 需要自动化时只写"未封装，需人工或新增封装"；交付说明不得声称已自动完成布线。
- 确需原生 Routing 时，交付物是"人工步骤"清单（命令名 + 操作对象 + 判据，见第 11 节）。
- 人工步骤中引用教材命令名（如〖分割线路〗），不伪造菜单路径。

## 2. 线路的本质与组织

- 线路 = 子装配体：内含线路零件（3D 草图中心线 + 扫描/拉伸成形）与零部件两个文件夹；3D 草图存于"路线1"特征下（P1–3、P75–76）。[通用]
- 外部设备（泵、罐、风扇、电路板）留在线路外，只作连接端与配合基准，不并入线路子装配体（P1–3、P134、P290）。[通用]
- 线路子装配体按类型默认命名：Harness-/Conduit-/Flex-Cable-/Tube-/Pipe-1；管道线路零件名含公称尺寸与规格（如 2inSchedule40），管筒名含尺寸（P4）。
- 虚拟 vs 外部保存：不勾"外部保存线路装配体/线路零件/为线路零件使用自动命名" → 线路为虚拟件（文件名带 [ ]），按 Delete 一次删除整条线路；"使成为虚拟"断开外部链接（P3、P9–10）。
- 保存策略判据：方案探索期 → 虚拟件，确认后右键"保存到外部文件"；需独立管理/进 PDM/出工程图 → 勾外部保存线路装配体与线路零件（P3、P9）。
- 刚性线路：正交直段 + 草图圆角处自动放弯管（管道为拉伸特征，只能正交直线）；柔性线路：线路属性勾"使用软管"，轮廓沿样条扫描、无弯管（P135、P148–149、P156、P212–214）。
- 选错后果：刚性当柔性用 → 插不进弯管、线路退化为大量短段；柔性当刚性用 → 被强制正交、产生不必要弯头。[通用]
- 线路类型速判：管道/刚性管筒 = 正交直段 + 弯管；软管/柔性电缆 = 样条 + 无弯管；电气导管可刚性可柔性，看是否勾"使用软管"（P134–136、P148–149、P212–214）。
- 建模方式：管道用同心圆拉伸（仅直线），管筒用扫描（可沿直线/圆弧/样条）（P277）。[通用]
- 线路段属性：同标称直径但壁厚不同的管段，右键线路线段 → 〖线路段属性〗改配置，仅对该段生效（P225）。
- 坡度（斜度）：〖添加斜度〗选斜面线段 + 引力平面 + 起点；坡度 = 提升高度/水平距离比值（示例 1:30）或角度值；线路中尺寸/关系不得阻碍斜度（P250–251）。[通用]
- 复制线路：Ctrl+拖线路子装配体复制；配合用线路草图直线（重合）、基准面（平行）、法兰面（距离）；两线路几何面互相配合 → 其中一个必须浮动否则过定义；副本随原线路更新、不能单独编辑实例（P248–250）。[通用]
- 线路按管径命名（如 "6 inch Route"/"4inch Route2"）；引导线路的吊架进入线路子装配体零部件文件夹（步路零部件），线路完成后加的非定位吊架无步路特征（不能利用 RPoint），只能放线路子装配体外部（P160、P181）。
- 编辑线路的层次：〖编辑线路〗同时打开子装配体 + 3D 草图 + 线路零件；〖编辑零部件〗一键退回装配体。忘记退出草图/子装配体 → 后续操作作用域错误（P18–19）。
- 孤立线路：右键线路子装配体 → 孤立，四范围：仅限线路/线路和次要参考/线路线段边界框/线路边界框；可存为显示状态快速切换（P33–35、P179–180）。
- 现有几何体只定位端点：接线盒/容器等只用于在空间中定位线路末端，不是线路几何体，不并入线路子装配体；用显示状态管理其显隐（P134、P169）。
- 路径草图规则：样条两端与端头线相切；刚性管道用直线段+弯管、柔性管/电缆/导管用样条；用曲率梳、样条控标、控制多边形重塑；样条与端头线不相切 → 接头过渡生硬或步路报错（P2、P17–18）。[通用]

## 3. 线路零部件与步路点

- CPoint（连接点）：确定线路终止位置、进配件方向、标称直径、线路类型；RPoint（步路点）：把配件放到 3D 草图端点或线夹内定义路径。装配体级配件用 ACPoint/ARPoint；管道/管筒线路零件两者都不含（P282、P288）。
- 配件拓扑（CPoint+RPoint 数）：法兰 1+1；弯管 2+1；三通 3+1；四通 4+1；变径管 2+1；阀门/泵/过滤器 2+1。所有配件在连接点处切断管道，管道被相邻零部件分割成不同长度（P156–157）。[通用]
- CPoint 标称直径 = 可容纳的最大线束直径；多条电线超限提示"线束段直径将超过所选段的线路直径"，可强制覆盖但须留意（P43、P51）。
- FilterSketch 按线束直径选配置：配置中建 FilterSketch，含 NominalDiameter/InnerDiameter/OuterDiameter@FilterSketch 尺寸，按线束直径与 OuterDiameter 比较选"Up To Xmm"配置；前提是勾"在线夹落差处自动步路"（P24、P49）。
- 步路点创建位置：CPoint 选零件内面取圆形边线中心；RPoint 取零件原点或圆弧草图上的点；基准轴用两平面构造；非轴对称件必须加竖直轴；查看符号用 视图/隐藏显示/步路点（P282–287）。
- 配合参考三用途：放置设备用 one-sided（仅主要参考，圆边线或参考坐标系）；法兰连接用 double-sided（面〖重合+反向对齐〗、柱面〖同心+任何〗）；勾〖对齐轴〗使坐标系对齐并完全约束，不勾只重合不完全约束。放置用配合参考须最先创建且位于列表顶部（P291–292）。[通用]
- 配合参考必须在所有配置中不压缩：生成设计表后检查状态列全为 "U"，否则多数配置下零件放不上去（P69、P96）。
- 拖放捕捉前提：接头/线夹/法兰/设备须带配合参考才能拖放自动捕捉；无配合参考零件按 Alt 拖放（只放件不启动步路），手动配合后用"开始步路/添加到线路"（P11–12、P22）。
- 配置筛选：放置法兰/接头时不勾"列出所有配置" → 系统按管道直径只显示匹配配置，防止人工选错规格（P136–137、P159）。
- 自制零部件向导流程：选线路类型 → 零部件类型 → 加 CPoint/RPoint → 配合参考（主要/第二/第三+类型+对齐）→ 零件有效性检查（"遗失所需项：无"）→ 设计表检查 → 属性（PartNo/Description/Comment/Material/Manufacturer，进 BOM）→ 存库（库中名称可与文件名不同）（P40–46）。
- 步路几何体检查以颜色标注：必需缺失红、可选缺失蓝、已有绿（P283）。
- 设计表规则：单一规格零件无需 Excel 设计表；检查中"添加为列标题"不会填单元格，必须手动填数据；无设计表 = 单尺寸，向导会警告（P40–46、P283–285）。
- 自定义配件：右键〖使之独立〗另存改件——仅适用于配件，不适用于管道/管筒零件；单一规格件删设计表其余配置（P200–201）。
- 复制改件优于新建管件：另存副本、删多余配置、改 Pipe Identifier 前缀/Weightperfoot/Length@Extrusion，材料改为目标材料并作用于所有配置（P277–279）。[通用]
- 关键草图/尺寸命名：扫描草图改名 Route；管道草图尺寸需含 内径/外径@管道草图、名义直径@草图过滤器；命名错误 → 向导不识别为线路件（P277、P287）。
- 库零件几何简化：几何精度只需满足连接与干涉检查，压缩/移除无用特征；图标取自最后保存的视图（等轴测 + 合适缩放）（P42、P269）。[通用]
- 法兰连接与垫片：法兰拖到另一法兰上自动匹配尺寸（线路内/线路间均可）；垫片拖到两法兰之间隔开并计入 BOM（P245、P248）。
- 阀门与法兰匹配：阀门可拖入线路或用〖添加配件〗；阀门连线路法兰需匹配法兰几何与配合参考，库参考 routing\piping\valves（P288）。
- 管嘴库特征：把法兰+管道加到任意零件上（需平面和草图定向定位）；管嘴不含 CPoint 和配合参考，用〖生成连接点〗补（P290）。
- 设备建模粒度：设备在线路外，关键是与线路的连接（法兰管嘴几何 + CPoint）；简单几何即可，加细节几何可检查与线路/结构件的间隙与干涉（P290）。
- 螺纹管库：threaded fittings (npt) 取螺纹管/配件，该库不含法兰——法兰从 piping\flanges 文件夹取；删除弯管时框选圆弧+点一起删，勿单选（P252–254）。
- 库组织与命名：按 标准(ansi/iso)/材料(ss/pvc)/零部件类型(flanges/elbows/tees) 建文件夹；零件名唯一且含材料信息；同一线路混用标准会造成法兰对不上（P314–316）。[通用]
- 标准件按标准选：欧标管道 DIN EN 10220、弯管 DIN 2605/EN 10242、法兰 DIN EN 1092-1/2628；美标阀门 ASME B16.34（Class 150 等，**Class 2000/3000 与法兰 PN 值 OCR 存疑，以原书/标准为准**）（P314–315、P321）。[通用]
- SOLIDWORKS Content 扩展库：Ctrl+点击 zip 下载（如 Steel.zip、PVC-U），解压到 routing\piping\<标准名>，再在 Routing Library Manager〖Routing 文件位置和设定〗把步路库指向该文件夹（P313、P321）。
- 库路径配置：默认 design library\routing（按普通步路/管筒管道/电气电缆分类）；路径错误时 routinglib.db 找不到、"管道和管筒设计数据库"与"线路属性"选项卡失效；路径须同时加入系统选项/文件位置/参考的文件，并在外部参考中启用〖文件位置中指定的参考文档〗以优先于工作目录搜索（P8–9）。Routing Library Manager 单位可选 in/mm/cm/m、内部以 m 存储（P8–9）。
- 截面语义：电气管道 = 封闭薄壁矩形（通道+盖板两实体，端部成对槽形孔）；电缆槽 = 开放薄壁矩形；HVAC = 封闭薄壁矩形或圆形；矩形截面线路发生扭曲 → 零部件无法正确匹配（P299–301）。
- 电气管道/电缆槽/HVAC 端部零部件含配合参考（同管道法兰）以连接设备（P299–300）。
- 支撑挂架类别：库中挂架有 roller hanger（滚轮）/strap hanger（管卡）两类，管筒有 tubing clip；支架可用零部件向导〖管道设计/支架〗创建；支撑间距数值教材未给出，不得引用（P271、P276、P317）。
- 支架的创建与使用方法与线夹相同（同两轴+两线路点结构）（P26、P47–48）。

## 4. 线夹与路径

- 线夹三要素：Clip Axis（沿穿线路径方向，圆锥面建轴）+ Axis of Rotation（放置时旋转用，两平面建轴）+ 两个 RPoint（两侧各一）；缺 RPoint 向导报"要求两个线路点"，缺旋转轴则姿态不可控（P26、P47–48、P67）。[通用]
- 多线穿夹两种命令：〖重新步路样条线或直线〗= 所有样条穿过同一线夹轴且互相交叉；〖步路/编辑穿过线夹〗= 样条穿过轴但夹内可偏移错开，配"自动排列线路"按与线夹轴的距离和参考实体距离堆叠。选错后果：线互相交叉干涉（P32–33、P101）。
- 多线穿夹刷新：选不中线夹轴时退出线路后用"编辑线路"刷新（P32–33）。
- 虚拟线夹：无实体几何（草图/平面/轴/步路点/配合参考构成），用于穿墙洞等无真实挂架处引导路径；轴长度决定穿过线段的长度（P29、P316–320）。[通用]
- 虚拟线夹配合：配合参考拖到圆柱孔面加同心、草图圆/点加重合（P316–320）。
- 管道线与线夹轴共线：布线时在两者之间加共线关系；缺共线关系导致线路偏离（P316–320）。[通用]
- 虚拟线夹引导自动步路：自动步路可在端头端点与虚拟线夹轴之间生成正交线路（P302、P319）。
- 端头线长度：设 0 时自动取 1.5×线路直径（p14 提示，**OCR 待原书复核**）；接头 CPoint"端头长度"参数可覆盖全局值（P14、P43）。
- 端头短直线是自动步路失败的第一原因：过短线夹无法定位、过长浪费线材；拖端头终点拉长/缩短后重试步路（P139、P162）。
- 线夹拖放到已有孔时靠配合参考自动就位；正交穿夹可选线夹轴或加同心 3D 草图关系；穿夹方向反了 → 扭结 → 〖反转方向〗（P219–221、P223）。
- 管筒穿夹：线夹内部沿夹轴在 RPoint 间生成短线段；旋转线夹（拖边或点）管筒跟随，消除扭结（P219–221）。
- 线夹自动换配置：向线路中增加电线后系统按线束截面自动选更大的线夹配置（P67、P70–71）。
- 起步路三入口：右键连接点 CPoint → 〖开始步路〗（新线）/〖添加到线路〗（续接）；孔起步路选孔圆面用〖起始于点〗；活接头两侧线路须分别用两侧 CPoint 步路（P218–220）。
- 样条编辑工具：样条右键可插入型值点、加相切控制、显示最小半径/曲率梳形图；〖重新步路样条线或直线〗让样条穿过一个或多个线夹改形（P221–224）。
- 柔性电缆线夹先放：线夹不含线路点、不是真正线路零部件，必须先于线路放置；自动步路单击开放端点 + 线夹轴线（P131–133）。
- 带状操纵点修形：三重轴拖样条型值点缩短起始段、平滑折弯；过度移动/旋转产生无法重建的形状（P131–133）。
- 脱钩 ≠ 删除：脱钩保留线夹、线路保持原形或勾"重新步路到最短路径"强制最短；删除需编辑零部件后直接删（P28）。
- 中接管与分割线路：分割线路生成 JPoint（存于"路线1"特征下），JPoint 改名 SP<n> 才保证正确步路；中接管可带零部件（Splice 类）或不带（"短管"文件夹球体特征）；草图工具"分割实体"≠ 步路专用"分割线路"（P29–31）。
- 吊架配合组：Clip-Axis 与管道草图重合、吊架水平面与钢结构底面平行、旋转轴与角钢背面定距（示例 9in，OCR 存疑）（P173、P181–182）。
- 吊架放置步骤序：插入 → 与线路草图配合 → 沿线移动 → 与结构配合 → 加螺纹扣（可选）→ 建螺纹杆（可选）→ 结构上打孔（装配体特征异型孔向导，特征范围限单件）（P181–182）。

## 5. 折弯与直段规则

- 最小折弯半径 > 管径（半径应大于直径，量级为半径≈管径；示例：3/8in 管配 3/8in 半径）（P215–216）。[通用]
- 电气侧对应库字段：电缆/电线库中每条线/缆带"最小折弯"字段，样条曲率不得小于库值，重塑样条后核对（P51–52）。[通用]
- 违规信号：红色条纹标记 + "线路样条曲线半径太小"/"不能生成步路零部件"报错（P100、P215–216、P221）。
- 修复顺序：①线路属性加大折弯半径 → ②〖修复线路〗浏览黄色可行解（右键循环、左键选定）→ ③换自动步路方案；替代修法：改接头长度、删尺寸/关系、改样条形状（P100、P215–216、P221）。
- 系统选项可勾"折弯半径小于最小值时创建分段线路零件"放行违规弯；电线/电缆检测有独立设置（P100）。
- 90°/45° 相交自动放标准弯管；其他角度用标准弯管派生自定义弯管（按角度值建当前弯管的新配置）；管筒线路不自动加弯管，必须手动添加（P286、P5–6）。
- 弯管库分 LR（长半径）/SR（短半径）/Metric 及 45°/90°/180°；**长半径弯管半径量级 ≈ 2× 外径**
  （示例：DIN 2605 DN25、OD33.7×2，弯管 R≈72.5 mm，OCR 值仅量级可信）；半径空间不足 →
  系统自动产生斜接折弯（管道本身折弯而非放弯管，存"线路零件"文件夹）（P270、P305、P175–176）。
- 交替弯管三选项（退出草图时对话框弹出）：①使用默认交替弯管（匹配库中 45°/180°）②制作自定义弯管（按角度建新配置）③生成成形折弯；成形折弯可用〖弯管角度〗命令改回标准管道+弯管组合（P175–176）。
- 电缆槽/电子管道弯管三种方向配置：水平折弯/竖直内侧/竖直外侧，配置名描述方向（P303–304）。
- 标准长度 + 自动管接（示例 1000mm）：勾"使用标准长度"+"插入管接"并选耦合件，超长直段自动分段并在接头处放耦合件，起始位置可漂移（P318–319）。[通用]
- 直段插配件路径①拖放：拖配件到直线段上自动在放置点分割，Tab 键翻转 90°（变径三通换支线方向），右键反转方向（P192–193）。
- 直段插配件路径②分割线路：分割线路 → 分割点与线段加共线 → 与端点加合并 → 拖放配件到端点（P196–197、P202–203）。
- 放置后定向：Shift+方向键按增量旋转（示例增量 15/30/45/90°），增量在系统选项/步路/零部件旋转增量中设置；仍不对则右键"以三重轴移动配件"或用基准面加角度约束（P198–199、P224、P306、P321）。
- 添加折弯：连接点处创建圆弧样条过渡（类似草图圆角），用于平滑转向（P30）。
- 移除管道/移除管筒：短管段多余时编辑线路模式右键线段移除，使弯管与三通直连；管筒线路误用"移除管道"无效（P197）。
- 替换配件：退出草图后右键配件〖替换配件〗；提示"可能与线路属性不匹配" → 零部件属性选匹配配置，必要时重编辑线路（P201）。
- 折弯-弯管对话框：手动圆角半径 ≠ 默认 → 退出草图弹〖折弯-弯管〗对话框选弯管与配置；"丢失弯管"错误 → 拖配件到端点补上（P252–255）。
- 穿透（支管接主管开孔）：重合约束连到主管中心线与端点（不用分割线路）→ 端头加法兰 → 右键连接点〖穿透〗；大管（贯通管）开孔，小管轮廓转化匹配大管半径，两管都被切断；45° 相交用 45° 弯头实现穿透布置，换管径时穿透角度关系不变（P244、P264）。
- 端点预留直段再加弯管：法兰拖放后先把端点向外拖出直段（示例约 600mm）再画线路加弯管，避免弯管与法兰/孔口干涉（P302）。
- 合并关系收尾：开放端点之间添加〖合并〗关系并加尺寸，完成线路草图定义（P321）。
- 3D 草图尺寸标注四法：单根线 → 弯管虚拟交点间线性尺寸；两端点 → 真实 3D 距离（放置前 Tab 切换正交投影）；两条线 → 角度（移象限切换 4 种）；法兰端面与草图几何体间可标尺寸。管道实际长度短于标注尺寸——被配件切割，尺寸≠长度（P241–242）。
- 更改线路直径向导：整线改规格时逐段设第一/第二配件配置（勾〖驱动〗），相邻段自动衔接；中间件（阀门/三通）须逐段选对匹配配置（P238–239）。
- 生成自定义管道配置：两根等长管道几何不同（如一根有穿透）需独立配置，右键管道表面生成，配置名自动递增；不能与〖成形折弯〗同用；〖约束接头到草图〗/〖约束草图到接头〗控制驱动方向（P243）。
- 矩形转圆形 HVAC：用过渡件 hvac square-round（两个 CPoint：一矩形一圆形），再用〖线路段属性〗把后续段改用圆管与圆弯管（P307）。

## 6. 自动步路与方案选择

- 六因素筛选：①端头短直线（拖端头终点拉长/缩短重试）→ ②干涉与间隙（自动步路不检查，人工预判）→ ③弯管数量与类型（避免非 90° 除非库支持 30°/45°）→ ④管道数量与长度（弯管多则管道多；短管难用，弯管连弯管可消除短管）→ ⑤靠近支撑几何体（为吊架留位）→ ⑥最短路径警告（通常非正交，可有意采用）（P138–139、P162）。
- 自动步路不检查干涉：方案选定后必须干涉/间隙验证；干涉敏感段或复杂线路改手动 3D 草图（P139、P170）。
- 正交线路开关：管道必须正交 → 勾〖正交线路〗生成 X/Y/Z 直线+草图圆角；选最短路径会收到非正交警告（可有意采用）（P139、P162）。
- 手动 3D 草图兜底：Tab 在 XY/YZ 平面间切换，用水平/竖直/45° 引导线绘制；拖动端头末端到相交 → 剪裁实体去多余 → 合并开放端点 → 标注尺寸；串联配件拖放到公共端点；手动模式不勾"自动生成圆角"；剪裁后出现警告属正常，加弯头后消失（P145–147、P170–171）。
- 线路草图报错：状态栏"过定义/无法找到解" → 点提示〖诊断〗看方案（接受删除相交约束的方案）→ 〖手工修复〗列全部冲突 → Ctrl+Q 强制重建；诊断删掉圆角后要在方向变化处补圆角（P198、P242）。
- 自动步路适合 90° 弯管场景；复杂线路分多段步路（法兰→管夹轴线→末端法兰），每段浏览〖交替路径〗；方案按"解决方案 n-Y、X、Z"命名（轴序），集合中可能含非正交方案（P162–163、P170、P173–175、P214、P229）。
- 自动步路对正交矩形截面（电气管道/电缆槽/HVAC）同样适用；多解时弃系统解可能得不到可制造路径（P302、P319）。
- 沿此步路：点线路直线 + Ctrl+点平面 → 〖沿此步路〗设偏移值，管道沿墙面保持固定距离；偏移量尺寸不带平行关系（P178–179、P187）。
- 沿几何体步路：选起始端点 + 一系列平面（呈角度平面定义走向并给出两种长度选择），最终选端头端点；等距量在"为沿曲面的线路等距"中设（示例 4in）；测量距离是与所选平面垂直的偏移量；端点不偏至内侧会与选定面干涉（P182–187）。
- 步路装配体模板 routeAssembly.asmdot 与标准装配体模板不可互换，误用导致线路创建失败/单位错乱；定制 = 复制模板改文档属性（绘图标准/尺寸/单位/取整）后另存，系统选项"提示用户选择文件模板"使每次创建时选择（P85、P157–158）。
- 线路规格模板：Routing Library Manager 按管道明细表 + 默认弯管（90° LR）+ 自定义弯管（45°/180°，选"始终使用弯管"）建模板，全厂统一管表用；线路含多个管道尺寸时模板无用，勾"自定义设置"逐项覆盖；不勾自定义设置则模板字段灰色不可改（P159–160、P164–166）。
- 基准面控制线路高度：参考几何体 → 基准面选 Top Plane+线路草图端点；编辑线路选平面+草图直线加〖在平面上〗约束；草图中出现过定义 → 状态栏点〖过定义〗→ PropertyManager 〖诊断〗（P194）。
- 多容器/多泵线路组织：设备用零部件阵列布置（改阵列间隔后重建）；线路分 A/B/C 多条：〖添加到线路〗建 A，〖移除管道〗建 B（P295–296、P305）。

## 7. 验证三件套

- 干涉检查：可针对单管、弯管或整个线路子装配体（先清默认选择再选目标）；工作循环是"检查 → 编辑线路改尺寸 → 重新检查"直至与结构件无干涉（P203–204、P310）。[通用]
- 间隙验证：设"可接受的最小间隙"；间隙为 3D 空间距离，重合与干涉也会被列出（P207–208）。[通用]
- 封套：零部件属性勾"封套"表示无几何体体积（阀门操作空间、立管、障碍物）；"使用封套进行选择"按内部/外部/交叉批量选择；封套不进 BOM 与计算（P217、P223–224、P255）。[通用]
- 封套修复手法：线路与封套交叉 → 插入样条型值点 + 相切控制把样条拖出封套后重测（P223–224）。
- 干涉修复手法：线段与板面间加〖沿此步路〗尺寸（P204）；或三重轴移动配件避障 → 黄色虚线引导线 → 〖将引导线转换到线路〗重建连接（P255–257）。
- 覆盖层（保温/包覆）：全长或部分、多层并排序；自定义覆盖层 = 材料 + 厚度；快捷菜单加覆盖层只影响部分线路（P204–207）。
- 覆盖层与尺寸：尺寸属性"使用中心线尺寸"/"包括覆盖层厚度"决定测量位置；覆盖层厚度导致干涉但尺寸未含 → 勾"包括覆盖层厚度"重算（P204–207）。
- 验收顺序：先干涉检查（硬冲突）→ 再间隙验证（最小间隙）→ 最后封套（体积/维护空间）；三者互不替代（P203–208、P217）。

- 电气/电缆槽/HVAC 的 BOM 可含描述、直段长度可单列或总计；电气导管工程图用右键视图 →〖电气表〗

- 短管 spool 定义：〖定义短管〗选直线段 → 两端法兰自动纳入 → 短管 001/002/003 文件夹组织（P246–248）。

## 9. 电气线路（附带知识，p66–130 主要是电气）

- 电线长度 = 样条曲线长度 + 2×端头长度 + 2×额外内部电线长度；"空隙百分比"为切割长度加成（计入扭结/弯曲，默认 0 示例值）（P117–118）。[通用]
- 端头长度在接头连接点中设（接头到样条的直线段）；额外内部电线长度 = 末端剥线/压接预留；电线长度显示在电线名内（如 20g red-2<218.66mm>，示例值）（P15–17、P117–118）。
- 固定长度线路：右键草图勾"固定长度"锁定端头直线+样条总长；标准电缆创建的线路长度灰显锁定；拖动样条型值点端点"回弹"以保持长度（P75–78、P80）。
- 固定长度被解除：接头摆放距离超过电缆长度 → 系统提示并自动解除固定长度，事后用线路属性重设（P78）。
  对固定长度样条用〖修复线路〗会弹"不更改长度将不能修复"确认——先解除固定长度再修复（P75–80）。
- 重用线路像阵列实例链接原始线路：改动不能从重用线路传回父线路；不勾"保持步路段长度"或清除"固定长度"可适配更长路径（P81–84）。[通用]
- 重用线路未分离会导致 BOM 数量/长度错误，系统主动提示"要正确反映电线/线路的数量和长度，请分离"；右键"分离线路"断开链接（P83–84）。[通用]
- 数据驱动布线三件套：零部件库（零件+管脚清单）/电缆电线库（外径/最小折弯半径/颜色；电缆必须有"芯线数"）/从-到清单（参考名+从管脚/到管脚+电线名）（P89–93、P104）。
- 从-到清单只存逻辑连接不存长度 → 同一清单可跨装配体复用；创建后可经〖从-到清单向导〗修改并另存为新文件（P89、P94–96）。
- 库文件 xml 首选（也可 xls/xlsx）；从-到清单向导要求 Excel 格式库；导入失败最常见原因是列名与"标题定义"不匹配 → 弹错误清单且整文件不入库（P89–93、P104）。
- 标准电缆 Excel 库结构：表头说明区 + 数据区，第一行的数字（示例 16）= 列标题起始行号，其上说明被工具忽略；列为 零件编号/线路类型/说明/从接头/到接头/长度/直径；单位全部为米（P73–74）。
- 标准电缆三操作：〖添加新电缆〗复制当前设置到所选 Excel 文件并改名；对话框内改长度/直径/接头 = 即时自定义；直接编辑 Excel 增删行 = 永久更改（P73、P77–79）。
- 手动分配管脚：编辑电线中为每根电线选从-到接头及管脚（任一管脚可对任一管脚）；图标区分路径已定义/未定义/有错误（P15–17）。
- 扭曲面组：选一对电线设"每单位长度扭曲"，仅为计算值、外观不变（P15–17）。
- 引导线工作流：从-到清单先以黄色虚线临时图形预览；"合并引导线以形成线路"把多条引导线合成一条多线束线路（合并时可穿过线夹，可选合并到两端/一端）；直接单条转换会把多线束拆成多条独立线路（P98–99、P103–106）。
- "将引导线与现有线路连接"需选引导线 + 一个连接点；自动步路中只显示线路引导线（P98–99）。
- 从-到可步路到线路点：分割线路创建的线路点名作零部件名、"*" 作管脚名；清单引用零件缺失 → 名称旁无图标，需浏览重指（P94–96、P101–102）。
- 柔性电缆（扁平排线）两条硬限制：不能用〖编辑电线〗、不能用从-到清单（P127–129）。
  CPoint 参数 T/W 定义截面尺寸（黄色矩形预览）；端头线中直线=电缆中心、构造线=定向；
  〖自动步路〗只有〖灵活〗一个选项且只有一种解（P127–129）。
- 柔性电缆长度校验：用〖测量〗工具校验样条长度（P131–133）。
- 电气导管混合零部件（如 male terminal adapter）同时含导管+电气连接点，放置时产生两条端头直线（较长者代表导管）；电气线路扩展四步法：放电气零部件（线路属性设"线束"）→ 自动步路连接端点 → 编辑电线 → 出工程图（P136–137、P149–150）。
- 电缆电线库编辑四步：Routing Manager 打开现有库（XML）→ 双击名称列单元格编辑 → 另存 → 在 Routing 文件位置和设定中选中该 xml；只保存不指认 → 新库不生效（P142–143、P153）。
- 电气数据文件默认位置 design library\routing\electrical\（P51–52）。
- 库电线优先：标准电缆带入的电线属性少于电缆/电线库电线 → 〖编辑电线〗→〖替换电线〗换库电线，再删除标准电缆（P77）。
- 电气覆盖层类型：带子/绳子/可黏合带子；全长或固定长度；系统选项可设透明（P52）。
- 平展线路两种模式：〖注解〗= 不按比例标准工程图（标注仍是真实长度）；〖制造〗= 模壳板边线内 1:1 真实尺寸配置（钉板/制造模板用），后续工程图为缩放视图（P111–115、P119）。
- 平展前提：被平展的线路子装配体不能是虚拟件；2D 接头块（关联 .slddrw 块文件）须先于平展存在，块可显示与电线匹配的彩色管脚（P111–115、P119）。
- 平展表格：电气材料明细表/切割清单/接头表格，可用"列类型=线路属性"扩展列（P111–115、P119）。
- 编辑展开的线路（仅制造型）：矫直/添加折弯/调整角度/水平竖直翻转/调整扇出；模壳板边线可改 X/Y 偏移与宽高；矫直使线段重叠时用"选择其他"选隐藏线段（P120–123）。

## 10. 失败模式速查

| 现象 | 原因 | 一线修复 | 兜底 |
|---|---|---|---|
| 样条半径过小报错/红色条纹 | 折弯半径 < 最小折弯半径（应 > 管径） | 线路属性加大折弯半径 | 修复线路选可行解；换自动步路方案 |
| 端头过短步路失败 | 端头线长度不当 | 拖端头终点拉长/缩短重试 | 设 0 自动取 1.5×线路直径（规则待复核） |
| 拖放配件乱跳/误开线路 | 缺配合参考或误触发步路 | 按住 Alt 拖放（只放件不启动步路） | 手动配合后"开始步路/添加到线路" |
| 多线过同一线夹互相交叉 | 用错命令（重新步路样条线或直线） | 改用〖步路/编辑穿过线夹〗+自动排列 | 退出线路后"编辑线路"刷新 |
| 线夹不随线径变化 | 缺 FilterSketch 或未勾"在线夹落差处自动步路" | 补 FilterSketch 配置 | 手动换配置 |
| JPoint 不改名步路失败 | 分割线路默认名 <n> | 改名 SP<n> | 重建分割 |
| BOM 数量/长度错误 | 重用线路未分离 | 分离线路 | 重建线路 |
| 虚拟件无法出工程图 | 未外部保存 | 保存装配体（在外部文件中） | — |
| 线夹穿管方向错/扭结 | 穿夹方向反 | 反转方向 | 旋转线夹/加同心 3D 草图关系 |
| 加配合报"将删除线路约束" | 对步路配件加装配配合 | 接受（建配合删冲突约束） | 三重轴移动配件+引导线转回线路 |
| 增量旋转不可用 | 零部件旋转增量未设 | 系统选项/步路设增量（示例 15/30/45/90°） | 右键"以三重轴移动配件" |
| 替换配件提示与线路属性不匹配 | 配置与线路规格不符 | 零部件属性选匹配配置 | 重编辑线路后重试 |
| 从-到清单整文件不入库 | 列名与"标题定义"不匹配 | 标题定义中逐列映射 | 改库文件列名后重导 |
| 平展无接头块可用 | 2D 块未预先创建 | 先创建关联 .slddrw 块文件 | 用 3D 接头显示 |
| 编辑线路模式下改不了配置 | 编辑线路限制 | 先退出编辑线路模式 | 替换配件后选配置 |
| 管筒线路删段无效 | 误用"移除管道" | 改用〖移除管筒〗 | 编辑线路直接删线段 |
| 多线束被拆成多条独立线路 | 直接转换单条引导线 | 改用"合并引导线以形成线路" | 将引导线与现有线路连接 |
| "使之独立"不可用 | 目标不是配件（是管道/管筒零件） | 仅对配件使用 | 生成自定义管道配置 |
| 样条与端头线不相切 | 样条重塑破坏了相切 | 重塑样条加相切 | 曲率梳检查过渡 |
| 配合参考被某配置压缩 | 设计表状态列非 U | 设计表状态列改 U | 重建配合参考 |
| 管筒线路缺弯管 | 管筒不自动加弯管 | 手动添加弯管 | 换成管道线路 |
| 固定长度线路无法修复 | 长度被锁定 | 先解除固定长度再〖修复线路〗 | 接受不改长度的修复方案 |
| 管线零件散放顶层装配 | 线路未建成子装配体 | 新建线路子装配体收纳 | — |

## 11. 给弱模型的执行边界

- 本技能不能自动布线。能交付的：读图规划（六因素方案筛选）、参数核算（电线长度公式、端头线 0→1.5D〔规则待复核〕、折弯半径 > 管径）、验收（干涉/间隙/封套/折弯半径）。
- 需要原生 Routing 时：输出"人工步骤"清单（命令名 + 操作对象 + 判据），交付说明不得声称已自动完成。
- 不得引用未封装的 API；凡教材数值必须标"示例"；OCR 存疑数值（如标准长度、旋转增量具体值）只能标示例，不得当阈值使用。
- 验收交付格式：判据 + 测量位置 + 结果（通过/失败），不用"看起来没问题"这类空话。
