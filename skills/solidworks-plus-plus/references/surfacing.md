# 曲面建模：适用边界、选型与失败处理

本文件来自《SOLIDWORKS 高级曲面教程（2024版）》P1–210 的提炼。**先看清本机能力**：
`sw_part.py` 已封装实体特征（拉伸/切除/旋转/圆角/抽壳/阵列/镜像），OCP 后端只有
闭壳 Knit 与开放面 Thicken（含 50% 最小曲率半径门禁）。**SolidWorks 原生曲面特征
（剪裁/缝合容差/相交/替换面/延伸/边界曲面/填充曲面/直纹曲面）尚未封装**。
因此本文件的作用是：判断该不该走曲面路线、走不通时怎么降级、验收看什么。

## 1. 什么时候才走曲面路线

| 输入特征 | 路线 |
|---|---|
| 等厚板件、回转体、规则凸台/孔槽 | **实体路线**（默认，稳定） |
| 薄壁但外形由 2D 轮廓拉伸/旋转可得 | 实体 + 抽壳 |
| 自由曲面外观件、模具型腔、导入的无特征史曲面 | 曲面路线（本文件；当前需人工/新增封装） |
| 示意模式下的曲面件 | 用实体近似（放样/旋转/加厚）并在交付说明标注“示意近似” |

硬规则：**不要用未封装的 SW 曲面 API 名称编写脚本**。需要曲面特征时，
在任务卡里写明“曲面步骤需人工完成或先新增封装”，不要假装自动完成。

## 2. 三个基础判据

1. **实体有效性**：每条边恰属 2 个面；闭合实体满足 V−E+F=2（立方体 8−12+6=2）。
   开放边=1 个面 → 还是曲面体；边属 4 个面 → 拓扑无效，先剪裁/分割。
2. **连续性**：C0 接触、C1 相切、C2 曲率。功能面/结构件 C1 足够；外观件 C2；
   A 级曲面才需要 C3。强行升 C2 而截面/引导线质量不足，会得到扭曲面。
3. **四边面优先**：尽量正交四边网格；多条边收敛到一点=退化面（奇点），
   圆角/抽壳/等距时最容易失败。对称端点收口是允许的例外。

## 3. 曲面 → 实体：两条主路线

| 条件 | 做法 | 参数 |
|---|---|---|
| 曲面组已闭合、只需实体化 | 缝合 + 勾选“创建实体” | 缝隙 ≤0.009 mm 用间隙控制；≥0.1 mm 先延伸曲面 |
| 多面相交、需要裁剪语义 | 相互剪裁（自动缝合）或相交特征 | 工具面必须**完全穿过**被剪面；曲面做大于成品 |
| 从模具型芯/型腔取零件 | 相交 + “排除区域”选工具实体 | 不要用“创建内部区域”（该选项不允许移除工具实体） |
| 需要保留工具面 | 相交时不要勾“消耗曲面” | — |

**剪裁不相交是最常见失败**：曲面画小了。先建大曲面再剪（教材明示“大曲面的目的
是确保相交”）。

## 4. 加厚还是抽壳

| 需求 | 做法 |
|---|---|
| 可以接受底面随曲面翘曲 | 直接加厚（偏移面+前后边放样+缝合），方向朝内侧 |
| 要求底面平整、壁厚正确 | **封闭体积→缝合创建实体→圆角→抽壳** |
| 已有实体壳件 | 直接抽壳，壁厚 < 最小圆角半径（例 1.5 < 2.5） |

量化门禁：**加厚/等距距离 ≤ 0.5 × 曲面最小曲率半径**（与 OCP thicken 门禁一致）。
超过必失败；失败时先用“检查实体”找最小曲率半径点。

## 5. 补洞特征怎么选

| 开口 | 首选 | 说明 |
|---|---|---|
| 四边开口、质量要求高 | 边界曲面 | 方向1/方向2 独立设连续性；长边曲率、短边相切 |
| 窄条开口、长边主导 | 放样曲面 | 长边界做轮廓（可曲率），短边界做引导线（放样引导线不支持曲率） |
| 不规则多边/收口 | 填充曲面 | 任意边线数；勾“应用到所有边线”；不要勾“优化曲面”（会退化成简单面） |
| 实体上的封闭内环孔 | 删除孔/解除剪裁 | 不要用填充 |
| 镜像对称缺口 | 修一半 → 使用曲面切除 → 镜像实体 | — |

降级顺序：曲率 → 相切 → 相触。选“曲率”后预览消失=该边界下无法生成，直接降级，
不要反复调参数。

## 6. 延伸与复制面

- 延伸曲面：解析曲面（平面/圆柱/圆锥）用“同一曲面”可无缝延长；
  NURBS/数值曲面长距离延伸必须用“线性”（有断边）。
- 等距曲面 offset=0 = **复制面**，用于替换面/包覆/剪裁底材，不动原实体。
- 使用曲面切除：工具面必须完全穿过实体；没穿过就先用“延展曲面”沿切面延伸
  （教材例 5 mm），再切。
- 替换面：替换体必须是曲面实体；延伸必须超出实体边界，否则失败。
  重建代价通常最高（教材四法对比 2.69 s vs 1.78 s），大模型优先“使用曲面切除”。

## 7. 导入几何修复（无特征史）

1. 格式优先级：**Parasolid (x_t/x_b) > STEP/ACIS > IGES**。IGES 会把圆柱/球拆成
   多面，面颜色斑驳是正常现象，不要逐面“修”。
2. 导入失败三机理：精度四舍五入（调缝合精度）、特征映射不支持（换格式）、
   实体大缺口（跳过自动修复，手动补面）。
3. 3D Interconnect 链接保持=源文件可更新但自动愈合禁用；断开链接不可撤销。
   判据只有一条：源文件以后还会不会改。
4. 修补质量数值化：最小曲率半径≈0.0002 mm 直接否决（补丁有奇点）；
   缝合后误差分析 + 斑马条纹（不匹配=C0、突变=C1、平滑=C2）。

## 8. 失败模式速查

| 现象 | 原因 | 处理 |
|---|---|---|
| 缝合后无法勾“创建实体” | 有开放边/缝隙过大 | 列缝隙清单；≤公差用间隙控制，大缝隙先延伸/补面 |
| 抽壳失败/报最小曲率半径 | 壁厚 ≥ 局部最小曲率半径 | 减小壁厚或局部改面；塑料壳可接受警告 |
| 圆角在曲面交汇处失败 | 退化面/多边交于一点 | 删角部面→填充曲面（相切）→缝合；或重建为四边面 |
| 放样扭曲/波纹 | 引导线与轮廓穿透关系缺失、相切长度过大 | 检查穿透/重合；缩短相切长度；仍不行换边界曲面 |
| 镜像后缝合有缝 | 公差随特征累积 | 列缝隙、分别处理；大缝隙改用独立填充面 |
| 曲面切实体留残余 | 工具面没有完全穿过 | 先延伸/延展曲面，确保超出实体 |

## 9. 给弱模型的执行边界

- 能用实体特征完成 → 不要碰曲面。
- 必须曲面时：先写任务卡，标出“需人工曲面步骤”，交付时如实说明，
  **不得声称已自动完成**。
- 验收至少给三项证据：包围盒、体积/壁厚、补丁最小曲率半径或缝隙清单。
- 详细教材提炼见 `digests/surfacing_p001_070.md`、`surfacing_p071_140.md`、
  `surfacing_p141_210.md`（训练区）。
