## 案例 1 ✅：64 题库 001 连杆支座（图纸 → 模型 → 三视图）

### 输入

- 题目图片：`...\1：三维练习题（64道 带答案文件）\64张图片格式（模型练习题）\image001.jpg`
- 答案模型：同目录 `对应的64个SW格式3D图(模型练习题)\001.SLDPRT`
- 模式：B 精确模式；单位 mm；1 个实体。

### 图纸信息 → 参数表

| 参数 | 值 | 来源 |
|---|---:|---|
| 底板 | 30 × 25 × 5 | explicit（30、25、5） |
| 左侧开口槽 | 13 高 × 10 深 | explicit（13；深度按图比例 10，`derived`） |
| 主圆凸台 | φ25 × 10 | explicit |
| 主圆孔 | φ15 贯穿 | explicit |
| 中心距 | 37 | explicit |
| 中心线角度 | 32°（相对 +X） | explicit |
| 端环 | φ12 × 4 | explicit |
| 端环孔 | φ8 贯穿 | explicit |

> 这是典型的“平面轮廓信息多于侧剖面”的零件。主参数是平面图，
> 所以把**平面轮廓**画在 Front Plane，侧剖面由拉伸高度自然得到。

### 建模顺序（7 个特征）

1. 底板：`(-30,-12.5)→(0,12.5)` 矩形，向 +Z 拉伸 5。
2. 开口槽：`(-30,-6.5)→(-20,6.5)` 矩形，完全贯穿。
3. 主圆凸台：φ25 圆，向 +Z 拉伸 10。
4. 杆：外公切线梯形（`p1a→p2a→p2b→p1b`），厚 4。
5. 端环：φ12 圆，位于 `(31.3778, 19.6070)`，厚 4。
6. 主圆孔：φ15 贯穿。
7. 端环孔：φ8 贯穿。

代码见 `references/recipes/link-lever.md`（参数与本题一致）。

### 实测结果（2026-10-24）

| 检查 | 结果 |
|---|---|
| 包围盒 | `67.37778 × 38.107013 × 10.0` mm |
| 答案包围盒 | `67.37778 × 38.107013 × 10.0` mm |
| 实体数 | 1 |
| 孔 | φ15 @ (0,0)，φ8 @ (31.3778,19.6070)，均贯穿 |
| 三视图 | 4 视图（前/俯/左/等轴测），A3 420×297，第一角 |
| 尺寸 | 23 个（含 φ25/φ15/φ12/φ8/37/32°/30/25/13/10/5/4） |
| 输出 | `.SLDDRW` + `.pdf` + `_drawing_preview.png` + `_drawing_report.json` |

生成的三视图与题目图在轮廓、孔位、板厚关系上一致；
主视图/俯视图的角色与题目图互换（见下）。

### 这次实测暴露的 4 个关键点

1. **切除方向 bug**：`FeatureCut4` 的方向是第 3 个参数 `Dir`；
   旧封装把 `direction` 传给 `Sd`，`Dir` 恒为 `False`，导致 direction 参数失效。
   已修复。贯穿切除仍按材料所在侧给方向；方向反了 `auto_flip` 会反向重试。
   当时记录过“正负两侧都通过”，后续在偏置面和实体端面实测发现方向反了会朝空侧切、
   返回 `None`，以新证据为准，不要假设贯穿方向无关。
2. **孔没有尺寸**：API 直接画圆不会生成显示尺寸，出图时 φ15/φ8 丢失。
   已在 `create_through_hole()` 内自动调用 `auto_dimension_sketch()`。
3. **图幅码**：SW2023 的 A3 纸型码是 **8**（不是 6），
   且不传 `.slddrt` 时 `SetupSheet6` 第 3 个参数 `TemplateIn` 必须同码；否则实际仍是 A4，
   布局按 A3 计算就会裁切。已改为回读 `GetProperties` 校验 0.420×0.297。
   （2026-10-25 补充：传 `.slddrt` 时 `TemplateIn` 必须为 12，图幅仍由 `PaperSize` 决定；
   传图幅码的症状是 PDF 丢图框/标题栏/尺寸线，图幅本身却正确。两种失败不要混为一谈。）
4. **视图角色**：平面轮廓画在 Front Plane 后，生成图的 Front 是平面、Top 是侧剖面，
   与题目图相反。几何正确；交付时说明角色，或用
   `drawing-to-part.md` 的“侧剖面做主视图”路线重做。

### 可复现路径

- 建模脚本（临时，不随技能交付）：`%TEMP%\sw_train\build_001.py`
- 生成图：`%TEMP%\sw_train\drawing_test8\001_build4_drawing_preview.png`

## 案例 2 📚：40 题库 06 传动轴（旋转类）

### 答案特征树

```text
草图1 → 旋转1 → 草图2 → 切除-拉伸1 → 草图3 → 切除-拉伸2 → 倒角1 → 圆角1
```

### 解读

- 主体一次旋转完成，没有逐段拉伸。
- 两个 `切除-拉伸` 对应轴上平面/键槽/径向结构。
- 倒角在切除之后、圆角之前；圆角最后。
- 没有阵列/镜像，说明是单件轴。

### 复建顺序

1. 读各段直径/长度 → 半剖轮廓 → 旋转 360°。
2. 键槽/平面 → 切向偏置面 → 盲切。
3. 端部倒角 C1。
4. 轴肩圆角最后。

配方：`references/recipes/stepped-shaft.md`。

## 案例 3 📚：64 题库 034 法兰/盘类

### 答案特征树

```text
草图1 → 旋转1 → 草图3 → 草图4 → 草图6 → 凸台-拉伸1 → 凸台-拉伸2
→ 切除-拉伸1 → 草图7 → 切除-拉伸2 → 阵列(圆周)1 → 圆角1
```

### 解读

- `旋转1` 是主体（法兰/轮毂）。
- 两个 `凸台-拉伸` 是局部凸台/耳。
- 两个 `切除-拉伸` 是中心孔/减重孔/槽。
- `阵列(圆周)1` 放在切除之后、圆角之前。
- 圆角最后。

### 复建顺序

1. 旋转主体（外径/内径/厚度/轮毂）。
2. 局部凸台。
3. 中心孔 + 减重孔/槽。
4. 圆周阵列。
5. 圆角。

配方：`references/recipes/flange-disk.md`。

## 案例 4 📚：64 题库 002 对称支架

### 答案特征树

```text
草图1 → 拉伸1 → 草图2 → 凸台-拉伸2 → 草图3 → 切除-拉伸1
→ 草图4 → 切除-拉伸2 → 草图5 → 筋1 → 镜像1
```

### 解读

- 主体拉伸 → 凸台 → 两次切除 → 筋 → 镜像。
- 筋在切除之后、镜像之前；镜像的是筋（或筋+局部特征）。
- 没有圆角，说明题目不要求外观圆角。

### 复建顺序

1. 主体拉伸。
2. 局部凸台。
3. 孔/槽切除。
4. 单侧筋。
5. 关于对称面镜像。
6. 不追加图纸没有的圆角。

配方：`references/recipes/bracket-rib.md`。

## 案例 5 ✅：法兰沉孔（先打穿 + 单独沉孔，实测）

### 参数

| 参数 | 值 |
|---|---:|
| 外径 OD | φ120 |
| 中心孔 ID | φ40 |
| 法兰厚 T | 12 |
| 轮毂 | φ60 × 20（x=12..32） |
| 螺栓孔 | 6×φ9，PCD 90 |
| 沉孔 | φ15 深 6，开在法兰端面 x=12 |

### 建模顺序

1. Front Plane 半剖轮廓（x=0..12 法兰 + x=12..32 轮毂）→ 旋转 360°。
2. Right Plane 中心孔 φ40 贯穿。
3. Right Plane 6×φ9 螺栓孔贯穿（极坐标转 `(u,v)=(-z,y)`）。
4. Right Plane 偏置 +12 得 `Plane_CboreFace`；6 个 φ15×6 沉孔，
   `through=False`、`direction=False`。
5. 不倒角（本试件只验证沉孔路径）。

### 实测结果（2026-10-24）

| 检查 | 结果 |
|---|---|
| 实体数 | 1 |
| 包围盒 | `32 × 120 × 120` mm |
| 圆柱面数 | 13 = 6×φ9 + 1×φ40 + 6×φ15 |
| 复合孔 | 6 组，每组 `[9, 15]`；φ15 段在 `x=6..12` |
| 右视图 | 6 个同心圆（φ15 外、φ9 内），大径朝法兰端面 |
| 审查 | `status=pass`，`score=100` |

### 关键教训

- **沉孔加工面先按图纸选，再按材料位置校验**：本案例图纸把沉孔画在轮毂一侧的
  法兰端面 `x=T=12`；`PCD 90 > HUB_OD 60`，该面 `r=45` 处有材料。若误从轮毂端面
  `x=T+HUB_H=32` 下刀，草图悬空，切除返回 `None`。
- **`through=False` 可用**：第 3 步已打穿，第 4 步只切沉孔，避免对同径通孔
  重复切除返回 `None`。
- **`hole_count` 是圆柱面数**，不是孔数；用 `compound_holes` 检查同轴两段。
- **偏置面方向不会整体反转**：`Plane_CboreFace` 贴在法兰材料外端 `x=12`，
  朝 +法向切就是朝空处切，所以沉孔用 `direction=False` 切回材料；`auto_flip` 兜底。

配方：`references/recipes/flange-disk.md`；复现脚本（临时）：
`%TEMP%\sw_train\validate_flange`。

## 从案例提炼的通用检查

1. **先算包围盒再建模**：用参数表算出的 `Xmin/Xmax/Ymin/Ymax/Zmax`
   与答案或图纸总尺寸对照；对不上说明参数理解错。
2. **孔位必须回读**：`collect_geometry_measurements()["holes"]` 的
   `diameter_mm/position_mm` 与参数表逐项比对。
3. **出一张图再交付**：模型→三视图能暴露“孔没切穿、凸台方向反、
   草图缺尺寸”等看模型看不出的问题。
4. **视图角色写进交付说明**：Front 是平面还是侧剖面，必须讲清楚，
   不要让用户按错误的主视图去加工。
