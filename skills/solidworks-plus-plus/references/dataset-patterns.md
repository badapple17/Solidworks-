# 题库挖掘出的建模模式（训练产物）

数据来源（本机，2026-10-24）：

| 题库 | 有效零件 | 说明 |
|---|---:|---|
| 阿奇 SOLIDWORKS 40 道答案 | 105 个 SLDPRT | 含标准件/装配零件，大量 `BaseBody` 历史体 |
| 64 道三维练习题答案 | 66 个 SLDPRT | 以原生 `Extrusion` / `Revolution` 为主，最适合学习建模顺序 |

> `ICE` 是 FeatureWorks 识别出来的导入特征，**不是**一种建模命令。
> 它的特征名仍保留原意（`Boss-Extrude2`、`Cut-Extrude1`），
> 读序列时要把 `ICE` 当作“凸台/切除”，不要被类型名吓住。

**训练结论**：

1. 题库的 95% 是“拉伸 + 切除 + 少量圆角/筋/阵列”，配方应优先覆盖这些，
   不要为了 1 个弹簧案例把 L1 文档写复杂。
2. 旋转件只有 3%，但轴类图纸在机械制图中很常见，`stepped-shaft.md` 仍必须保留。
3. 扫描/放样/螺旋属于 L3；当前没有真机验证的原生封装，按 `standard-parts.md`
   第 7 节的限制处理，不要凭记忆拼 API。
4. SW150 的 50 个实体件几乎全是“单次拉伸 + 少量切除”，适合做弱模型的
   入门回归集：先保证 50 个简单件 100% 通过，再谈复杂件。

## 1. 首特征统计（决定建模起点）

| 首特征 | 64 题库 | 40 题库（原生件） | 结论 |
|---|---:|---:|---|
| 拉伸 `Extrusion` | 43 / 66（65%） | 20 | 板、块、支架、壳体优先用拉伸 |
| 旋转 `Revolution` | 13 / 66（20%） | 8 | 轴、盘、套、轮坯优先用旋转 |
| 薄壁拉伸 `ExtruThin` | 3 | 0 | 钣金/薄壁件 |
| 螺旋 `Helix` | 3 | 0 | 弹簧、螺旋槽 |
| 放样/扫描 `Blend`/`Sweep` | 3 | 1 | 异形过渡、弯管 |
| `BaseBody` | 1 | 64 | 标准件/历史导入体，不做原生重建 |

64 题库原生件的有效特征数：中位数 **5**，最多 16。
80% 的零件在 **8 个特征以内**完成。因此：

- 不要把简单件拆成十几个特征；优先一个草图表达多个同层轮廓。
- 也不要为了“特征树短”把不同高度的凸台硬塞进一次拉伸；
  高度不同就分特征，后续出图尺寸更清楚。

### 从序列提炼的固定顺序

```
01 基础体（拉伸/旋转）
02 主体凸台 / 主体切除
03 孔（HoleWzd 或圆草图切除）
04 筋 / 薄壁特征
05 阵列 / 镜像
06 圆角 / 倒角
07 收尾（外观、属性、出图）
```

题库中 **圆角几乎总在最后**；只有少数外观件把圆角放在中段。
照此顺序做，修改尺寸时特征成功率最高。

## 3. 零件族识别 → 首特征

| 图纸特征 | 首特征 | 关键尺寸 |
|---|---|---|
| 一个方向看是阶梯轮廓，另一方向是圆 | 旋转 | 各段直径、各段长度、总长、倒角 |
| 板状、有缺口/凸台/孔 | 拉伸（板面） | 长、宽、厚、孔距、孔径 |
| L 形、U 形、带加强筋 | 拉伸（侧剖面） | 壁厚、开口尺寸、筋厚/筋高 |
| 法兰/圆盘 | 旋转 + 圆周阵列 | 外径、内径、PCD、螺栓孔数/孔径 |
| 轮坯/齿轮坯 | 旋转 + 圆周阵列 | 外径、辐板厚、轮毂孔径、减重孔 |
| 弹簧/螺旋槽 | 螺旋 + 扫描 | 中径、线径、圈数、螺距 |
| 弯管/异形杆 | 扫描 | 路径、截面、弯曲半径 |

识别错误时的代价最大：**把旋转件当拉伸件做，会多出 5～10 个特征，且同轴度难以保证**。
先看主视图是否有回转中心线，再决定首特征。

## 4. 尺寸标注模式（图纸 → 参数表）

| 零件族 | 图纸上通常给 | 需要推导 |
|---|---|---|
| 板类 | 总长、总宽、总厚、孔距、孔径 | 孔边距、圆角半径 |
| 轴类 | 各段直径、各段长度、总长、键槽宽/深 | 轴肩过渡圆角、倒角 |
| 法兰 | 外径、内径、PCD、孔数、孔径、厚度 | 螺栓孔沉孔尺寸 |
| 支架 | 外形长宽高、壁厚、孔径/孔距 | 筋厚、内圆角 |
| 轮坯 | 外径、轮毂外径/内径、辐板厚、减重孔 | 轮缘厚、过渡圆角 |

**只要图纸没有直接标，就必须标来源为 `derived` 或 `assumed`**，
并在模式 B 的检查点让用户确认，不要静默取值。

### 典型尺寸链

- 板类：`总长 = 左孔边距 + 孔距×(n-1) + 右孔边距`；先定孔位，再反推边距。
- 轴类：`总长 = Σ 各段长`；轴肩直径差决定定位面，倒角一般 C1。
- 法兰：`PCD = 螺栓孔中心圆直径`；孔位用极坐标 `(PCD/2·cosθ, PCD/2·sinθ)`。
- 连杆：`中心距` 是主参数；两端圆半径独立；连接边用**外公切线**，不是随手画斜线。

## 5. 题库里的“坑”

1. **`ICE` 不是错误**：导入件重建后大量特征会变成 `ICE`，尺寸仍在。
   审查时按特征名判断用途，不要按类型名判断失败。
2. **旋转角度伪值 6283.185307**：部分旧模型的旋转角度以 `2π×1000` 存储，
   读到这个值等价于 360°，不是 6283°。
3. **`BaseBody` 件不要重画**：40 题库里的轴承、螺栓、挡圈是标准件，
   应调用标准件或按标准尺寸建一次，不要从图纸逐线描。
4. **薄壁特征 `BossThin`/`CutThin`**：题库中用于钣金/壳体；
   普通实体件不要用它代替拉伸，否则出图时壁厚方向容易标错。
5. **镜像/阵列前先确认对称面**：题库支架类 90% 用 `MirrorPattern`，
   但镜像面选错会产生“看起来对称、实际偏 1 个壁厚”的模型。

## 6. 用这些模式做什么

- 拿到新图纸：先在第 3 节表里选零件族 → 首特征 → 对应 `references/recipes/` 配方。
- 配方里的步骤顺序来自本节统计，不要随意调换“孔在筋前、圆角最后”。
- 只有配方不覆盖时，才回到 `references/drawing-to-part.md` 的通用七步。
